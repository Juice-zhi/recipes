# 🍳 食谱集合 Recipe Collection

> 精心整理的中西美食食谱，包含经典菜肴和甜点

## 📁 项目结构

```
recipes/
├── classic/          # 经典菜谱 (100道)
│   ├── 中餐         # 川菜、粤菜、湘菜等
│   ├── 西餐         # 意大利菜、法国菜等
│   ├── 日料         # 寿司、拉面、天妇罗等
│   ├── 韩餐         # 烤肉、泡菜、石锅拌饭等
│   └── 东南亚       # 泰餐、越餐、马来菜等
│
└── desserts/        # 甜点食谱 (100道)
    ├── 蛋糕类       # 芝士蛋糕、慕斯等
    ├── 饼干类       # 曲奇、布朗尼等
    ├── 传统甜点     # 中式糖水、糕点等
    └── 冰品        # 冰淇淋、冰沙等
```

## 📖 使用说明

每个食谱文件包含：

- **简介** - 菜品的历史和特点
- **所需食材** - 完整的配料清单
- **步骤** - 详细的烹饪过程
- **烹饪技巧** - 让菜品更美味的小窍门

## 🍽️ 如何使用

1. 找到想做的菜
2. 查看所需食材
3. 按照步骤操作
4. 享受美食！
