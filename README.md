# 🍳 美食菜谱合集

这是一个收录全球经典美食的菜谱集合，包含中式菜肴和西式甜点。

## 📁 文件夹结构

```
recipes/
├── classic/     # 经典菜肴 (100道)
│   └── 中式菜肴 + 国际美食
└── desserts/    # 甜点食谱 (100道)
    └── 各种美味甜点
```

## 📖 食用指南

### Classic 文件夹
包含100道经典菜肴，涵盖：
- 川菜经典（麻婆豆腐、宫保鸡丁、糖醋排骨等）
- 中华名菜（北京烤鸭、西湖醋鱼、东坡肉等）
- 国际美食（日本寿司、韩国烤肉、意大利披萨、越南河粉等）

### Desserts 文件夹
包含100道美味甜点，涵盖：
- 蛋糕类（芝士蛋糕、布朗尼、提拉米苏等）
- 中式甜点（双皮奶、桂花糕、凤梨酥等）
- 冰淇淋与慕斯（冰淇淋、慕斯、果冻等）

## 📝 使用方法

1. 选择感兴趣的菜谱
2. 查看所需食材清单
3. 按照详细步骤操作
4. 享受美味佳肴！
