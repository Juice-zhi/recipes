# 蛋挞

## 简介

蛋挞（Egg Tart）是一款经典的中式甜点，外层酥脆的塔皮包裹着香滑嫩黄的蛋奶馅，口感层次分明，是茶餐厅和甜品店的热门点心。制作简单，成功率高，非常适合家庭制作。

## 所需食材

### 塔皮
- 低筋面粉 150克
- 黄油 75克
- 糖粉 30克
- 蛋黄 1个
- 牛奶 15毫升
- 盐 少许

### 蛋挞液
- 蛋黄 3个
- 细砂糖 50克
- 牛奶 100毫升
- 淡奶油 100毫升
- 香草精 1/2茶匙

## 步骤

### 1. 制作塔皮
1. 黄油软化后加入糖粉
2. 打发至颜色变浅
3. 加入蛋黄继续搅拌
4. 筛入面粉和盐
5. 加入牛奶揉成面团
6. 包保鲜膜冷藏30分钟

### 2. 分割与整形
1. 将面团分成12等份
2. 放入蛋挞模具中
3. 用手指按压成塔皮形状
4. 底部要薄，边缘要厚
5. 用叉子在底部扎几个小孔

### 3. 制作蛋挞液
1. 蛋黄和糖放入碗中
2. 搅拌至糖溶解
3. 加入牛奶和淡奶油
4. 加入香草精拌匀
5. 过筛去除气泡

### 4. 倒入与烘烤
1. 将蛋挞液倒入塔皮中
2. 约8分满
3. 烤箱预热220°C
4. 放入蛋挞
5. 烘烤约15-18分钟
6. 表面起焦斑即可

## 烹饪技巧

1. **塔皮厚度**：底部约3毫米，边缘约5毫米
2. **蛋挞液过滤**：过筛两次更细腻，无气泡
3. **烘烤温度**：高温快速烘烤，表面起焦斑
4. **防止馅料溢出**：倒8分满即可
5. **冷却后食用**：稍凉后塔皮更酥脆
