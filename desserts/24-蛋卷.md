# 蛋卷

## 简介

蛋卷是经典的中式传统点心，金黄酥脆的表皮包裹着香浓的馅料，味道香甜可口。在大街小巷的零食摊位都能看到它的身影，是很多人童年回忆中的味道。

## 所需食材

### 蛋卷皮
- 鸡蛋 3个
- 低筋面粉 100克
- 细砂糖 80克
- 黄油 60克
- 牛奶 50毫升
- 香草精 1/2茶匙

### 馅料
- 花生酱 100克
- 炼乳 50克
- 或直接使用打发的淡奶油

## 步骤

### 1. 制作面糊
1. 鸡蛋和糖放入碗中打散
2. 加入融化的黄油
3. 加入牛奶和香草精
4. 筛入低筋面粉
5. 搅拌成顺滑的面糊

### 2. 摊蛋卷皮
1. 蛋卷模具预热
2. 舀一勺面糊在模具上
3. 盖上模具
4. 两面加热约1分钟
5. 打开至表面金黄

### 3. 卷起
1. 趁热将蛋饼放在案板上
2. 用筷子或专用工具卷起
3. 边卷边压实
4. 抽出工具，定型

### 4. 填馅（可选）
1. 如果做空心蛋卷，在面糊中少加液体
2. 如需填馅，在卷之前加入馅料
3. 花生酱加炼乳调匀作为馅料

## 烹饪技巧

1. **模具选择**：专用蛋卷模具效果最好
2. **火候控制**：中小火，勤翻面
3. **动作要快**：蛋卷皮冷却后会变脆，无法卷起
4. **防粘处理**：模具要擦干净，必要时刷油
5. **保存方法**：密封保存，防止受潮
