# 糖不甩

## 简介

糖不甩是广东传统甜品，糯米丸子裹上浓稠的红糖浆，撒上花生碎，口感软糯香甜，是元宵节的应节食品。

## 所需食材

- 糯米粉 150克
- 温水 100毫升
- 红糖 80克
- 清水 150毫升
- 花生 50克
- 芝麻 20克
- 姜片 2片（可选）

## 步骤

### 1. 和面团
1. 糯米粉放入盆中
2. 慢慢加入温水
3. 揉成光滑面团
4. 不粘手即可

### 2. 制作丸子
1. 面团分成小份
2. 搓成约2cm的小丸子
3. 放入沸水中煮至浮起
4. 捞出沥干水分

### 3. 制作糖浆
1. 锅中放入红糖和清水
2. 小火加热搅拌
3. 煮至浓稠起小泡
4. 可加姜片增香

### 4. 炒配料
1. 花生和芝麻炒香
2. 花生去皮压碎
3. 与芝麻混合

### 5. 裹糖装盘
1. 丸子放入糖浆中翻匀
2. 装入盘中
3. 撒上花生芝麻碎

## 烹饪技巧

1. **温水和面**：太烫会烫熟，太冷不成团
2. **丸子大小**：2cm左右最佳，太大不熟
3. **糖浆浓稠**：要煮到能挂住勺子
4. **花生去皮**：炒好后装入袋子压一下，皮会自动脱落
