# 闪电泡芙

## 简介

闪电泡芙（Eclair）是法国最受欢迎的甜点之一，长条形状的外皮酥脆可口，淋上巧克力ganache，颜值与美味并存。

## 所需食材

### 泡芙皮
- 牛奶 80毫升
- 水 80毫升
- 黄油 70克
- 细砂糖 5克
- 盐 2克
- 低筋面粉 100克
- 鸡蛋 3个

### 巧克力ganache
- 黑巧克力 150克
- 淡奶油 150毫升
- 黄油 20克

### 奶油馅
- 淡奶油 200毫升
- 细砂糖 15克
- 香草精 少许

## 步骤

### 1. 制作泡芙面团
1. 牛奶、水、黄油、糖、盐加热至沸腾
2. 一次性倒入面粉搅拌成团
3. 冷却后逐个加入鸡蛋
4. 搅拌至光滑呈倒三角形

### 2. 挤形与烘烤
1. 面糊装入裱花袋
2. 挤出约12cm长条
3. 手指沾水抹平表面
4. 200°C烤15分钟，后180°C烤15分钟
5. 完全冷却后使用

### 3. 巧克力ganache
1. 淡奶油加热至沸腾
2. 倒入切碎的巧克力
3. 静置2分钟后搅拌
4. 加入黄油拌匀

### 4. 奶油馅
1. 淡奶油加糖打发
2. 加入香草精拌匀

### 5. 组装
1. 泡芙底部戳孔
2. 挤入奶油馅
3. 表面淋上巧克力ganache
4. 冷藏30分钟让巧克力凝固

## 烹饪技巧

1. **面团状态**：太稀会塌陷，太稠膨胀不起来
2. **烤制时间**：必须烤透，否则会塌陷
3. **巧克力温度**：ganache温度要适中才能淋出完美表面
4. **装饰创意**：可撒坚果碎或珍珠糖
