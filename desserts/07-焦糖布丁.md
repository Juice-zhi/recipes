# 焦糖布丁

## 简介

焦糖布丁（Creme Caramel）是一款经典法式甜点，细腻嫩滑的蛋奶布丁搭配香甜微苦的焦糖酱，入口即化，是东西方都深受喜爱的甜点。制作简单，但需要掌握好火候才能做出完美的口感。

## 所需食材

### 焦糖
- 细砂糖 100克
- 清水 30毫升
- 热水 15毫升

### 布丁液
- 鸡蛋 3个
- 蛋黄 2个
- 细砂糖 50克
- 牛奶 400毫升
- 香草精 1茶匙

## 步骤

### 1. 制作焦糖
1. 将糖和清水放入锅中
2. 中火加热至糖融化
3. 继续加热至琥珀色
4. 离火加入热水（小心溅出）
5. 快速晃动锅子混合
6. 倒入模具底部铺平

### 2. 制作布丁液
1. 鸡蛋和蛋黄打入碗中
2. 加入细砂糖搅拌至溶解
3. 牛奶加热至温热
4. 慢慢倒入蛋液中，边倒边搅拌
5. 加入香草精拌匀
6. 过筛去除气泡和杂质

### 3. 组合与蒸烤
1. 将布丁液倒入铺好焦糖的模具中
2. 盖上锡纸
3. 放入烤盘，加入热水至模具一半高度
4. 烤箱预热150°C，水浴法烘烤约40分钟
5. 或用蒸锅中小火蒸约30分钟

### 4. 冷却脱模
1. 取出冷却后放入冰箱冷藏至少2小时
2. 食用前用小刀沿边缘划开
3. 盘子扣在模具上快速翻转

## 烹饪技巧

1. **焦糖火候**：糖色深浅决定苦味程度，根据个人喜好调整
2. **加入热水**：一定要小心，热焦糖遇水会飞溅
3. **水浴温度**：烤箱150°C正好，温度太高会老
4. **判断熟透**：布丁中心轻晃时微微晃动即可
5. **脱模技巧**：确保布丁完全冷却后再脱模，成功率更高
