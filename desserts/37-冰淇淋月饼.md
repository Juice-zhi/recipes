# 冰淇淋月饼

## 简介

冰淇淋月饼是近年来流行的创意甜点，将冰淇淋做成月饼的形状，外层是细腻的巧克力脆皮，内里是各种口味的冰淇淋。口感丝滑，冰凉解暑，是中秋节的创新选择。

## 所需食材

### 冰淇淋内馅
- 淡奶油 200毫升
- 牛奶 100毫升
- 细砂糖 50克
- 蛋黄 2个
- 香草精 1茶匙

### 巧克力外皮
- 黑巧克力 150克
- 可可脂 50克（可选，增加光泽）

### 模具
- 月饼模具 50克左右

## 步骤

### 1. 制作冰淇淋
1. 蛋黄加糖打至颜色变浅
2. 牛奶加热至微沸，慢慢倒入蛋黄中
3. 倒回锅中，小火加热搅拌至浓稠
4. 冷却后加入淡奶油和香草精
5. 放入冰淇淋机冷冻

### 2. 冷冻成型
1. 将冰淇淋舀入月饼模具中
2. 插上冰棍棒
3. 冷冻至少4小时

### 3. 制作巧克力外皮
1. 巧克力和可可脂隔水融化
2. 温度控制在35-40°C

### 4. 挂巧克力
1. 冰淇淋脱模
2. 快速浸入巧克力中
3. 提起沥干多余巧克力
4. 表面凝固后可再次浸一次

## 烹饪技巧

1. **冰淇淋硬度**：冻硬后再挂巧克力
2. **巧克力温度**：不能太热，会烫化冰淇淋
3. **动作要快**：浸入后迅速提起
4. **保存方法**：冷冻保存
5. **口味变化**：可以加入抹茶、芒果等不同口味
