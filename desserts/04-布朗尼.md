# 布朗尼

## 简介

布朗尼（Brownie）是一款美国经典甜点，介于蛋糕与饼干之间，外表酥脆内心湿润，浓郁的巧克力风味让人回味无穷。

## 所需食材

- 黑巧克力 150克
- 黄油 100克
- 细砂糖 100克
- 鸡蛋 2个
- 低筋面粉 60克
- 可可粉 15克
- 核桃碎 80克
- 香草精 1茶匙
- 盐 少许

## 步骤

### 1. 融化巧克力
1. 巧克力和黄油隔热水融化
2. 搅拌至光滑细腻

### 2. 搅拌面糊
1. 加入细砂糖搅拌均匀
2. 加入鸡蛋和香草精拌匀
3. 筛入面粉、可可粉和盐
4. 翻拌至无干粉
5. 加入核桃碎拌匀

### 3. 烘烤
1. 将面糊倒入铺好烘焙纸的方形模具中
2. 烤箱预热180°C
3. 烘烤约20-25分钟
4. 表面凝固但内部微湿即可

### 4. 冷却切块
1. 冷却后切成长方形小块
2. 可撒上糖粉装饰

## 烹饪技巧

1. **巧克力选择**：使用70%黑巧克力，风味更浓郁
2. **判断熟度**：插入牙签有少量粘连即可，不要烤太干
3. **核桃替换**：可用碧根果或夏威夷果代替
4. **冷却时间**：完全冷却后再切块，切面更整齐
