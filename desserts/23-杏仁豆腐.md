# 杏仁豆腐

## 简介

杏仁豆腐是一款传统的中式甜品，口感嫩滑如豆腐，带有浓郁的杏仁香气，是清热润肺的美味甜点。

## 所需食材

- 杏仁露 400毫升
- 牛奶 200毫升
- 细砂糖 50克
- 吉利丁片 2片（10克）
- 桂花糖浆 或 蜂蜜 适量

## 步骤

### 1. 泡吉利丁
1. 吉利丁片放入冷水中泡5分钟
2. 泡软后沥干水分

### 2. 加热混合
1. 杏仁露和牛奶放入锅中
2. 加入糖加热搅拌
3. 糖融化后关火
4. 加入泡软的吉利丁
5. 搅拌至完全融化

### 3. 过滤
1. 过筛去除杂质
2. 让口感更细腻

### 4. 凝固
1. 倒入模具中
2. 冷却后放入冰箱
3. 冷藏至少2小时至凝固

### 5. 食用
1. 取出倒扣在盘中
2. 淋上桂花糖浆或蜂蜜
3. 可加水果装饰

## 烹饪技巧

1. **杏仁露选择**：可自制或购买现成的
2. **吉利丁泡发**：必须用冷水，热水会失去凝固力
3. **过滤重要**：去除颗粒，口感更顺滑
4. **脱模技巧**：模具边缘用热水烫一下再倒扣
