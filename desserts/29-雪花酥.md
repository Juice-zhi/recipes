# 雪花酥

## 简介

雪花酥是近年流行的网红零食，酥脆的饼干搭配坚果和果干，裹上奶粉和糖粉，口感丰富，甜而不腻。

## 所需食材

- 棉花糖 150克
- 黄油 40克
- 奶粉 50克
- 蔓越莓干 60克
- 坚果 80克（花生、杏仁、核桃等）
- 韧性饼干 150克
- 糖粉或奶粉 适量（表面装饰）

## 步骤

### 1. 准备工作
1. 蔓越莓干切碎
2. 坚果切碎或保持整颗
3. 饼干掰成小块
4. 奶粉准备好

### 2. 融化棉花糖
1. 不粘锅小火加热
2. 放入黄油融化
3. 加入棉花糖
4. 不断搅拌至完全融化

### 3. 混合
1. 棉花糖融化后关火
2. 迅速倒入奶粉翻拌
3. 加入饼干、坚果和蔓越莓
4. 快速翻拌均匀

### 4. 整形
1. 倒入不粘烤盘或硅胶垫上
2. 戴手套趁热整形成方形
3. 压实压平
4. 冷却至定型

### 5. 切块
1. 冷却后切成小块
2. 撒上奶粉或糖粉
3. 摇晃让表面均匀裹粉

## 烹饪技巧

1. **全程小火**：防止棉花糖焦化
2. **动作要快**：混合后要迅速翻拌
3. **饼干选择**：要用韧性饼干，硬饼干会扎嘴
4. **坚果选择**：多种坚果混合口感更丰富
5. **保存**：密封保存，避免受潮
