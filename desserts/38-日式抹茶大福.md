# 日式抹茶大福

## 简介

日式抹茶大福是日本和果子的经典，外皮加入抹茶粉呈翠绿色，内馅通常是红豆沙或栗子，口感软糯，茶香浓郁。

## 所需食材

### 外皮
- 糯米粉 100克
- 抹茶粉 8克
- 细砂糖 50克
- 牛奶 120毫升
- 玉米淀粉 30克（炒熟）

### 内馅
- 红豆沙 150克
- 栗子酱 适量（可选）

## 步骤

### 1. 炒熟淀粉
1. 玉米淀粉放入锅中
2. 小火炒至微黄
3. 冷却备用

### 2. 制作外皮
1. 糯米粉、抹茶粉、糖混合
2. 加入牛奶搅拌
3. 盖保鲜膜蒸约15分钟
4. 蒸熟后搅拌至光滑

### 3. 包制
1. 案板撒熟淀粉
2. 糯米团分成小球
3. 压扁包入红豆沙
4. 收口搓圆

### 4. 装饰
1. 顶部可点上少许抹茶
2. 冷藏后口感更佳

## 烹饪技巧

1. **抹茶粉选择**：品质好的抹茶颜色翠绿
2. **蒸熟程度**：完全蒸熟才能包
3. **趁热操作**：糯米团凉后会变硬
4. **手粉用量**：不要太多，影响口感
5. **当天食用**：放久了皮会变硬
