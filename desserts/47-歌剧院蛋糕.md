# 歌剧院蛋糕

## 简介

歌剧院蛋糕（Opera Cake）是法国甜点的巅峰之作，由多层杏仁海绵蛋糕、咖啡奶油和巧克力甘纳许组成，层层叠叠高达十层。

## 所需食材

### 杏仁海绵蛋糕
- 鸡蛋 3个
- 细砂糖 60克
- 杏仁粉 60克
- 低筋面粉 20克
- 黄油 20克（融化）

### 咖啡奶油
- 蛋黄 3个
- 细砂糖 50克
- 淡奶油 150毫升
- 速溶咖啡粉 8克
- 吉利丁片 1片

### 巧克力甘纳许
- 黑巧克力 100克
- 淡奶油 80毫升
- 黄油 20克

### 装饰
- 融化巧克力 适量
- 金箔 少许（可选）

## 步骤

### 1. 烤杏仁蛋糕
1. 蛋白蛋黄分开
2. 蛋黄加30克糖打至淡黄色
3. 蛋白加30克糖打至硬性发泡
4. 混合后筛入杏仁粉和面粉
5. 加入融化的黄油
6. 烤盘铺平，180°C烤约10分钟
7. 冷却后切成三片

### 2. 制作咖啡奶油
1. 蛋黄和糖隔热水打至浓稠
2. 咖啡粉用少许热水化开
3. 加入蛋黄糊中
4. 泡软的吉利丁加入搅拌
5. 冷却后与打发的淡奶油混合

### 3. 制作甘纳许
1. 巧克力切碎
2. 淡奶油加热倒入巧克力
3. 搅拌至光滑
4. 加入黄油拌匀

### 4. 组装
1. 一片蛋糕抹咖啡奶油
2. 重复三层
3. 顶部倒甘纳许抹平
4. 冷藏至凝固

### 5. 装饰
1. 切去边缘不整齐部分
2. 融化巧克力画线装饰
3. 切块食用

## 烹饪技巧

1. **蛋糕烤制**：不要烤太久，保持湿润
2. **咖啡浓度**：根据个人口味调整
3. **甘纳许温度**：不能太热或太凉
4. **切割技巧**：热刀切更整齐
5. **层次分明**：每层都要抹平
