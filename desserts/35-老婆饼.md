# 老婆饼

## 简介

老婆饼是广东传统糕点，酥脆的千层外皮包裹着冬瓜糖馅，甜而不腻，是潮汕地区的著名伴手礼。

## 所需食材

### 油皮
- 中筋面粉 150克
- 猪油 50克
- 糖 20克
- 水 70毫升

### 油酥
- 低筋面粉 100克
- 猪油 50克

### 馅料
- 冬瓜糖 100克
- 细砂糖 80克
- 熟芝麻 30克
- 猪油 30克
- 清水 50毫升

### 装饰
- 蛋黄 1个（刷表面）
- 白芝麻 少许

## 步骤

### 1. 制作油皮
1. 面粉、糖、猪油混合
2. 加水揉成光滑面团
3. 冷藏30分钟

### 2. 制作油酥
1. 面粉和猪油混合
2. 揉成团，冷藏

### 3. 制作馅料
1. 冬瓜糖切碎
2. 加糖和清水煮化
3. 加入芝麻和猪油
4. 冷却后分成小份

### 4. 包裹与折叠
1. 油皮包入油酥
2. 擀开成长条
3. 卷起，冷藏15分钟
4. 重复两次

### 5. 包制与烘烤
1. 面团擀成圆皮
2. 包入馅料，收口
3. 压扁，表面划两刀
4. 刷蛋黄，撒芝麻
5. 180°C烤约20分钟

## 烹饪技巧

1. **猪油作用**：起酥效果最好，也可用黄油
2. **油皮油酥软硬**：两者软硬度要相近
3. **折叠次数**：两次三折，层次丰富
4. **表面划刀**：划破表皮，防止鼓包
