# 雪花酥

## 简介

雪花酥是近年来流行的网红甜点，酥脆的饼干、柔软的棉花糖、浓郁的奶粉和香脆的坚果完美结合。口感丰富，甜而不腻，是下午茶和伴手礼的热门选择。制作简单，无需烤箱。

## 所需食材

- 棉花糖 150克
- 黄油 40克
- 奶粉 50克
- 韧性饼干 150克
- 坚果（杏仁、核桃、腰果）80克
- 蔓越莓干 40克
- 糖粉 适量（表面装饰）

## 步骤

### 1. 准备工作
1. 坚果切碎
2. 蔓越莓干切小
3. 韧性饼干掰成小块
4. 准备一个不粘烤盘

### 2. 融化棉花糖
1. 不粘锅中放入黄油
2. 小火加热至融化
3. 放入棉花糖
4. 不断搅拌至完全融化
5. 融化后立即离火

### 3. 混合材料
1. 快速倒入奶粉
2. 搅拌均匀
3. 倒入饼干、坚果和蔓越莓干
4. 快速翻拌，让材料均匀裹上棉花糖

### 4. 整形
1. 戴上手套
2. 将混合物放入烤盘中
3. 用手按压平整
4. 表面撒上一层奶粉
5. 翻面再撒奶粉
6. 冷却定型

### 5. 切块
1. 完全冷却后
2. 用刀切成小块
3. 表面再撒些奶粉防粘

## 烹饪技巧

1. **火候控制**：全程小火，棉花糖焦了会苦
2. **动作要快**：棉花糖融化后要迅速加入材料
3. **饼干选择**：要用韧性饼干，酥性饼干会太碎
4. **坚果选择**：混合坚果风味更丰富
5. **保存方法**：密封保存，防止受潮变软
