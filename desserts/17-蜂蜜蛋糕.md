# 蜂蜜蛋糕

## 简介

蜂蜜蛋糕是日本著名的伴手礼，绵密湿润的蛋糕体带着浓郁的蜂蜜香甜，是茶道茶点的绝佳选择。

## 所需食材

- 鸡蛋 3个
- 细砂糖 80克
- 蜂蜜 50克
- 低筋面粉 100克
- 黄油 30克（融化）
- 牛奶 30毫升
- 柠檬汁 少许

## 步骤

### 1. 准备工作
1. 模具铺好烘焙纸
2. 烤箱预热170°C

### 2. 打发蛋液
1. 鸡蛋和糖放入盆中
2. 隔热水打发
3. 打发至颜色变浅、体积膨胀
4. 加入蜂蜜继续打发

### 3. 加入干料
1. 筛入面粉
2. 翻拌至无干粉
3. 融化黄油和牛奶混合
4. 取少量面糊与黄油混合
5. 倒回主面糊中翻拌

### 4. 烘烤
1. 将面糊倒入模具中
2. 轻轻敲几下震出气泡
3. 170°C烤约40分钟
4. 表面金黄，插入牙签无面糊即可

### 5. 装饰
1. 冷却后刷一层蜂蜜水
2. 可撒杏仁片装饰

## 烹饪技巧

1. **隔水打发**：水温约40°C，帮助打发
2. **蜂蜜作用**：增加湿润度和特殊香气
3. **黄油混合**：必须先与少量面糊混合再倒回，防止消泡
4. **保存**：密封保存可维持一周
