# 木瓜炖雪蛤

## 简介

木瓜炖雪蛤是经典的美容养颜甜品，雪蛤（林蛙卵巢）富含胶原蛋白，搭配木瓜的清香，是女性的滋补圣品。

## 所需食材

- 木瓜 1个（选择熟透的）
- 雪蛤膏 5克
- 冰糖 30克
- 牛奶 100毫升
- 枸杞 少许（装饰）

## 步骤

### 1. 泡发雪蛤
1. 雪蛤膏用冷水泡12小时
2. 期间换水2-3次
3. 泡发后去除杂质
4. 放入沸水中焯一下

### 2. 处理木瓜
1. 木瓜洗净
2. 从1/3处切开
3. 挖去籽和部分果肉
4. 形成盅状

### 3. 炖制
1. 雪蛤放入木瓜中
2. 加入冰糖
3. 盖上木瓜盖
4. 放入炖盅
5. 加水隔水炖1小时

### 4. 加入牛奶
1. 炖好后打开木瓜盖
2. 加入牛奶
3. 继续炖5分钟

### 5. 完成
1. 撒上枸杞装饰
2. 趁热或冷却后食用

## 烹饪技巧

1. **雪蛤选择**：品质好的雪蛤泡发率高
2. **泡发时间**：必须充分泡发
3. **木瓜选择**：选熟透的，香味更浓
4. **炖盅密封**：确保炖盅密封效果好
5. **牛奶时机**：最后加入，保持营养
