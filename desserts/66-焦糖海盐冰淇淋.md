# 焦糖海盐冰淇淋

## 简介

焦糖海盐冰淇淋是进阶版冰淇淋，焦糖的甜味与海盐的咸味碰撞，层次丰富。

## 所需食材

- 蛋黄 4个
- 细砂糖 100克
- 牛奶 200毫升
- 淡奶油 250毫升
- 海盐 1/2茶匙
- 香草精 1茶匙

## 步骤

### 1. 制作焦糖
1. 50克糖放入锅中
2. 小火煮至琥珀色
3. 加入50毫升热水（小心）
4. 焦糖酱完成

### 2. 制作蛋奶酱
1. 蛋黄和50克糖打至淡黄色
2. 牛奶加热倒入蛋黄中
3. 倒回锅中，小火搅拌至浓稠
4. 加入香草精

### 3. 混合
1. 蛋奶酱冷却
2. 加入淡奶油
3. 加入焦糖酱和海盐
4. 搅拌均匀

### 4. 冷冻
1. 倒入冰淇淋机
2. 或每30分钟搅拌一次
3. 冻至硬身

## 烹饪技巧

1. **焦糖火候**：琥珀色即可，糊了会苦
2. **海盐选择**：片状海盐效果更好
3. **搅拌次数**：手动搅拌越多越绵密
