# 椰奶西米露

## 简介

椰奶西米露是东南亚地区的经典甜品，Q弹的西米搭配香浓的椰奶，口感清爽。夏天冰镇后饮用消暑解渴，是非常受欢迎的热带风味甜品。

## 所需食材

- 西米 50克
- 椰浆 200毫升
- 牛奶 100毫升
- 细砂糖 30克
- 芒果 1个（可选）
- 椰丝 少许（装饰）

## 步骤

### 1. 煮西米
1. 烧一锅水，水开后下西米
2. 煮约10分钟，期间不断搅拌
3. 西米中间还有小白点时关火
4. 盖上锅盖焖10分钟
5. 至完全透明
6. 捞出用冷水冲洗，沥干

### 2. 制作椰奶
1. 椰浆和牛奶混合
2. 加入糖搅拌至融化
3. 可以稍微加热让糖融化

### 3. 混合
1. 将西米放入碗中
2. 倒入椰奶
3. 搅拌均匀
4. 放入冰箱冷藏1小时

### 4. 装饰
1. 芒果切块放入
2. 撒上椰丝

## 烹饪技巧

1. **西米煮法**：沸水下锅，不断搅拌防止粘锅
2. **西米保存**：沥干水分，防止粘连
3. **椰奶比例**：椰浆和牛奶比例约2:1
4. **甜度调整**：根据个人口味调整糖量
5. **食用温度**：冰镇后口感更佳
