# 南瓜布丁

## 简介

南瓜布丁是万圣节特色甜点，绵密的南瓜泥搭配顺滑的布丁，秋季限定。

## 所需食材

- 南瓜泥 200克
- 鸡蛋 2个
- 牛奶 150毫升
- 细砂糖 40克
- 肉桂粉 1/2茶匙
- 焦糖 适量

## 步骤

### 1. 蒸南瓜
1. 南瓜蒸熟压成泥
2. 取200克备用

### 2. 制作布丁液
1. 鸡蛋和糖搅拌
2. 加入牛奶和南瓜泥
3. 加入肉桂粉拌匀
4. 过筛

### 3. 蒸制
1. 模具底部倒焦糖
2. 倒入布丁液
3. 盖保鲜膜扎孔
4. 中火蒸约25分钟

### 4. 出炉
1. 冷却后脱模
2. 表面可撒肉桂粉

## 烹饪技巧

1. **南瓜选择**：贝贝南瓜口感最佳
2. **过筛**：口感更细腻
3. **蒸的火候**：中小火，大火会起泡
