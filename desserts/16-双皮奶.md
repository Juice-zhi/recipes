# 双皮奶

## 简介

双皮奶是广东顺德的传统甜点，因制作后表面形成两层奶皮而得名。第一层奶皮是牛奶冷却后自然形成的，第二层是蛋清蒸熟后形成的。口感细腻嫩滑，奶香浓郁，是经典的广式糖水。

## 所需食材

- 纯牛奶 500毫升（首选水牛奶）
- 鸡蛋清 2个
- 细砂糖 30克
- 桂花 少许（装饰）
- 红豆 适量（配食）

## 步骤

### 1. 加热牛奶
1. 将牛奶倒入锅中
2. 小火加热至边缘冒小泡
3. 不要煮沸
4. 倒入碗中

### 2. 形成第一层奶皮
1. 静置放凉
2. 冷却后表面会形成一层奶皮
3. 大约需要30分钟

### 3. 加入蛋清
1. 鸡蛋清打散
2. 加入细砂糖搅拌至糖融化
3. 将蛋清液倒入放凉的牛奶中
4. 轻轻搅拌均匀

### 4. 蒸制
1. 将混合液倒回锅中（从边缘慢慢倒）
2. 保留第一层奶皮在碗底
3. 盖上保鲜膜
4. 蒸锅水开后放入
5. 中小火蒸约15分钟
6. 蛋清凝固即可

### 5. 出炉与装饰
1. 取出放凉
2. 表面会形成第二层奶皮
3. 撒上桂花
4. 可搭配红豆食用

## 烹饪技巧

1. **牛奶选择**：水牛奶脂肪含量高，奶皮更厚实
2. **加热程度**：加热至冒小泡即可，不要煮沸
3. **蒸制火候**：中小火，大火会起蜂窝
4. **蛋清比例**：蛋清太多口感硬，2个正好
5. **保存方法**：冷藏可保存2天，最好现做现吃
