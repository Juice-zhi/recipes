# 奶酪包

## 简介

奶酪包是新疆地区的特色甜点，外层裹着厚厚的奶粉和糖粉，内部是柔软的奶油奶酪馅。奶香浓郁，口感绵密，是一款让人一口幸福的甜点。

## 所需食材

### 面包体
- 高筋面粉 250克
- 酵母 3克
- 牛奶 120毫升
- 鸡蛋 1个
- 细砂糖 40克
- 盐 3克
- 黄油 30克

### 奶酪馅
- 奶油奶酪 150克
- 糖粉 30克
- 淡奶油 50毫升

### 表面装饰
- 奶粉 50克
- 糖粉 30克

## 步骤

### 1. 制作面团
1. 酵母溶于温牛奶中
2. 面粉、糖、盐、鸡蛋放入盆中
3. 加入酵母水
4. 揉成面团
5. 加入黄油继续揉至扩展阶段
6. 发酵1小时至2倍大

### 2. 整形与发酵
1. 排气，分成6等份
2. 滚圆松弛15分钟
3. 再次滚圆，放入烤盘
4. 盖上保鲜膜，发酵30分钟

### 3. 烘烤
1. 烤箱预热180°C
2. 放入面包
3. 烤约15分钟
4. 表面金黄即可
5. 冷却

### 4. 制作奶酪馅
1. 奶油奶酪软化
2. 加入糖粉打至顺滑
3. 加入淡奶油继续打发
4. 馅料顺滑即可

### 5. 组装
1. 面包从中间切开（不切断）
2. 抹上奶酪馅
3. 表面也抹上奶酪
4. 在奶粉糖粉中滚一圈
5. 均匀裹满

## 烹饪技巧

1. **面团发酵**：温度28-30°C最适合发酵
2. **奶酪软化**：提前软化更容易打发
3. **奶粉选择**：使用无糖奶粉，糖粉根据口味添加
4. **面包选择**：可以用现成的餐包
5. **保存方法**：冷藏保存，食用前回温
