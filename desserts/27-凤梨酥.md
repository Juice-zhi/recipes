# 凤梨酥

## 简介

凤梨酥是台湾的标志性伴手礼，外酥内软的酥皮包裹着酸甜的凤梨馅，寓意"旺来"。内馅可以是纯凤梨或冬瓜凤梨混合，传统做法还会加入咸蛋黄。

## 所需食材

### 凤梨馅
- 凤梨 1个（约800克）
- 细砂糖 100克
- 麦芽糖 50克
- 冬瓜 300克（可选，增加口感）

### 酥皮
- 低筋面粉 200克
- 奶粉 30克
- 黄油 120克
- 糖粉 40克
- 鸡蛋 1个
- 盐 少许

## 步骤

### 1. 制作凤梨馅
1. 凤梨去皮切块
2. 用料理机打成泥
3. 冬瓜去皮切块煮熟，也打成泥
4. 将凤梨泥放入锅中
5. 大火翻炒至水分减少
6. 加入糖和麦芽糖
7. 小火不断翻炒
8. 炒至馅料浓稠成团
9. 冷却后使用

### 2. 制作酥皮
1. 黄油软化，加糖粉打发
2. 加入鸡蛋继续搅拌
3. 筛入面粉、奶粉和盐
4. 揉成面团
5. 包保鲜膜冷藏30分钟

### 3. 包制
1. 凤梨馅分成约15克一个
2. 酥皮分成约20克一个
3. 酥皮按扁，包入馅料
4. 收口捏紧
5. 放入模具中压平

### 4. 烘烤
1. 烤箱预热170°C
2. 放入凤梨酥
3. 烤约15分钟
4. 表面金黄即可

## 烹饪技巧

1. **凤梨选择**：选用金钻凤梨，甜度高
2. **炒馅关键**：要炒到足够干，否则馅料会太湿
3. **酥皮状态**：冷藏后更好包制
4. **模具选择**：专用凤梨酥模具效果好
5. **保存方法**：密封保存，可保存2周
