# 柠檬酱

## 简介

柠檬酱是英式经典酱料，酸甜可口，可以搭配司康、吐司或冰淇淋。

## 所需食材

- 柠檬 3个
- 细砂糖 200克
- 黄油 50克
- 鸡蛋 3个
- 柠檬皮屑 少许

## 步骤

### 1. 处理柠檬
1. 柠檬取汁
2. 保留柠檬皮屑

### 2. 煮酱
1. 柠檬汁、糖、柠檬皮屑放入锅中
2. 加热至糖融化
3. 加入黄块搅拌

### 3. 加入鸡蛋
1. 鸡蛋打散
2. 慢慢倒入热的柠檬混合物
3. 不断搅拌
4. 小火煮至浓稠

### 4. 装瓶
1. 趁热装入消毒的瓶子
2. 冷却后冷藏

## 烹饪技巧

1. **柠檬选择**：皮薄的柠檬更佳
2. **火候控制**：小火慢煮，防止结块
3. **保存期限**：冷藏约2周
