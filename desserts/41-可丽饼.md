# 可丽饼

## 简介

可丽饼（Crepe）是法国布列塔尼地区的经典小吃，薄薄的饼皮可以包裹各种馅料，甜咸皆宜。搭配水果、奶油、巧克力酱等，是优雅的法式甜点代表。

## 所需食材

### 饼皮
- 低筋面粉 100克
- 鸡蛋 2个
- 牛奶 250毫升
- 细砂糖 30克
- 黄油 20克（融化）
- 盐 少许

### 甜味馅料
- 淡奶油 100毫升
- 糖粉 20克
- 草莓 适量
- 香蕉 1根
- 巧克力酱 适量
- 蜂蜜 适量

## 步骤

### 1. 制作面糊
1. 鸡蛋和糖放入碗中打散
2. 加入牛奶搅拌
3. 筛入面粉和盐
4. 加入融化的黄油
5. 搅拌至无颗粒
6. 静置30分钟

### 2. 煎饼皮
1. 平底不粘锅预热
2. 舀一勺面糊倒入
3. 快速转动锅子铺满
4. 中火煎约1分钟
5. 边缘微翘时翻面
6. 再煎10秒
7. 取出叠放

### 3. 包裹馅料
1. 淡奶油加糖粉打发
2. 饼皮铺平
3. 抹上奶油
4. 摆上水果
5. 淋上巧克力酱或蜂蜜
6. 卷起或对折

## 烹饪技巧

1. **面糊浓稠**：酸奶稠度，可根据面粉吸水量调整
2. **锅子温度**：锅热后倒入面糊，快速转动
3. **翻面时机**：边缘微翘时翻面最佳
4. **馅料选择**：可以根据喜好选择任何馅料
5. **现做现吃**：饼皮冷却后会变硬
