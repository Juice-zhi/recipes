# 桃酥

## 简介

桃酥是传统的中式点心，酥脆香甜，入口即化。因加入了核桃仁而得名，是很多人童年回忆中的经典味道。制作简单，是非常受欢迎的传统糕点。

## 所需食材

- 低筋面粉 200克
- 猪油 80克
- 细砂糖 80克
- 鸡蛋 1个
- 泡打粉 2克
- 小苏打 2克
- 核桃仁 50克
- 黑芝麻 少许（装饰）

## 步骤

### 1. 准备工作
1. 核桃仁切碎
2. 鸡蛋打散备用

### 2. 制作面团
1. 猪油软化，加入糖打发
2. 分次加入蛋液搅拌
3. 筛入面粉、泡打粉和小苏打
4. 加入核桃碎
5. 揉成面团

### 3. 整形
1. 面团分成小份，搓圆
2. 放在烤盘上
3. 轻轻压扁
4. 表面刷蛋液
5. 撒上黑芝麻

### 4. 烘烤
1. 烤箱预热170°C
2. 放入桃酥
3. 烤约15-18分钟
4. 表面金黄即可

## 烹饪技巧

1. **猪油选择**：传统使用猪油，起酥效果好
2. **核桃要香**：可以先烤香核桃
3. **面团软硬**：太软会塌，太硬会裂
4. **烘烤观察**：表面金黄即可，不要烤焦
5. **保存方法**：密封保存，保持酥脆
