# 驴打滚

## 简介

驴打滚是北京传统小吃，因制作过程中需要撒黄豆粉，形似老北京郊外野驴打滚扬起的尘土而得名。

## 所需食材

- 糯米粉 200克
- 温水 180毫升
- 红豆沙 200克
- 熟黄豆粉 100克
- 细砂糖 20克（可省）

## 步骤

### 1. 蒸制糯米面团
1. 糯米粉慢慢加入温水
2. 揉成光滑面团
3. 放入盘中压平
4. 蒸锅大火蒸约20分钟

### 2. 准备黄豆粉
1. 黄豆粉放入锅中
2. 小火炒至颜色变深
3. 香味飘出
4. 冷却备用

### 3. 擀制
1. 案板上撒黄豆粉
2. 蒸熟的糯米团取出
3. 表面也撒满黄豆粉
4. 用擀面杖擀成薄片

### 4. 铺馅
1. 红豆沙擀成薄片
2. 铺在糯米皮上
3. 边缘留白

### 5. 卷起
1. 从一边卷起
2. 卷紧实
3. 切段

### 6. 装饰
1. 切面朝上
2. 撒少许黄豆粉

## 烹饪技巧

1. **糯米团软硬**：太软粘手，太硬不好擀
2. **黄豆粉炒制**：炒到金黄香味浓
3. **红豆沙厚薄**：均匀铺开，不要太厚
4. **卷紧**：否则切的时候会散
5. **刀要湿**：切的时候刀沾水防粘
