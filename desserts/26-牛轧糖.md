# 牛轧糖

## 简介

牛轧糖（Nougat）是西方的传统糖果，源自法国。口感软糯Q弹，奶香浓郁，可以加入各种坚果。分为软硬两种，这里介绍的是受欢迎的软质牛轧糖。

## 所需食材

- 棉花糖 200克
- 花生米 150克
- 奶粉 100克
- 黄油 50克
- 蔓越莓干 50克（可选）

## 步骤

### 1. 准备材料
1. 花生米烤香后去皮
2. 稍微压碎
3. 蔓越莓干切碎
4. 棉花糖可以选择白色或彩色的

### 2. 融化棉花糖
1. 不粘锅中放入黄油
2. 小火加热至融化
3. 放入棉花糖
4. 不断翻炒至完全融化
5. 加入奶粉快速翻拌

### 3. 加入配料
1. 倒入花生碎和蔓越莓干
2. 快速翻拌均匀

### 4. 整形
1. 戴上手套
2. 将糖团放入铺了烘焙纸的烤盘中
3. 用手按压平整
4. 表面盖上烘焙纸
5. 用擀面杖擀平

### 5. 冷却切块
1. 冷却至硬
2. 切成小块
3. 用糖纸包好

## 烹饪技巧

1. **棉花糖选择**：无夹心的白色棉花糖最适合
2. **火候控制**：全程小火，防止焦糊
3. **奶粉选择**：全脂奶粉奶香更浓
4. **坚果选择**：可以用杏仁、核桃等代替花生
5. **保存方法**：密封保存，避免受潮
