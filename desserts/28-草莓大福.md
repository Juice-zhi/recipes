# 草莓大福

## 简介

草莓大福是日式和果子中的经典，外皮软糯Q弹，内馅是甜蜜的红豆沙包裹着新鲜草莓，酸甜可口，颜值超高。

## 所需食材

- 草莓 8-10个
- 糯米粉 100克
- 细砂糖 50克
- 水 140毫升
- 玉米淀粉 30克（炒熟作手粉）
- 红豆沙 150克

## 步骤

### 1. 处理草莓
1. 草莓洗净去蒂
2. 用厨房纸吸干水分
3. 红豆沙团成小球
4. 用红豆沙包裹草莓
5. 收口包紧

### 2. 制作糯米皮
1. 糯米粉和糖混合
2. 慢慢加入水
3. 搅拌成无颗粒的糊状
4. 盖上保鲜膜

### 3. 蒸制
1. 放入蒸锅中火蒸约15分钟
2. 蒸至完全熟透
3. 取出搅拌至光滑

### 4. 包制
1. 炒熟的淀粉铺在案板上
2. 糯米团分成小球
3. 擀成圆形薄皮
4. 放上包裹好的草莓
5. 收口包紧

### 5. 完成
1. 收口朝下
2. 可撒少许淀粉防粘
3. 冷藏30分钟口感更佳

## 烹饪技巧

1. **草莓选择**：中等大小、形状均匀的草莓
2. **红豆沙干湿**：太湿会渗出来，太干不好包
3. **糯米皮温度**：温热时好包，凉了会硬
4. **手粉重要**：必须用熟淀粉，生粉口感不好
5. **尽快食用**：放久了外皮会变硬
