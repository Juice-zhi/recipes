# 杨枝甘露

## 简介

杨枝甘露是香港满记甜品的招牌甜品，芒果的香甜与西柚的酸苦完美平衡，加上Q弹的西米，是广式糖水的代表作。

## 所需食材

- 芒果 2个（较大）
- 西柚 1/2个
- 西米 50克
- 椰奶 200毫升
- 淡奶油 100毫升
- 细砂糖 30克
- 薄荷叶 少许（装饰）

## 步骤

### 1. 煮西米
1. 锅中水开后放入西米
2. 煮约15分钟，焖10分钟
3. 透明后过冷水冲洗
4. 沥干水分备用

### 2. 处理水果
1. 芒果去皮，一半切块，一半打泥
2. 西柚取出果肉，剥成小粒

### 3. 制作芒果酱
1. 芒果泥加一半椰奶和糖
2. 搅拌至糖融化

### 4. 混合
1. 剩余椰奶和淡奶油混合
2. 加入西米和芒果酱
3. 轻轻拌匀

### 5. 装碗
1. 先放芒果块
2. 倒入西米芒果混合物
3. 撒上西柚果肉
4. 薄荷叶装饰

## 烹饪技巧

1. **芒果选择**：成熟度高、香味浓的芒果最好
2. **西柚替代**：可用沙田柚代替
3. **西柚去苦**：白色筋膜要去干净
4. **即做即食**：放置久了西米会变硬
