# 拿破仑蛋糕

## 简介

拿破仑蛋糕（Mille-feuille）是法国经典三层甜点，酥脆的千层派皮夹着顺滑的香草奶油，层层叠叠高达十几层。

## 所需食材

### 千层派皮
- 低筋面粉 300克
- 黄油 250克（冷藏）
- 细砂糖 10克
- 盐 3克
- 冰水 150毫升

### 香草奶油
- 牛奶 300毫升
- 蛋黄 3个
- 细砂糖 60克
- 玉米淀粉 25克
- 香草精 1茶匙
- 淡奶油 150毫升

### 装饰
- 糖粉 适量
- 巧克力酱 少许

## 步骤

### 1. 制作派皮
1. 面粉、糖、盐混合，加水揉成团
2. 冷藏1小时
3. 黄油切片，擀成薄片
4. 面团擀开包入黄油
5. 三折，冷藏30分钟
6. 重复3次（共3次三折）

### 2. 烘烤派皮
1. 擀成3mm厚，切成三份
2. 扎孔，防止鼓起
3. 200°C烤约20分钟至金黄
4. 冷却后备用

### 3. 制作香草奶油
1. 蛋黄和糖搅拌至淡黄色
2. 加入玉米淀粉拌匀
3. 牛奶加热至沸腾，慢慢倒入
4. 倒回锅中，小火搅拌至浓稠
5. 加入香草精，冷藏备用
6. 淡奶油打发后拌入

### 4. 组装
1. 一层派皮抹奶油
2. 重复铺完三层
3. 表面撒糖粉
4. 切块后淋巧克力酱

## 烹饪技巧

1. **黄油状态**：全程保持冷藏，烤出来才酥脆
2. **折叠次数**：每次折叠必须冷藏，否则会混酥
3. **扎孔重要**：防止烤时鼓起
4. **当天食用**：派皮会吸收奶油变软
