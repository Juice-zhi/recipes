# 番薯糖水

## 简介

番薯糖水是广东传统糖水，绵密的番薯搭配清甜的糖水，简单却温暖，是老广记忆中的味道。

## 所需食材

- 番薯 300克（红心番薯）
- 冰片糖 或 红糖 80克
- 清水 1000毫升
- 姜 2片（可选）

## 步骤

### 1. 处理番薯
1. 番薯洗净去皮
2. 切成滚刀块
3. 用清水冲洗去表面淀粉

### 2. 煮制
1. 锅中放入番薯和清水
2. 大火煮开后转中火
3. 煮约15分钟至番薯软烂

### 3. 加糖
1. 加入冰片糖或红糖
2. 搅拌至融化
3. 继续煮5分钟

### 4. 完成
1. 番薯和糖水融合
2. 姜可在开始时加入
3. 热食或冷食皆可

## 烹饪技巧

1. **番薯选择**：红心番薯更甜更绵密
2. **冲洗淀粉**：洗去淀粉汤更清
3. **火候掌握**：煮到番薯软但不散
4. **糖的选择**：冰片糖清甜，红糖浓郁
5. **姜的作用**：驱寒增香，可根据喜好添加
