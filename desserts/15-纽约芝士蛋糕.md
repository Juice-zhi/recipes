# 纽约芝士蛋糕

## 简介

纽约芝士蛋糕是芝士蛋糕中的经典，以其浓郁醇厚的口感和细腻绵密的质地著称，是美国最受欢迎的甜点之一。

## 所需食材

### 饼底
- 全麦饼干 150克
- 黄油 60克（融化）
- 细砂糖 20克

### 蛋糕体
- 奶油奶酪 900克（室温）
- 细砂糖 200克
- 鸡蛋 5个（室温）
- 柠檬皮屑 1个
- 柠檬汁 30毫升
- 香草精 2茶匙
- 酸奶油 200克
- 低筋面粉 30克

## 步骤

### 1. 准备饼底
1. 饼干放入保鲜袋压碎
2. 加入融化的黄油和糖拌匀
3. 铺在25cm圆模底部，压实
4. 冷藏30分钟

### 2. 制作奶酪糊
1. 奶油奶酪室温软化
2. 加糖打至顺滑无颗粒
3. 逐个加入鸡蛋，每次搅拌均匀
4. 加入柠檬皮屑、柠檬汁和香草精
5. 筛入面粉拌匀
6. 加入酸奶油拌匀

### 3. 烘烤
1. 奶酪糊倒入模具中
2. 烤箱预热160°C
3. 水浴法烘烤约70-80分钟
4. 边缘凝固，中间微颤即可
5. 关闭烤箱，焖1小时

### 4. 冷却
1. 取出后在烤箱门缝中冷却1小时
2. 取出后再冷却至室温
3. 冷藏至少4小时或过夜

## 烹饪技巧

1. **奶酪软化**：必须室温软化，否则会颗粒感
2. **水浴法**：防止表面开裂的关键
3. **判断熟度**：中间微颤是正常的，冷却后会凝固
4. **脱模技巧**：热毛巾捂或吹风机加热边缘
