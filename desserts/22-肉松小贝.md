# 肉松小贝

## 简介

肉松小贝是近年来流行的网红甜点，两片柔软的蛋糕夹着丰富的沙拉酱和肉松，口感丰富，咸甜适中。既有蛋糕的柔软，又有肉松的香脆，是下午茶的绝佳选择。

## 所需食材

### 蛋糕胚
- 鸡蛋 4个
- 低筋面粉 60克
- 细砂糖 50克（蛋白）
- 细砂糖 20克（蛋黄）
- 牛奶 40毫升
- 植物油 40毫升
- 柠檬汁 少许

### 夹馅与装饰
- 沙拉酱 150克
- 肉松 100克
- 海苔碎 20克

## 步骤

### 1. 制作蛋糕胚
1. 蛋白蛋黄分离
2. 蛋黄加20克糖打至颜色变浅
3. 加入牛奶和植物油拌匀
4. 筛入面粉拌至无颗粒
5. 蛋白加柠檬汁，分三次加糖打发
6. 取1/3蛋白霜与蛋黄糊翻拌
7. 倒回剩余蛋白霜中翻拌

### 2. 烘烤
1. 烤箱预热170°C
2. 将面糊倒入铺好烘焙纸的烤盘
3. 抹平表面
4. 烤约15分钟
5. 取出冷却

### 3. 切割
1. 用圆形模具切出蛋糕片
2. 两片为一组

### 4. 组装
1. 一片蛋糕抹上沙拉酱
2. 盖上另一片蛋糕
3. 表面和边缘都抹上沙拉酱
4. 滚在肉松和海苔碎中
5. 均匀裹满

## 烹饪技巧

1. **蛋糕细腻**：蛋白打发到位，蛋黄糊翻拌轻柔
2. **沙拉酱选择**：丘比沙拉酱口感较好
3. **肉松选择**：使用即食肉松，比较松散
4. **现做现吃**：肉松吸收沙拉酱后会变软
5. **防潮处理**：可在肉松中加少许糖粉防潮
