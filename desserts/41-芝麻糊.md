# 芝麻糊

## 简介

芝麻糊是传统的养颜甜品，黑芝麻富含钙质和维生素，研磨成糊后香浓顺滑，是早餐或下午茶的滋补选择。

## 所需食材

- 黑芝麻 100克
- 糯米 30克
- 冰糖 50克
- 清水 800毫升

## 步骤

### 1. 炒香芝麻
1. 芝麻洗净晾干
2. 放入锅中，小火炒香
3. 炒至芝麻发出香味，颜色微黄
4. 冷却备用

### 2. 炒糯米
1. 糯米洗净晾干
2. 同样小火炒至微黄

### 3. 打磨
1. 芝麻和糯米放入料理机
2. 加适量水打磨成细腻的糊
3. 需要多打几次

### 4. 煮制
1. 将芝麻糊倒入锅中
2. 加入剩余的水
3. 加入冰糖
4. 小火不断搅拌
5. 煮至浓稠

### 5. 完成
1. 煮到顺滑无颗粒
2. 表面起小泡即可
3. 可撒少许芝麻装饰

## 烹饪技巧

1. **炒芝麻火候**：小火慢炒，糊了会苦
2. **糯米作用**：增加顺滑度和浓稠度
3. **打磨细腻**：多打几次口感才顺滑
4. **煮要搅拌**：防止糊底
5. **浓稠度**：根据个人喜好调整
