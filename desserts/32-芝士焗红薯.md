# 芝士焗红薯

## 简介

芝士焗红薯是一道简单美味的甜点，绵密的红薯泥配上香浓的芝士，烤至表面金黄。香甜软糯，奶香浓郁，是秋冬季节的暖心甜点。

## 所需食材

- 红薯 2个（约500克）
- 细砂糖 30克
- 黄油 30克
- 牛奶 50毫升
- 鸡蛋黄 1个
- 马苏里拉芝士 80克
- 柠檬汁## 步骤

### 1. 烤红薯
 少许

1. 红薯洗净，用锡纸包好
2. 烤箱预热200°C
3. 放入红薯
4. 烤约40分钟至软透
5. 取出放凉

### 2. 处理红薯
1. 红薯对半切开
2. 用勺子挖出红薯肉
3. 皮留用作为容器
4. 红薯肉放入碗中

### 3. 制作红薯泥
1. 红薯肉趁热加入黄油
2. 加入糖和柠檬汁
3. 加入牛奶
4. 搅拌成顺滑的泥
5. 如果太干可以加牛奶调整

### 4. 装入容器
1. 将红薯泥放回红薯皮中
2. 或者放入烤碗中
3. 表面撒上马苏里拉芝士
4. 刷上一层蛋黄液

### 5. 焗烤
1. 烤箱预热180°C
2. 放入红薯
3. 烤约15分钟
4. 表面金黄芝士融化即可

## 烹饪技巧

1. **红薯选择**：选用蜜薯或烟薯，糖分高更甜
2. **判断熟透**：用筷子能轻松插入即可
3. **芝士选择**：马苏里拉拉丝效果好
4. **蛋黄液**：刷蛋黄液颜色更好看
5. **趁热食用**：热吃芝士可以拉丝
