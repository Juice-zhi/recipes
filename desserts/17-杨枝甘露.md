# 杨枝甘露

## 简介

杨枝甘露是香港利苑酒楼的招牌甜点，寓意"观音用杨枝和甘露"，是一款清甜爽口的热带风味甜品。芒果的香甜、椰奶的浓郁、西柚的微苦完美融合，是广式糖水的经典之作。

## 所需食材

### 主料
- 芒果 2个（约400克果肉）
- 西柚 1个
- 西米 50克
- 椰浆 100毫升
- 淡奶 50毫升
- 细砂糖 30克
- 薄荷叶 少许（装饰）

## 步骤

### 1. 煮西米
1. 烧一锅水，水开后下西米
2. 煮约10分钟，期间不断搅拌
3. 西米中间还有小白点时关火
4. 盖上锅盖焖10分钟
5. 至完全透明
6. 捞出用冷水冲洗，沥干水分

### 2. 处理水果
1. 芒果去皮切块
2. 取200克芒果肉搅成芒果泥
3. 其余切块备用
4. 西柚去皮取果肉
5. 小心去除白色膜衣

### 3. 制作芒果浆
1. 芒果泥中加入椰浆
2. 加入淡奶和细砂糖
3. 搅拌均匀
4. 放入冰箱冷藏1小时

### 4. 组合
1. 将冷藏好的芒果浆放入碗中
2. 加入西米拌匀
3. 摆上芒果块和西柚果肉
4. 装饰薄荷叶

## 烹饪技巧

1. **西米处理**：煮西米要沸水下锅，不断搅拌防止粘锅
2. **西柚选择**：红西柚颜色更美，味道微苦回甜
3. **芒果成熟度**：选择成熟度高的芒果，甜度高
4. **椰浆比例**：椰浆和淡奶的比例约为2:1
5. **提前准备**：芒果浆提前做好冷藏，风味更佳
