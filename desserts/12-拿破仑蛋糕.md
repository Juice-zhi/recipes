# 拿破仑蛋糕

## 简介

拿破仑蛋糕（Mille-feuille）是一款经典的法式甜点，层层酥脆的千层酥皮夹着细腻的卡仕达酱，层次分明，口感丰富。虽然制作过程需要一些耐心，但成品绝对值得等待。

## 所需食材

### 千层酥皮
- 低筋面粉 300克
- 黄油 250克（冷藏）
- 细砂糖 15克
- 盐 5克
- 冰水 150毫升
- 柠檬汁 少许

### 卡仕达酱
- 牛奶 500毫升
- 蛋黄 5个
- 细砂糖 100克
- 低筋面粉 40克
- 玉米淀粉 20克
- 黄油 50克
- 香草精 2茶匙

### 装饰
- 防潮糖粉 适量
- 新鲜水果 适量

## 步骤

### 1. 制作酥皮
1. 面粉、糖、盐混合，加水和成面团
2. 包保鲜膜冷藏30分钟
3. 将黄油切片，夹在两片保鲜膜间擀成方形
4. 将面团擀开，放上黄油
5. 折成三折，冷藏1小时
6. 重复擀开、折叠3次

### 2. 烘烤酥皮
1. 将酥皮擀成3毫米厚
2. 切成三等份
3. 戳上小孔，防止鼓起
4. 烤箱预热200°C
5. 放入酥皮，烤约15分钟
6. 至金黄酥脆，取出冷却

### 3. 制作卡仕达酱
1. 蛋黄和糖打至发白
2. 筛入面粉和淀粉拌匀
3. 牛奶加热至微沸
4. 慢慢倒入蛋黄中，边倒边搅拌
5. 倒回锅中，小火加热不断搅拌
6. 煮至浓稠，离火加入黄油和香草精
7. 冷却后使用

### 4. 组装蛋糕
1. 取一片酥皮放在盘子上
2. 抹上一层卡仕达酱
3. 盖上第二片酥皮
4. 重复上述步骤
5. 盖上第三片酥皮
6. 表面筛糖粉，装饰水果

## 烹饪技巧

1. **黄油状态**：保持黄油冷藏但可塑形的状态
2. **折叠次数**：每次折叠后都要冷藏，让面团休息
3. **擀制力度**：用力均匀，避免黄油挤出
4. **烤箱温度**：高温入炉让酥皮快速膨胀
5. **切割技巧**：用锋利的刀，切出整齐的边缘
