# 榴莲千层

## 简介

榴莲千层是东南亚地区的明星甜点，由多层薄薄的班戟皮和榴莲肉、淡奶油叠加而成。班戟皮柔软Q弹，榴莲肉香浓绵密，是榴莲爱好者的终极享受。

## 所需食材

### 班戟皮
- 鸡蛋 3个
- 牛奶 250毫升
- 低筋面粉 100克
- 糖粉 30克
- 黄油 20克
- 盐 少许

### 夹馅
- 淡奶油 300毫升
- 糖粉 30克
- 榴莲肉 200克

## 步骤

### 1. 制作班戟面糊
1. 鸡蛋打散，加入糖粉
2. 加入融化的黄油
3. 加入牛奶拌匀
4. 筛入面粉和盐
5. 搅拌至无颗粒
6. 过筛一次更细腻

### 2. 煎班戟皮
1. 平底不粘锅预热
2. 舀一勺面糊倒入锅中
3. 快速转动锅子让面糊铺满
4. 中火煎约30秒
5. 边缘微翘时翻面
6. 煎10秒后取出
7. 重复直至用完面糊
8. 冷却备用

### 3. 打发淡奶油
1. 淡奶油加糖粉
2. 打至八分发（挺立）

### 4. 榴莲处理
1. 榴莲肉去核
2. 用勺子压成泥

### 5. 组装千层
1. 一层班戟皮
2. 抹上一层淡奶油
3. 铺上一层榴莲肉
4. 重复叠加
5. 最后一层班戟皮朝下
6. 冷藏1小时定型

## 烹饪技巧

1. **面糊浓稠**：太稠皮厚，太稀皮薄，根据实际情况调整
2. **锅子温度**：锅太热皮会焦，不热皮会破
3. **榴莲选择**：选择成熟度高的榴莲，香气足
4. **叠加技巧**：每层要铺均匀
5. **刀要热切**：切之前把刀烫热，切面更整齐
