# 糖不甩

## 简介

糖不甩是广东传统甜点，名字来源于其黏糊糊的特性——糯米丸子挂在糖浆上甩不掉。外酥内糯的糯米丸子裹上香甜的红糖姜汁，是冬至和元宵节的传统美食。

## 所需食材

### 糯米丸子
- 糯米粉 150克
- 温水 120毫升
- 花生碎 50克
- 熟白芝麻 20克

### 糖浆
- 红糖 50克
- 清水 80毫升
- 姜 3片
- 桂花 少许（可选）

## 步骤

### 1. 制作糯米团
1. 糯米粉放入盆中
2. 慢慢加入温水
3. 揉成光滑柔软的面团
4. 如果太湿可以加粉，太干可以加水

### 2. 搓丸子
1. 将面团搓成长条
2. 切成约15克的小剂子
3. 搓成圆形
4. 表面可以裹一层干糯米粉防粘

### 3. 煮丸子
1. 烧一锅水，水开后下丸子
2. 煮至丸子浮起
3. 继续煮2分钟
4. 捞出沥干水分

### 4. 制作糖浆
1. 红糖、清水、姜片放入锅中
2. 小火煮至糖融化
3. 煮至糖浆略微浓稠
4. 过滤掉姜片

### 5. 裹糖浆
1. 将煮好的丸子放入糖浆中
2. 小火翻炒，让丸子均匀裹上糖浆
3. 撒上花生碎和芝麻
4. 出锅装盘

## 烹饪技巧

1. **糯米粉选择**：使用水磨糯米粉口感更细腻
2. **温水揉面**：温水可以让糯米团更有弹性
3. **丸子大小**：约15-20克一个，大小适中
4. **糖浆浓稠**：太稀挂不住，太稠会过硬
5. **花生碎炒香**：花生碎提前炒香风味更佳
