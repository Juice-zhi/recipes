# 沙琪玛

## 简介

沙琪玛是满族的传统点心，也是清代宫庭点心之一。口感酥脆甜蜜，入口即化，是春节和婚礼等喜庆场合的必备糖果。虽然制作需要油炸，但成功率很高。

## 所需食材

### 面团
- 中筋面粉 200克
- 鸡蛋 2个
- 泡打粉 3克
- 清水 30毫升

### 糖浆
- 细砂糖 150克
- 麦芽糖 100克
- 清水 60毫升

### 配料
- 熟白芝麻 30克
- 炸油 适量

## 步骤

### 1. 制作面团
1. 面粉和泡打粉混合过筛
2. 鸡蛋打散，加入面粉中
3. 揉成光滑的面团
4. 如果太干可以加水
5. 静置15分钟

### 2. 擀制与切条
1. 将面团擀成约3毫米厚
2. 撒上干面粉防粘
3. 切成约5厘米长、1厘米宽的条
4. 抖散防止粘连

### 3. 油炸
1. 锅中油烧至160°C
2. 放入面条
3. 炸至金黄酥脆
4. 捞出沥油

### 4. 熬糖浆
1. 糖、麦芽糖和清水放入锅中
2. 小火加热
3. 熬至约115°C（略稠）
4. 可以用筷子蘸糖浆滴入冷水中测试

### 5. 混合与整形
1. 快速放入炸好的面条
2. 撒入芝麻
3. 快速翻拌让面条均匀裹上糖浆
4. 放入抹油的模具中
5. 压实压平

### 6. 冷却切块
1. 冷却至温热时切块
2. 完全冷却后更酥脆

## 烹饪技巧

1. **面团湿度**：面团要稍软，但不能粘手
2. **炸制温度**：油温不能太高，否则外焦里生
3. **糖浆温度**：115°C左右最适合，太稀会硬，太稠会苦
4. **动作要快**：糖浆冷却会凝固
5. **保存方法**：密封保存，防止受潮
