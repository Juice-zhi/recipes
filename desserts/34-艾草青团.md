# 艾草青团

## 简介

青团是江南地区清明节的传统点心，用艾草汁制作，呈青绿色，包裹着红豆沙，淡淡的艾草清香。

## 所需食材

- 糯米粉 200克
- 粘米粉 30克
- 艾草汁 180毫升
- 细砂糖 30克
- 猪油 15克
- 红豆沙 200克

### 艾草汁
- 新鲜艾草 150克
- 碱水 少许（保持绿色）
- 清水 300毫升

## 步骤

### 1. 制作艾草汁
1. 艾草洗净，去掉老茎
2. 锅中水开加少许碱水
3. 放入艾草焯水
4. 捞出放入料理机
5. 加水打成汁

### 2. 和面团
1. 糯米粉和粘米粉、糖混合
2. 加入艾草汁
3. 加入猪油
4. 揉成光滑面团

### 3. 包制
1. 面团分成小球
2. 红豆沙也分成小球
3. 面团压扁包入红豆沙
4. 收口搓圆

### 4. 蒸制
1. 蒸笼铺湿布
2. 放入青团
3. 大火蒸约10分钟
4. 出锅后刷一层油防粘

## 烹饪技巧

1. **艾草选择**：清明前后的艾草最嫩
2. **碱水作用**：保持艾草翠绿色
3. **面团软硬**：软硬适中，太软会塌陷
4. **蒸制时间**：时间短不熟，时间长会塌
5. **保存**：冷却后密封，防止变硬
