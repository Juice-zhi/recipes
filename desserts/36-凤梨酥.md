# 凤梨酥

## 简介

凤梨酥是台湾最著名的伴手礼，酥脆的外皮包裹着酸甜的凤梨馅，寓意\"旺来\"，是馈赠亲友的吉祥礼物。

## 所需食材

### 凤梨馅
- 新鲜凤梨 1个（约1000克）
- 细砂糖 100克
- 麦芽糖 50克
- 柠檬汁 1个量

### 酥皮
- 低筋面粉 200克
- 奶粉 20克
- 鸡蛋 1个
- 糖粉 40克
- 黄油 120克
- 盐 1克

## 步骤

### 1. 制作凤梨馅
1. 凤梨去皮切块
2. 用料理机打碎
3. 放入锅中加入糖
4. 小火不断翻炒
5. 加入麦芽糖和柠檬汁
6. 炒至水分蒸发，颜色变深
7. 冷却后分成小份

### 2. 制作酥皮
1. 黄油软化加糖粉打至发白
2. 加入鸡蛋继续搅拌
3. 筛入面粉、奶粉和盐
4. 揉成团，冷藏30分钟

### 3. 包制
1. 酥皮分成小份
2. 压扁包入凤梨馅
3. 放入模具中压平
4. 脱模

### 4. 烘烤
1. 烤箱预热170°C
2. 放入凤梨酥
3. 烘烤约15分钟
4. 表面金黄即可

## 烹饪技巧

1. **凤梨选择**：台农17号金钻凤梨最佳
2. **炒馅耐心**：小火不断翻炒，防止糊锅
3. **皮馅比例**：2:1或3:1均可
4. **模具选择**：可用专用凤梨酥模具
5. **保存**：密封保存可放两周
