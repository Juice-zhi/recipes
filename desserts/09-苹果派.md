# 苹果派

## 简介

苹果派（Apple Pie）是一款经典的美式甜点，外层酥脆的派皮包裹着酸甜可口的苹果馅料，是感恩节和圣诞节必备的节日甜点。热腾腾的苹果派配上一球香草冰淇淋，是最经典的享受方式。

## 所需食材

### 派皮
- 低筋面粉 300克
- 黄油 150克（冷藏）
- 细砂糖 30克
- 盐 3克
- 冰水 60毫升
- 蛋黄 1个（刷表面）

### 苹果馅
- 苹果 600克（推荐 Granny Smith）
- 细砂糖 80克
- 肉桂粉 1茶匙
- 柠檬汁 15毫升
- 玉米淀粉 15克
- 黄油 20克
- 香草精 1茶匙

## 步骤

### 1. 制作派皮
1. 将面粉、糖和盐混合
2. 加入冷藏的黄油块
3. 用手指捏成粗玉米粉状
4. 加入冰水揉成面团
5. 包保鲜膜冷藏1小时

### 2. 制作苹果馅
1. 苹果去皮去核，切成薄片
2. 加入糖、肉桂粉、柠檬汁拌匀
3. 静置30分钟出水
4. 滤掉多余水分
5. 加入玉米淀粉和香草精拌匀

### 3. 擀派皮
1. 将面团分成两份
2. 擀成3毫米厚的大圆片
3. 一份铺在派盘中
4. 边缘多余部分切掉

### 4. 填入馅料
1. 将苹果馅铺入派皮中
2. 放上小块黄油
3. 盖上另一张派皮
4. 边缘捏紧并切出花边
5. 表面刷蛋黄液，切几道缝隙透气

### 5. 烘烤
1. 烤箱预热220°C
2. 放入派，中层
3. 15分钟后降至180°C
4. 再烤约35分钟至表面金黄
5. 派汁沸腾表示内部已熟

## 烹饪技巧

1. **黄油温度**：保持黄油冷藏状态，烤出的派皮才酥脆
2. **苹果选择**：酸苹果如 Granny Smith 搭配甜馅料口味更平衡
3. **派皮松弛**：冷藏后的派皮更容易擀开，不回缩
4. **防止馅料溢出**：确保派皮边缘高出馅料
5. **判断熟透**：苹果软烂、汁液浓稠即可
