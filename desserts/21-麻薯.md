# 麻薯

## 简介

麻薯（Mochi）是一种源自日本的糯米点心，外皮Q弹软糯，可包入各种馅料，如红豆沙、芝麻、花生等。烘烤后的麻薯外皮酥脆，内里柔软拉丝，深受年轻人喜爱。

## 所需食材

### 麻薯皮
- 糯米粉 100克
- 玉米淀粉 30克
- 细砂糖 40克
- 牛奶 120毫升
- 黄油 15克
- 食用色素 少许（可选）

### 馅料
- 红豆沙 200克
- 芝麻馅 100克
- 肉松 适量

## 步骤

### 1. 制作麻薯面团
1. 糯米粉、玉米淀粉、糖混合
2. 加入牛奶搅拌成无颗粒的糊
3. 盖上保鲜膜，扎几个小孔
4. 蒸锅水开后放入
5. 蒸约20分钟至完全熟透

### 2. 加入黄油
1. 蒸熟后取出
2. 趁热加入黄油
3. 用刮刀搅拌
4. 稍凉后用手揉成光滑面团

### 3. 包馅
1. 将面团分成小块
2. 擀成圆皮
3. 包入馅料
4. 收口捏紧
5. 搓圆

### 4. 烘烤（可选）
1. 烤箱预热180°C
2. 麻薯表面刷水
3. 放入烤箱
4. 烘烤约10分钟至表面微黄
5. 取出刷上酱油或味淋
6. 再烤5分钟

### 5. 完成
1. 冷却后即可食用
2. 可撒上黄豆粉或海苔碎

## 烹饪技巧

1. **蒸制时间**：确保完全蒸熟，否则口感会粘牙
2. **黄油加入**：趁热加入黄油更容易揉匀
3. **防粘技巧**：操作时手上抹油或沾熟糯米粉
4. **馅料选择**：可以根据喜好选择任何馅料
5. **保存方法**：密封保存，冷藏后口感更Q弹
