# 艾草青团

## 简介

青团是江南地区清明时节的传统点心，以艾草汁调入糯米粉制成碧绿的外皮，包裹着香甜的豆沙馅。软糯Q弹，艾草清香，是季节限定的传统美味。

## 所需食材

### 青团皮
- 糯米粉 200克
- 艾草粉 15克（或新鲜艾草150克）
- 细砂糖 40克
- 温水 150毫升
- 植物油 15克
- 澄粉 60克（开水烫熟）

### 馅料
- 红豆沙 300克

## 步骤

### 1. 制作艾草汁
1. 艾草洗净，去掉硬梗
2. 放入开水中焯烫
3. 捞出放入冷水中
4. 挤干水分，加水打成泥
5. 取艾草汁使用

### 2. 制作面团
1. 糯米粉、糖、艾草汁混合
2. 加入植物油
3. 揉成绿色面团
4. 澄粉用开水烫熟
5. 揉入糯米团中
6. 面团更Q弹

### 3. 包制
1. 红豆沙分成约30克一个
2. 青团皮分成约40克一个
3. 面团按扁，包入豆沙
4. 收口捏紧
5. 搓圆

### 4. 蒸制
1. 蒸锅铺上蒸笼纸
2. 放入青团
3. 水开后蒸约10分钟
4. 表面刷油防粘

## 烹饪技巧

1. **艾草选择**：新鲜艾草或艾草粉都可以
2. **澄粉加入**：让青团更Q弹，不粘牙
3. **面团软硬**：软硬适中，太软会塌
4. **蒸制时间**：不要蒸太久，会塌陷
5. **保存方法**：密封保存，冷藏后蒸热食用
