# 桂花糕

## 简介

桂花糕是江南地区的传统甜点，以糯米粉和糖桂花为主料，口感软糯香甜，桂花的清香令人回味无穷。历史可追溯到明朝，是秋季赏桂时节的时令美食。

## 所需食材

- 糯米粉 150克
- 粘米粉 50克
- 细砂糖 60克
- 清水 150毫升
- 糖桂花 30克
- 食用油 少许（抹模具）
- 干桂花 少许（装饰）

## 步骤

### 1. 混合粉类
1. 将糯米粉和粘米粉放入盆中
2. 加入细砂糖混合均匀
3. 慢慢加入清水
4. 用手揉搓成松散的粉团
5. 用筛子过筛两次，更细腻

### 2. 加入桂花
1. 将过筛后的粉铺在蒸盘上
2. 轻轻抹平表面
3. 均匀撒上糖桂花
4. 轻轻按压让桂花嵌入粉中

### 3. 蒸制
1. 蒸锅水开后放入
2. 盖上盖子
3. 大火蒸约30分钟
4. 至粉熟透呈透明状

### 4. 冷却切块
1. 取出放凉
2. 完全冷却后用刀切块
3. 表面撒干桂花装饰

## 烹饪技巧

1. **粉类选择**：糯米粉和粘米粉混合，口感更软糯不粘牙
2. **水量控制**：水要慢慢加，粉团呈松散状即可
3. **过筛重要**：过筛后的粉蒸出来更细腻
4. **蒸制时间**：根据厚度调整，确保完全熟透
5. **切块技巧**：完全冷却后再切，切面更整齐
