# 花生糖

## 简介

花生糖是传统的中式糖果，香甜酥脆，花生香味浓郁。逢年过节必备的糖果，也是很多人小时候的甜蜜回忆。制作简单，成功率高。

## 所需食材

- 花生米 300克
- 细砂糖 150克
- 麦芽糖 100克
- 清水 50毫升
- 炸油 适量

## 步骤

### 1. 炸花生
1. 花生米冷油下锅
2. 小火慢炸至金黄酥脆
3. 捞出沥油，放凉
4. 去皮后切碎

### 2. 熬糖浆
1. 糖、麦芽糖和清水放入锅中
2. 小火加热搅拌
3. 熬至约150°C（琥珀色）
4. 可以用筷子蘸糖浆滴入冷水中测试

### 3. 混合
1. 快速放入花生碎
2. 快速翻拌均匀

### 4. 整形
1. 放入抹油的模具中
2. 压实压平
3. 冷却至温热时切块

## 烹饪技巧

1. **花生炸制**：冷油下锅，小火慢炸
2. **糖浆温度**：150°C左右正好，太低会软，太高会苦
3. **动作要快**：糖浆冷却会凝固
4. **切块时机**：温热时好切，凉了就脆
5. **保存方法**：密封保存，防止受潮
