# 奥利奥芝士蛋糕

## 简介

奥利奥芝士蛋糕将经典的奥利奥饼干融入芝士蛋糕，甜而不腻，是年轻人的最爱。

## 所需食材

### 饼底
- 奥利奥饼干 200克
- 黄油 80克（融化）

### 芝士糊
- 奶油奶酪 450克
- 细砂糖 100克
- 鸡蛋 3个
- 淡奶油 100毫升
- 奥利奥碎 80克
- 香草精 1茶匙

## 步骤

### 1. 饼底
1. 奥利奥去夹心后压碎
2. 加入融化的黄油拌匀
3. 铺在模具底部压实
4. 冷藏30分钟

### 2. 芝士糊
1. 奶油奶酪加糖打顺滑
2. 逐个加鸡蛋
3. 加淡奶油和香草精
4. 加入奥利奥碎拌匀

### 3. 烘烤
1. 倒入模具
2. 160°C水浴烤约60分钟
3. 焖1小时
4. 冷藏4小时

## 烹饪技巧

1. **奥利奥选择**：原味奥利奥即可
2. **饼干碎大小**：保持颗粒感
3. **烤箱温度**：根据自家烤箱调整
