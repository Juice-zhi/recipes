# 水煮鱼

## 菜系/国家
川菜 / 中国四川

## 概述
水煮鱼是四川经典名菜，以草鱼为主料，用大量的辣椒和花椒煮制。鱼肉鲜嫩，麻辣鲜香，是川菜中非常受欢迎的硬菜。

## 份量/人数
4人份

## 所需餐具
- 炒锅
- 汤锅
- 盘子

## 食材清单

### 主料
- 草鱼：1条（约750克）
- 豆芽：200克

### 鱼片腌料
- 盐：5克
- 料酒：15ml
- 淀粉：15克
- 蛋清：1个

### 调料
- 干辣椒：50克
- 花椒：30克
- 郫县豆瓣酱：60克
- 姜：20克
- 蒜：20克
- 葱：30克

### 汤底
- 高汤或清水：1500ml

### 油料
- 食用油：150ml

## 详细步骤

### 步骤1：处理鱼
**正在做什么：** 将草鱼片成鱼片。

**食材当前状态：** 草鱼是整条的。

**操作要点：**
1. 草鱼去鳞、去内脏
2. 片下两侧鱼肉
3. 鱼骨剁成块
4. 鱼肉片成薄片

**注意事项：** 鱼片要切得厚薄均匀。

### 步骤2：腌制鱼片
**正在做什么：** 将鱼片腌制入味。

**食材当前状态：** 鱼片已片好。

**操作要点：**
1. 鱼片放入碗中
2. 加盐抓匀
3. 加入料酒、蛋清
4. 加入淀粉抓匀
5. 腌制15分钟

**注意事项：** 淀粉可以让鱼片更嫩滑。

### 步骤3：处理配料
**正在做什么：** 将辣椒和花椒准备好。

**食材当前状态：** 辣椒和花椒是干的。

**操作要点：**
1. 干辣椒切段
2. 去掉辣椒籽
3. 姜蒜切片
4. 葱切段

**注意事项：** 辣椒籽要去掉，否则会太辣。

### 步骤4：炒制底料
**正在做什么：** 炒制豆瓣酱等调料。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 锅中倒油
2. 放入姜蒜片炒香
3. 放入豆瓣酱
4. 小火炒出红油
5. 加入高汤

**注意事项：** 豆瓣酱要炒出红油。

### 步骤5：煮豆芽
**正在做什么：** 将豆芽煮熟垫底。

**食材当前状态：** 豆芽是生的。

**操作要点：**
1. 汤烧开
2. 放入豆芽
3. 煮2分钟
4. 捞出放入碗中

**注意事项：** 豆芽不要煮太久，保持脆爽。

### 步骤6：煮鱼片
**正在做什么：** 将鱼片放入汤中煮熟。

**食材当前状态：** 鱼片已腌制好。

**操作要点：**
1. 汤烧开后关火
2. 放入鱼片
3. 轻轻推动
4. 鱼片变色后捞出
5. 放入装有豆芽的碗中
6. 浇上汤汁

**注意事项：** 鱼片不要煮太久。

### 步骤7：浇油
**正在做什么：** 最后浇上大量热油。

**食材当前状态：** 鱼片已煮好。

**操作要点：**
1. 鱼片上放上干辣椒段和花椒
2. 锅中烧热油至冒烟
3. 浇在辣椒和花椒上
4. 发出"滋啦"声，香气四溢

**注意事项：** 油要足够热。

## 烹饪关键点/小贴士

1. **辣椒和花椒**：用量要足够多，这是水煮鱼的灵魂。
2. **火候**：煮鱼片要关火，保持鱼的嫩滑。
3. **油温**：浇的油要烧到冒烟，才能激发出香味。
4. **豆瓣酱**：要选正宗的郫县豆瓣酱。
