# 叫化鸡

## 菜系/国家
苏菜 / 中国江苏

## 概述
叫化鸡是江苏常熟的传统名菜，相传由叫化子发明。这道菜以童子鸡为主料，用荷叶和泥土包裹后烤制，鸡肉酥软，香气扑鼻，是古代武侠小说中经常出现的美食。

## 份量/人数
4人份

## 所需餐具
- 烤箱或炭火
- 锡纸
- 荷叶（可用保鲜膜代替）
- 泥土（可选，黄泥）

## 食材清单

### 主料
- 童子鸡：1只（约750克）

### 腌料
- 生抽：30ml
- 老抽：15ml
- 料酒：30ml
- 盐：10克
- 糖：10克
- 五香粉：5克

### 辅料
- 姜：20克（切片）
- 葱：30克（切段）
- 蒜：15克（整瓣）
- 香菇：50克（泡发，切块）
- 栗子：50克（去壳）
- 火腿：50克（切块）

### 包裹材料
- 荷叶：1-2张
- 锡纸：适量
- 黄泥：500克（可选）

## 详细步骤

### 步骤1：处理鸡
**正在做什么：** 将鸡处理干净。

**操作要点：**
1. 童子鸡洗净
2. 去掉内脏
3. 彻底清洗干净
4. 沥干水分
5. 用厨房纸吸干表面

**注意事项：** 鸡要彻底清洗干净。最好选用童子鸡，肉质细嫩。

### 步骤2：腌制
**正在做什么：** 将鸡腌制入味。

**操作要点：**
1. 鸡身内外均匀抹上盐
2. 放入生抽、老抽、料酒
3. 撒上糖和五香粉
4. 放入姜片、葱段、蒜瓣
5. 用手按摩鸡身
6. 腌制2-3小时
7. 中间翻动几次

**注意事项：** 腌制时间要够，让味道渗透到鸡肉里。

### 步骤3：填料
**正在做什么：** 在鸡肚子内填入辅料。

**操作要点：**
1. 腌制好的鸡取出
2. 在鸡肚子内放入香菇
3. 放入栗子
4. 放入火腿
5. 再放入一些姜片、葱段

**注意事项：** 填料不要太多，太多鸡不容易熟。

### 步骤4：包裹
**正在做什么：** 用荷叶包裹鸡。

**操作要点：**
1. 荷叶提前泡软
2. 沥干水分
3. 将鸡放在荷叶上
4. 用荷叶将鸡包裹起来
5. 再包上一层锡纸
6. 如果有黄泥，可以裹上黄泥

**注意事项：** 荷叶要包裹紧实，不要让调料漏出。包两层更保险。

### 步骤5：烤制
**正在做什么：** 将鸡烤熟。

**操作要点：**
1. 烤箱预热至200°C
2. 放入包裹好的鸡
3. 先烤30分钟
4. 降温至150°C
5. 继续烤1.5-2小时
6. 如果用炭火，要烤3-4小时

**注意事项：** 烤的时间要够，鸡肉才能酥烂。温度要先高后低。

### 步骤6：上桌
**正在做什么：** 叫化鸡完成。

**操作要点：**
1. 取出烤好的鸡
2. 去掉外面的包裹物
3. 鸡肉香气扑鼻
4. 直接用手撕开食用
5. 配上调料

**注意事项：** 叫化鸡要趁热吃，鸡肉非常酥软。可以用手直接撕开。

## 烹饪关键点/小贴士

1. **鸡的选择**：要用童子鸡，肉质细嫩。老鸡不容易酥烂。

2. **腌制**：腌制时间要够，至少2-3小时。让味道充分渗透。

3. **荷叶**：荷叶是叫化鸡的特色，增添了荷叶的清香。没有荷叶可以用锡纸。

4. **烤制**：烤的时间要够，鸡肉才能酥烂。先高火后低火。

5. **传统做法**：传统做法是用黄泥包裹，在炭火中烤制。现代可以用烤箱。

6. **食用方法**：叫化鸡要用手直接撕开吃，这样更有气氛。

## 营养信息

- 热量：约300-350千卡（每份）
- 蛋白质：约30克
- 脂肪：约20克
- 碳水化合物：约10克

### 营养亮点
- 童子鸡富含优质蛋白质
- 配料增加了营养
- 荷叶有清热解暑的功效
