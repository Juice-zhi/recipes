# 味增汤

## 菜系/国家
日本料理 / 日本

## 概述
味增汤是日本最具代表性的传统汤品，以味增酱为主要调料，加入豆腐、海藻、蔬菜等配料制成。味道鲜美，营养丰富，是日本料理中不可或缺的经典。

## 份量/人数
2-3人份

## 所需餐具
- 汤锅
- 碗

## 食材清单

### 主料
- 嫩豆腐：150克
- 海带（昆布）：5克

### 调料
- 味增酱：50克
- 鲣鱼干（柴鱼片）：5克

### 辅料
- 葱：20克
- 蘑菇：50克

## 详细步骤

### 步骤1：准备高汤
**正在做什么：** 制作昆布高汤。

**食材当前状态：** 昆布是干燥的硬片。

**操作要点：**
1. 昆布用湿布擦拭干净
2. 放入锅中，加水800ml
3. 小火慢煮，不要煮沸
4. 煮约10分钟后取出昆布
5. 加入鲣鱼干，煮1分钟后过滤

**注意事项：** 昆布不要煮沸，否则会有腥味。

### 步骤2：处理配料
**正在做什么：** 将豆腐切块，蘑菇切片。

**食材当前状态：** 豆腐是整块，蘑菇是完整的。

**操作要点：**
1. 豆腐切成1厘米见方的小块
2. 蘑菇洗净切片
3. 葱切碎

**注意事项：** 豆腐要切得大小均匀。

### 步骤3：加入配料
**正在做什么：** 将配料放入高汤中煮。

**食材当前状态：** 高汤已做好，配料已切好。

**操作要点：**
1. 高汤重新烧开
2. 放入豆腐块
3. 放入蘑菇片
4. 煮约2分钟

**注意事项：** 不要让汤沸腾，保持微开。

### 步骤4：加入味增
**正在做什么：** 将味增酱溶入汤中。

**食材当前状态：** 配料已煮熟，汤在微开状态。

**操作要点：**
1. 味增酱放入碗中
2. 加入少许汤汁调开
3. 慢慢倒入锅中，边倒边搅
4. 立即关火，不要煮沸

**注意事项：** 味增不能煮沸，否则会失去风味。

### 步骤5：装盘
**正在做什么：** 将味增汤盛入碗中。

**食材当前状态：** 汤已调好味道。

**操作要点：**
1. 盛入碗中
2. 撒上葱花
3. 可加少许七味粉

**注意事项：** 味增汤要趁热喝。

## 烹饪关键点/小贴士

1. **昆布**：昆布是高汤的关键，要选择质量好的。
2. **味增**：不同品牌味增味道不同，可根据喜好选择。
3. **火候**：味增不能煮沸，否则会变酸。
4. **配料**：可添加各种喜欢的配料，如魔芋丝、油豆腐等。
