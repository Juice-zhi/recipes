# 红烧肉

## 菜系/国家
浙菜/苏菜 / 中国江浙地区

## 概述
红烧肉是中国最具代表性的家常菜之一，历史悠久，起源于宋代。这道菜以五花肉为主料，经过慢火炖煮，呈现出色泽红亮、肥而不腻、入口即化的特点。苏东坡对其尤为喜爱，有"东坡肉"之美誉。

## 份量/人数
4-5人份

## 所需餐具
- 砂锅或炖锅（最佳选择）
- 炒锅（用于炒糖色）
- 锅铲
- 漏勺
- 细筛子（过滤汤汁）
- 盘子（盛装成品）

## 食材清单

### 主料
- 五花肉：600克（建议选用带皮的猪五花肉）

### 调料
- 冰糖：40克（约4大勺）
- 生抽（酱油）：40ml（约4大勺）
- 老抽：20ml（约2大勺）
- 料酒：30ml（约3大勺）
- 食盐：5克（约1小勺）
- 八角：2个
- 桂皮：1小块（约5克）
- 香叶：2片
- 草果：1个（可选）
- 干辣椒：2个（可选）

### 辅料
- 大葱：30克（1根，切段）
- 姜：20克（4-5片）
- 蒜：15克（3-4瓣，整颗即可）

### 油料
- 食用油：20ml（1大勺）
- 清水：适量

## 详细步骤

### 步骤1：五花肉处理
**正在做什么：** 将五花肉切成约4厘米见方的大块，便于后续烹饪。

**食材当前状态：** 五花肉是一大块连皮的猪肉，肥瘦相间。

**操作要点：**
1. 将五花肉洗净，用厨房纸巾吸干表面水分
2. 先将五花肉切成约4厘米宽的长条
3. 再将长条切成约4厘米见方的块
4. 检查一下，确保每块肉都带皮
5. 切好的肉块放入盘中备用

**注意事项：** 肉块不要切得太小，炖煮后会收缩。太小的块炖出来口感不好。4厘米左右是最佳大小。

### 步骤2：五花肉焯水
**正在做什么：** 将五花肉块放入沸水中焯烫，去除血沫和腥味。

**食材当前状态：** 切好的肉块整齐地摆在盘中。

**操作要点：**
1. 锅中加入足够多的清水，能没过肉块
2. 放入五花肉块，加入料酒15ml
3. 大火烧开，观察血沫浮起
4. 用漏勺撇去浮沫，保持大火
5. 焯约3-5分钟，直到不再有血沫冒出
6. 捞出肉块，用温水洗净表面浮沫
7. 沥干水分备用

**注意事项：** 焯水时加料酒可以帮助去腥。捞出后用温水清洗，不要用冷水，肉质会变硬。

### 步骤3：炒糖色
**正在做什么：** 将冰糖炒成焦糖色，用于给红烧肉上色。

**食材当前状态：** 炒锅是干净的，冰糖是大颗粒的白色晶体。

**操作要点：**
1. 炒锅烧热，加入20ml食用油
2. 放入冰糖40克
3. 用中小火加热，不断用锅铲搅拌
4. 冰糖会逐渐融化，从白色变成淡黄色
5. 继续搅拌，糖色变成琥珀色
6. 当糖色变成深琥珀色，并开始冒小泡时
7. 迅速放入五花肉块，快速翻匀

**注意事项：** 炒糖色是最关键的步骤。火候要控制好，糖色炒太浅上色不够，炒太焦会发苦。糖色变深琥珀色时要立即下肉。

### 步骤4：翻炒上色
**正在做什么：** 将肉块与糖色翻炒均匀，使每块肉都裹上漂亮的颜色。

**食材当前状态：** 肉块已经下锅，表面还比较苍白。

**操作要点：**
1. 立即下入五花肉块
2. 快速翻炒，让每块肉都均匀裹上糖色
3. 炒至肉块表面呈现漂亮的红褐色
4. 加入生抽40ml和老抽20ml
5. 继续翻炒，让调料均匀分布
6. 炒约2-3分钟

**注意事项：** 翻炒要快，糖色很容易糊。加入酱油后也要快速翻匀。

### 步骤5：加入香料和辅料
**正在做什么：** 加入所有香料和辅料，准备炖煮。

**食材当前状态：** 肉块已经上色，呈红褐色。

**操作要点：**
1. 放入八角2个、桂皮1小块、香叶2片
2. 草果1个（如果使用）
3. 干辣椒2个（如果使用）
4. 放入葱段、姜片、蒜瓣
5. 翻炒一下，让香料出香味

**注意事项：** 香料可以根据个人口味调整。不喜欢药膳味可以少放桂皮和草果。

### 步骤6：炖煮
**正在做什么：** 加入足量的水，用小火慢炖。

**食材当前状态：** 所有材料已经在锅中，香气开始散发。

**操作要点：**
1. 加入足够的开水，水量没过肉块约2厘米
2. 大火烧开后，转最小火
3. 盖上锅盖，保持微沸状态
4. 炖煮约1.5-2小时
5. 中途可以翻动肉块一次，让味道更均匀

**注意事项：** 一定要加开水，不能加冷水，否则肉质会变硬。火候要小，保持微沸即可。大火会让肉块炖散。

### 步骤7：收汁
**正在做什么：** 大火收汁，使汤汁浓稠包裹肉块。

**食材当前状态：** 肉块已经软烂，汤汁还比较稀。

**操作要点：**
1. 炖至肉块软烂后，开大火
2. 不断用锅铲翻动肉块，防止粘底
3. 收汁约10-15分钟
4. 汤汁变得浓稠，裹在肉块表面
5. 根据口味加入食盐调味
6. 关火

**注意事项：** 收汁时要不断翻动，防止底部糊锅。盐要最后放，提前放会让肉质变柴。

### 步骤8：装盘
**正在做什么：** 将红烧肉装入盘中，可以撒上葱花装饰。

**食材当前状态：** 红烧肉已经完成，色泽红亮，油润光泽。

**操作要点：**
1. 先将香料（八角、桂皮等）挑出
2. 将肉块整齐地摆放在盘中
3. 淋上锅中的浓稠汤汁
4. 撒上少许葱花作装饰（可选）

**注意事项：** 装盘后要尽快食用，放凉后油脂会凝固，影响口感。

## 烹饪关键点/小贴士

1. **五花肉选择**：选用肥瘦相间的三层五花肉，带皮的最好。太瘦的肉炖出来柴，太肥的腻。

2. **炒糖色技巧**：这是红烧肉成败的关键。糖色炒得恰到好处，肉的颜色才会红亮。可以用冰糖或白糖，冰糖炒出来颜色更透亮。

3. **火候控制**：全程控制好火候。炒糖色时用中小火，炖煮时用最小火，收汁时用大火。

4. **水温注意**：焯水和炖煮都要用热水或开水，不能用冷水。冷水会让肉质变硬变柴。

5. **炖煮时间**：至少要炖1.5小时以上，肉才能软烂入味。时间越长越好吃，但要注意不要干锅。

6. **去腥方法**：料酒要在焯水时加入，能有效去腥。香料也有去腥增香的作用。

7. **保存技巧**：红烧肉放凉后可以冷藏保存3-5天。重新加热时可以加一些水或高汤。

## 营养信息

- 热量：约450-500千卡（每100克）
- 蛋白质：约20克
- 脂肪：约40克
- 碳水化合物：约10克

### 营养亮点
- 五花肉提供优质蛋白质和铁元素
- 适量食用可以补充维生素B族
- 胶原蛋白对皮肤有益
- 糖分提供快速能量
