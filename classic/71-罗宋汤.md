# 罗宋汤

## 菜系/国家
俄罗斯菜 / 俄罗斯

## 概述
罗宋汤是俄罗斯的经典浓汤，以牛肉、土豆、番茄、卷心菜等蔬菜炖煮而成。汤色红亮，酸甜可口，是俄罗斯最具代表性的菜肴之一。

## 份量/人数
6人份

## 所需餐具
- 汤锅
- 炒锅
- 刀
- 碗

## 食材清单

### 主料
- 牛肉：500克
- 土豆：300克
- 番茄：300克
- 卷心菜：300克
- 洋葱：150克
- 胡萝卜：150克
- 甜菜：200克

### 调料
- 黄油：50克
- 番茄酱：60克
- 柠檬汁：30ml
- 糖：20克
- 盐：适量
- 黑胡椒：适量
- 月桂叶：2片
- 香叶：适量

## 详细步骤

### 步骤1：处理牛肉
**正在做什么：** 将牛肉切块煮熟。

**食材当前状态：** 牛肉是整块的。

**操作要点：**
1. 牛肉切成3厘米的块
2. 放入锅中，加水煮沸
3. 撇去浮沫
4. 转小火炖1小时至软烂

**注意事项：** 牛肉要炖到软烂。

### 步骤2：炒香蔬菜
**正在做什么：** 将蔬菜炒香。

**食材当前状态：** 蔬菜都是完整的。

**操作要点：**
1. 洋葱、胡萝卜切块
2. 甜菜去皮切块
3. 锅中放入黄油
4. 融化后炒香洋葱和胡萝卜
5. 加入甜菜翻炒
6. 加入番茄酱炒匀

**注意事项：** 要把蔬菜炒透。

### 步骤3：加入番茄
**正在做什么：** 加入番茄。

**食材当前状态：** 番茄是完整的。

**操作要点：**
1. 番茄顶部划十字
2. 用开水烫后去皮
3. 切成块
4. 放入锅中翻炒

**注意事项：** 番茄要去皮。

### 步骤4：加入汤中
**正在做什么：** 将炒好的蔬菜放入牛肉汤中。

**食材当前状态：** 牛肉汤已炖好，蔬菜已炒好。

**操作要点：**
1. 将炒好的蔬菜放入牛肉汤中
2. 加入月桂叶
3. 继续炖30分钟

**注意事项：** 要让蔬菜和牛肉的味道融合。

### 步骤5：加入卷心菜和土豆
**正在做什么：** 加入卷心菜和土豆。

**食材当前状态：** 卷心菜和土豆都是完整的。

**操作要点：**
1. 卷心菜切块
2. 土豆去皮切块
3. 放入锅中
4. 继续炖15分钟至土豆软烂

**注意事项：** 土豆不要放太早，会煮烂。

### 步骤6：调味
**正在做什么：** 调味。

**食材当前状态：** 汤已快煮好。

**操作要点：**
1. 加入柠檬汁
2. 加入糖
3. 盐和黑胡椒调味
4. 试试味道，酸甜适中即可

**注意事项：** 罗宋汤的味道是酸甜的。

### 步骤7：完成
**正在做什么：** 装盘。

**食材当前状态：** 汤已调好味。

**操作要点：**
1. 盛入碗中
2. 可以撒上少许香菜
3. 配上酸奶油

**注意事项：** 罗宋汤要趁热喝。

## 烹饪关键点/小贴士

1. **甜菜**：甜菜是罗宋汤红色的来源，不可用其他蔬菜代替。
2. **番茄酱**：要选择质量好的番茄酱。
3. **酸甜**：酸甜比例要平衡，不要太酸或太甜。
4. **炖煮**：所有材料要炖到软烂，味道才融合。
