# 北京烤鸭

## 菜系/国家
京菜 / 中国北京

## 概述
北京烤鸭是中国最著名的名菜之一，起源于明朝，已有两百多年的历史。它以选用特定的鸭子、独特的烤制方法和片鸭技艺著称。烤好的鸭子皮脆肉嫩，色泽红润，配以甜面酱、葱段、黄瓜条，用薄饼卷食，肥而不腻，满口留香。

## 份量/人数
4-6人份

## 所需餐具
- 烤箱或烤鸭炉
- 挂钩或烤叉
- 片鸭刀
- 甜面酱碗
- 葱段、黄瓜条盘
- 薄饼（春饼或烤鸭饼）
- 白糖碟

## 食材清单

### 主料
- 北京填鸭：1只（约2-2.5公斤）

### 调料
- 麦芽糖（或饴糖）：50克
- 蜂蜜：30克
- 白醋：30ml（2大勺）
- 料酒：30ml（2大勺）
- 食盐：10克（约2小勺）
- 五香粉：5克（1小勺）

### 脆皮水
- 麦芽糖：30克
- 白醋：30ml
- 蜂蜜：15ml
- 清水：100ml

### 配料
- 甜面酱：100克（约6大勺）
- 大葱：100克（2根，切成约5厘米的段）
- 黄瓜：150克（1根，切成约5厘米的条）
- 白糖：30克（2大勺，用于蘸食）
- 薄饼：20-30张
- 蒜泥：15克（3瓣，切成末）

## 详细步骤

### 步骤1：鸭子处理
**正在做什么：** 将鸭子洗净，去除内脏和杂质。

**食材当前状态：** 北京填鸭是完整的鸭子，带有内脏。

**操作要点：**
1. 将鸭子宰杀后，去除内脏
2. 仔细检查是否有残留的羽毛和杂质
3. 用清水将鸭子内外彻底清洗干净
4. 将鸭子挂在通风处，表皮水分完全风干
5. 或者用厨房纸将表皮和内部吸干

**注意事项：** 鸭子一定要彻底风干，否则烤不出来脆皮。风干时间约2-4小时。

### 步骤2：腌制入味
**正在做什么：** 将调料均匀地涂抹在鸭子内外，使其入味。

**食材当前状态：** 鸭子已经风干，表面干燥。

**操作要点：**
1. 将食盐和五香粉混合均匀
2. 在鸭子内部均匀地撒上盐和五香粉
3. 用手轻轻按摩，让调料均匀分布
4. 在鸭子表面也均匀地撒一些盐
5. 倒入料酒30ml到鸭子内部
6. 用手轻轻晃动，让料酒均匀分布
7. 腌制2小时

**注意事项：** 腌制时间要足够，让味道渗透到肉里。但不要超过4小时，否则肉质会变柴。

### 步骤3：制作脆皮水
**正在做什么：** 制作脆皮水，用于涂抹鸭子表面。

**食材当前状态：** 所有调料都是原始状态。

**操作要点：**
1. 取一个碗，放入麦芽糖30克
2. 加入白醋30ml
3. 加入蜂蜜15ml
4. 加入清水100ml
5. 搅拌均匀，让麦芽糖完全溶化
6. 脆皮水就制作完成了

**注意事项：** 脆皮水要搅拌均匀，麦芽糖要完全溶化，不要有颗粒。

### 步骤4：涂抹脆皮水
**正在做什么：** 将脆皮水均匀地涂抹在鸭子表面。

**食材当前状态：** 鸭子已经腌制好，表面干燥。

**操作要点：**
1. 将腌制好的鸭子取出
2. 用刷子将脆皮水均匀地刷在鸭子表面
3. 特别注意翅膀下面、腿部等隐蔽部位
4. 将鸭子挂在通风处，自然风干
5. 风干时间约2-3小时，直到表面完全干燥
6. 可以用电风扇加速风干

**注意事项：** 脆皮水要刷均匀，不要有遗漏。风干是脆皮的关键，一定要彻底风干。

### 步骤5：烤制鸭子
**正在做什么：** 将鸭子放入烤箱或烤鸭炉中烤制。

**食材当前状态：** 鸭子已经彻底风干，表面呈淡黄色。

**操作要点：**
1. 预热烤箱至200°C
2. 在烤盘上铺上锡纸，放上烤架
3. 将鸭子放在烤架上，胸部朝上
4. 放入烤箱中层
5. 先烤30分钟，让鸭子定形
6. 取出，将鸭子翻转，背部朝上
7. 继续烤20分钟
8. 再取出，翻转回胸部朝上
9. 最后烤15-20分钟，直到表皮呈红棕色

**注意事项：** 烤制温度和时间要根据鸭子大小调整。烤的过程中可以观察表皮颜色。烤箱温度要均匀。

### 步骤6：制作甜面酱
**正在做什么：** 将甜面酱调匀，加入配料增加风味。

**食材当前状态：** 甜面酱是稠密的酱料。

**操作要点：**
1. 将甜面酱100克放入碗中
2. 加入少许清水，约30ml，搅拌稀释
3. 加入白糖15克，搅拌均匀
4. 放入蒸锅中蒸10分钟
5. 取出后加入蒜泥拌匀
6. 甜面酱就调好了

**注意事项：** 甜面酱蒸过之后更香滑。稀稠要适度，能拉出丝但不会滴落。

### 步骤7：准备配料
**正在做什么：** 将葱段、黄瓜条切好，白糖装碟。

**食材当前状态：** 大葱和黄瓜是完整的。

**操作要点：**
1. 大葱去掉老叶，只留葱白
2. 切成约5厘米的段
3. 再切成细条
4. 黄瓜切成约5厘米的条
5. 可以将黄瓜条切成长条片
6. 白糖装入小碟中
7. 薄饼叠好放入蒸锅中蒸热

**注意事项：** 葱要选大葱的葱白，辣味少，甜味多。黄瓜要新鲜脆嫩。

### 步骤8：片鸭
**正在做什么：** 将烤好的鸭子片成薄片。

**食材当前状态：** 鸭子烤好了，表皮红亮，非常香。

**操作要点：**
1. 将鸭子取出，放在案板上
2. 让鸭子稍微冷却，约10分钟
3. 用片鸭刀先片下鸭胸的肉
4. 片成约0.5厘米厚的薄片
5. 再片鸭腿和鸭背的肉
6. 片的时候皮肉相连
7. 尽量保持肉片的完整性

**注意事项：** 片鸭需要一定的刀工，要皮肉相连。片好的鸭子要尽快食用，否则皮就不脆了。

### 步骤9：上桌
**正在做什么：** 将所有配料摆好，上桌享用。

**食材当前状态：** 鸭子已经片好，配料都准备齐全。

**操作要点：**
1. 将片好的鸭子整齐地码放在盘中
2. 鸭子放在中间，周围放配料
3. 甜面酱放在小碗中
4. 葱段、黄瓜条摆在旁边
5. 白糖碟放在一角
6. 薄饼放在蒸笼或保温盘中
7. 趁热食用

**注意事项：** 鸭子一定要趁热吃，凉了就不好吃了。皮会变软，不脆了。

## 烹饪关键点/小贴士

1. **鸭子选择**：最好选用北京填鸭，这种鸭子适合烤制。体重2-2.5公斤的最合适，太小没肉，太大肉老。

2. **风干关键**：鸭子一定要彻底风干，这是脆皮的关键。风干时间越长，皮越脆。可以用风扇加速。

3. **脆皮水**：脆皮水是烤鸭脆皮的关键，可以用麦芽糖、蜂蜜、白醋调配。比例要适当。

4. **烤制温度**：烤制温度要掌握好。先用高温让表皮定型，再用中温让肉熟透，最后高温上色。

5. **片鸭技巧**：片鸭需要练习，要皮肉相连，片得薄厚均匀。片好的鸭子要尽快食用。

6. **食用方法**：传统的吃法是：用薄饼夹一片鸭皮、一片鸭肉、葱段、黄瓜条，蘸甜面酱或白糖，卷起来吃。

7. **保存方法**：片好的鸭子要当天吃完。整只鸭子可以放冰箱冷藏3天，冷冻1个月。

## 营养信息

- 热量：约450千卡（每100克）
- 蛋白质：约25克
- 脂肪：约35克
- 碳水化合物：约10克

### 营养亮点
- 鸭肉富含B族维生素
- 适量食用可以滋阴补虚
- 鸭皮含有胶原蛋白
- 搭配葱菜更加营养均衡
