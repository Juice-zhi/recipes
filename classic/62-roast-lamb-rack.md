# 烤羊排

## 菜系/国家
地中海菜 / 中东/地中海

## 概述
烤羊排是中東和地中海地区的经典菜肴，以羊排为主料，用迷迭香、百里香等香料腌制后烤制。外酥里嫩，香气四溢，是非常受欢迎的烤肉料理。

## 份量/人数
4人份

## 所需餐具
- 烤箱
- 烤盘
- 刀
- 碗

## 食材清单

### 主料
- 羊排：800克（8块）

### 调料
- 橄榄油：60ml
- 迷迭香：10克
- 百里香：5克
- 大蒜：30克
- 盐：适量
- 黑胡椒：适量
- 柠檬：1个

## 详细步骤

### 步骤1：处理羊排
**正在做什么：** 将羊排修整干净。

**食材当前状态：** 羊排是连在一起的。

**操作要点：**
1. 将羊排切成单块
2. 去掉多余的脂肪
3. 用厨房纸吸干水分
4. 在羊排两面撒上盐和黑胡椒

**注意事项：** 羊排要保持干燥，烤出来才酥脆。

### 步骤2：腌制羊排
**正在做什么：** 将羊排腌制入味。

**食材当前状态：** 羊排已处理好。

**操作要点：**
1. 迷迭香和百里香切碎
2. 大蒜切末
3. 放入碗中，加橄榄油
4. 放入羊排，两面沾满调料
5. 腌制30分钟

**注意事项：** 腌制时间越长越入味。

### 步骤3：预热烤箱
**正在做什么：** 将烤箱预热。

**食材当前状态：** 烤箱是冷的。

**操作要点：**
1. 烤箱预热至220℃
2. 准备好烤盘，可以铺上锡纸

**注意事项：** 烤箱要充分预热。

### 步骤4：烤羊排
**正在做什么：** 将羊排烤制。

**食材当前状态：** 羊排已腌制好。

**操作要点：**
1. 将羊排放在烤盘上
2. 放入烤箱
3. 先烤10分钟
4. 翻面再烤8-10分钟
5. 烤至表面焦脆，内部呈粉红色

**注意事项：** 根据羊排厚度调整时间。

### 步骤5：休息
**正在做什么：** 让羊排休息一下。

**食材当前状态：** 羊排已烤好。

**操作要点：**
1. 从烤箱取出
2. 放在盘中休息5分钟
3. 挤上柠檬汁

**注意事项：** 休息可以让肉汁重新分布。

## 烹饪关键点/小贴士

1. **羊排**：选择新鲜的羊排，肥瘦相间的口感最好。
2. **腌制**：腌制时间越长越入味。
3. **火候**：烤的时候要注意观察，不要烤太老。
4. **休息**：烤好后要休息一下再切。
