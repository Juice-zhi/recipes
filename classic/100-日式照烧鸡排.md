# 日式照烧鸡排

## 菜系/国家
日本料理 / 日本

## 概述
日式照烧鸡排是日本的家庭常备菜肴，以鸡腿肉为主料，用照烧酱汁煎制。酱汁浓郁，鸡肉鲜嫩，是日本料理中最受欢迎的西式料理之一。

## 份量/人数
2人份

## 所需餐具
- 平底锅
- 锅铲
- 盘子

## 食材清单

### 主料
- 鸡腿肉：400克

### 照烧酱汁
- 酱油：45ml
- 味醂：30ml
- 清酒：30ml
- 糖：25克
- 蜂蜜：15克

### 辅料
- 芝麻：10克
- 葱花：20克
- 姜片：10克

### 油料
- 食用油：20ml

## 详细步骤

### 步骤1：处理鸡肉
**正在做什么：** 将鸡腿肉处理一下。

**食材当前状态：** 鸡腿肉是带骨的。

**操作要点：**
1. 鸡腿去骨
2. 在鸡肉表面划几刀
3. 用少许盐腌制10分钟

**注意事项：** 划刀可以让鸡肉更容易熟。

### 步骤2：调制照烧酱汁
**正在做什么：** 调制照烧酱汁。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 
2. 加入味醂和碗中放入酱油清酒
3. 加入糖
4. 加入蜂蜜
5. 搅拌均匀

**注意事项：** 糖要搅拌至融化。

### 步骤3：煎鸡肉
**正在做什么：** 将鸡肉煎至金黄。

**食材当前状态：** 鸡肉已处理好。

**操作要点：**
1. 锅中倒油
2. 放入姜片
3. 放入鸡肉，皮朝下
4. 中火煎
5. 煎至皮金黄
6. 翻面再煎
7. 煎至两面金黄

**注意事项：** 要把鸡皮的油煎出来。

### 步骤4：加入酱汁
**正在做什么：** 将照烧酱汁倒入锅中。

**食材当前状态：** 鸡肉已煎好。

**操作要点：**
1. 倒入调好的照烧酱汁
2. 盖上锅盖
3. 中火焖煮5分钟
4. 打开锅盖
5. 大火收汁
6. 不断把酱汁浇在鸡肉上

**注意事项：** 要不断翻动，避免糊底。

### 步骤5：装盘
**正在做什么：** 将照烧鸡排装盘。

**食材当前状态：** 鸡肉已收汁。

**操作要点：**
1. 取出鸡肉，切成块
2. 摆放在盘中
3. 浇上剩余的酱汁
4. 撒上芝麻
5. 撒上葱花

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **鸡肉**：选择鸡腿肉，肉质更嫩。
2. **煎皮**：要把鸡皮的油煎出来，才不油腻。
3. **收汁**：要大火收汁，让酱汁挂住鸡肉。
4. **酱汁**：照烧酱汁比例是酱油:味醂:清酒=3:2:2。
