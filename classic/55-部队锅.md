# 部队锅

## 菜系/国家
韩国料理 / 韩国

## 概述
部队锅是韩国经典火锅料理，起源于朝鲜战争时期。是以韩国辣酱为主要调料，加入各种肉类、蔬菜、面条等一起煮沸的丰盛料理，辣味浓郁，深受年轻人喜爱。

## 份量/人数
4人份

## 所需餐具
- 火锅盆或深锅
- 炉具（卡式炉或电磁炉）

## 食材清单

### 主料
- 午餐肉：200克
- 韩国拉面：2块
- 芝士片：4片
- 韩国年糕：200克

### 调料
- 韩国辣酱：60克
- 韩国辣白菜：150克
- 酱油：15ml
- 糖：10克
- 蒜末：15克
- 胡椒粉：少许

### 辅料
- 洋葱：100克
- 大葱：50克
- 蘑菇：100克
- 西葫芦：100克
- 鸡蛋：2个

### 汤底
- 鸡汤或清水：1000ml

## 详细步骤

### 步骤1：准备食材
**正在做什么：** 将所有食材切好备用。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 午餐肉切厚片
2. 洋葱切丝
3. 大葱切段
4. 蘑菇洗净切片
5. 西葫芦切片

**注意事项：** 食材要切得大小适中，方便煮熟。

### 步骤2：调制酱料
**正在做什么：** 将辣酱和其他调料调匀。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 碗中放入韩国辣酱
2. 加入酱油、糖、蒜末
3. 加入少许胡椒粉
4. 调匀备用

**注意事项：** 酱料要调匀，糖可以帮助辣酱更好地溶解。

### 步骤3：煮汤底
**正在做什么：** 煮好汤底。

**食材当前状态：** 锅中是清水。

**操作要点：**
1. 锅中加入鸡汤或清水
2. 大火烧开
3. 放入调好的辣酱
4. 搅拌均匀

**注意事项：** 要确保辣酱完全溶解。

### 步骤4：加入食材
**正在做什么：** 将食材放入锅中煮。

**食材当前状态：** 汤底已准备好。

**操作要点：**
1. 先放入耐煮的食材：午餐肉、年糕、蘑菇
2. 煮几分钟后放入拉面
3. 放上芝士片
4. 放入辣白菜、洋葱、西葫芦
5. 放入大葱

**注意事项：** 拉面不要煮太久，会糊。

### 步骤5：加入鸡蛋
**正在做什么：** 在锅中打入鸡蛋。

**食材当前状态：** 鸡蛋是完整的。

**操作要点：**
1. 汤煮沸后打入鸡蛋
2. 不要翻动，让鸡蛋定型
3. 可以直接边煮边吃

**注意事项：** 溏心蛋更美味。

## 烹饪关键点/小贴士

1. **芝士**：芝士是部队锅的灵魂，要选择可以拉丝的。
2. **拉面**：最后放拉面，避免煮得太软。
3. **辣酱**：根据个人口味调整辣酱用量。
4. **吃法**：可以配米饭或直接吃。
