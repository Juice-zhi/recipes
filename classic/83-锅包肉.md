# 锅包肉

## 菜系/国家
东北菜 / 中国东北

## 概述
锅包肉是东北经典名菜，以猪里脊肉为主料，裹上淀粉糊炸至酥脆，再浇上酸甜的糖醋汁。酸甜酥脆，是东北菜的代表之一。

## 份量/人数
4人份

## 所需餐具
- 炒锅
- 漏勺
- 盘子

## 食材清单

### 主料
- 猪里脊肉：300克

### 裹糊材料
- 土豆淀粉：100克
- 面粉：30克
- 泡打粉：3克
- 清水：80ml
- 油：10ml

### 糖醋汁
- 白糖：50克
- 醋：40ml
- 番茄酱：20克
- 生抽：10ml
- 盐：2克
- 清水：30ml

### 辅料
- 姜丝：10克
- 葱丝：20克
- 胡萝卜丝：30克
- 蒜片：10克

### 油料
- 食用油：500ml（实耗约80ml）

## 详细步骤

### 步骤1：处理肉片
**正在做什么：** 将里脊肉切成大片。

**食材当前状态：** 里脊肉是整块的。

**操作要点：**
1. 里脊肉切成约0.5厘米厚的大片
2. 用刀背轻轻拍松
3. 放入碗中，加少许盐腌制10分钟

**注意事项：** 肉片要切得厚薄均匀。

### 步骤2：调裹糊
**正在做什么：** 调制炸糊。

**食材当前状态：** 淀粉和面粉都是粉末。

**操作要点：**
1. 土豆淀粉、面粉、泡打粉放入碗中
2. 加入清水
3. 搅拌成均匀的糊状
4. 加入10ml油
5. 调成浓稠的酸奶状

**注意事项：** 裹糊要有一定的稠度。

### 步骤3：炸肉片
**正在做什么：** 将裹好糊的肉片炸至金黄。

**食材当前状态：** 肉片已裹好糊。

**操作要点：**
1. 锅中倒油，烧至六成热（160℃）
2. 放入裹好糊的肉片
3. 中火炸至金黄
4. 捞出沥油
5. 油温升至八成热（180℃）
6. 复炸一次至酥脆

**注意事项：** 复炸是关键。

### 步骤4：调糖醋汁
**正在做什么：** 调制酸甜汁。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 碗中放入白糖、醋
2. 加入番茄酱、生抽
3. 加入盐和清水
4. 调匀

**注意事项：** 糖醋比例要适中。

### 步骤5：炒汁
**正在做什么：** 将糖醋汁炒浓稠。

**食材当前状态：** 糖醋汁已调好。

**操作要点：**
1. 锅中留底油
2. 放入姜丝、葱丝、胡萝卜丝、蒜片
3. 炒出香味
4. 倒入糖醋汁
5. 小火熬至浓稠

**注意事项：** 要小火熬汁。

### 步骤6：裹汁
**正在做什么：** 将炸好的肉片裹上糖醋汁。

**食材当前状态：** 肉片已炸好，糖醋汁已熬好。

**操作要点：**
1. 迅速放入炸好的肉片
2. 快速翻匀
3. 让每片肉都裹上汁
4. 立即出锅

**注意事项：** 动作要快，保持肉片酥脆。

## 烹饪关键点/小贴士

1. **裹糊**：裹糊要稠一些，炸出来才酥脆。
2. **复炸**：一定要复炸，外皮才会酥脆。
3. **火候**：炸的时候油温要控制好。
4. **裹汁**：裹汁要快，保持肉片酥脆。
