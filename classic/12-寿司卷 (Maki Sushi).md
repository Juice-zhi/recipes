# 寿司卷 (Maki Sushi)

## 菜系/国家
日本料理 / 日本

## 概述
寿司卷是日本最具代表性的寿司类型之一，由海苔包裹醋饭和馅料制成。这道料理起源于东京（江户前寿司），既可作为正餐，也可作为便当。制作寿司卷需要掌握醋饭的制作和卷制的技巧。

## 份量/人数
4人份（约12-16个寿司卷）

## 所需餐具
- 竹帘（寿司卷帘）
- 刀（锋利，切寿司用）
- 砧板
- 碗（拌饭用）
- 小毛巾（湿润，敷手用）
- 盘子（盛装成品）

## 食材清单

### 主料
- 寿司米：300克
- 海苔（烤紫菜）：4张（约18x21厘米）

### 寿司醋饭
- 米醋：45ml（3大勺）
- 糖：30克（2大勺）
- 食盐：5克（1小勺）

### 馅料（可选择）
- 黄瓜：1根（约100克）
- 胡萝卜：1根（约80克）
- 牛油果：1个（约100克）
- 蟹棒（人造蟹肉）：4根
- 鸡蛋：2个
- 三文鱼（生鱼片级）：100克
- 金枪鱼（生鱼片级）：100克
- 奶酪条：4条

### 配料
- 芥末：10克
- 酱油：30ml（2大勺）
- 腌姜（红姜）：20克

## 详细步骤

### 步骤1：煮寿司米
**正在做什么：** 煮寿司米，这是寿司的基础。

**食材当前状态：** 寿司米是干燥的白色颗粒。

**操作要点：**
1. 将寿司米300克放入盆中
2. 用清水冲洗，用手轻轻揉搓
3. 倒掉浑水，重复冲洗2-3次
4. 直到水基本清澈
5. 将米倒入电饭锅中
6. 加入清水，米和水的比例约为1:1.1
7. 按下煮饭键，煮成熟饭
8. 煮好后，让米饭在锅中焖10分钟

**注意事项：** 寿司米要洗到水清澈，这样煮出来的饭才干净。水的比例要根据米的吸水性调整。

### 步骤2：制作寿司醋
**正在做什么：** 制作寿司醋，用于拌饭。

**食材当前状态：** 米醋、糖、食盐都是原始状态。

**操作要点：**
1. 取一个小碗
2. 放入米醋45ml
3. 加入糖30克
4. 加入食盐5克
5. 搅拌均匀，让糖和盐完全溶化
6. 寿司醋就做好了

**注意事项：** 糖和盐要完全溶化。可以用稍微加温的方法帮助溶化，但不要加热太多。

### 步骤3：拌醋饭
**正在做什么：** 将寿司醋拌入热米饭中。

**食材当前状态：** 米饭煮好了，热气腾腾。

**操作要点：**
1. 将煮好的米饭倒入大碗中
2. 用木勺或饭铲将米饭拨散
3. 趁热倒入寿司醋
4. 快速翻拌，让醋均匀分布
5. 边拌边用扇子扇风，帮助降温
6. 拌至米饭变得有光泽
7. 盖上湿毛巾，放置备用

**注意事项：** 米饭要趁热拌醋，这样醋味才能渗透。拌的时候要翻动，不要压饭粒。扇风可以让米饭更有光泽。

### 步骤4：准备馅料
**正在做什么：** 将各种馅料切好备用。

**食材当前状态：** 黄瓜、胡萝卜、牛油果等都是完整的。

**操作要点：**
1. 黄瓜去皮，切成约0.7厘米的条
2. 胡萝卜去皮，切成约0.7厘米的条
3. 牛油果去皮去核，切成条
4. 蟹棒切成约0.7厘米的条
5. 鸡蛋打散，摊成蛋饼，切成条
6. 三文鱼切成约0.7厘米的条
7. 金枪鱼切成约0.7厘米的条
8. 所有馅料切好后放在盘中备用

**注意事项：** 馅料要切得粗细均匀，和海苔的宽度匹配。切生鱼片要用锋利的刀。

### 步骤5：铺米饭
**正在做什么：** 将米饭均匀地铺在海苔上。

**食材当前状态：** 海苔是完整的干紫菜片，醋饭已经准备好。

**操作要点：**
1. 将竹帘放在案板上
2. 取一张海苔，光面朝下放在竹帘上
3. 用手沾一些水，防止米饭粘手
4. 取适量醋饭，均匀地铺在海苔上
5. 铺的时候从中间向四周推开
6. 铺的厚度约0.5厘米
7. 留出顶部约2厘米不铺米饭
8. 用手轻轻按压，让米饭紧实

**注意事项：** 米饭要铺得均匀，不要有厚薄。留出的边是用来粘合的。手要沾水，防止粘手。

### 步骤6：摆放馅料
**正在做什么：** 将馅料均匀地放在米饭上。

**食材当前状态：** 米饭已经均匀地铺在海苔上。

**操作要点：**
1. 在米饭的中间位置放馅料
2. 可以放一种或多种馅料
3. 馅料要成一条直线排列
4. 馅料的量不要太多
5. 轻轻按压，让馅料固定

**注意事项：** 馅料不要放太多，否则卷的时候容易漏出来。放的时候要在一条线上。

### 步骤7：卷制
**正在做什么：** 用竹帘将寿司卷起来。

**食材当前状态：** 馅料已经放在米饭上。

**操作要点：**
1. 双手握住竹帘
2. 将底部向上卷起
3. 边卷边轻轻按压
4. 卷到没有米饭的边缘时
5. 用手沾水，将边缘湿润
6. 继续卷紧
7. 放开竹帘，寿司卷就完成了

**注意事项：** 卷的时候要均匀用力，不要太紧也不要太松。边缘要粘牢。

### 步骤8：切寿司
**正在做什么：** 将寿司卷切成小段。

**食材当前状态：** 寿司卷是长条形。

**操作要点：**
1. 将寿司卷放在砧板上
2. 用锋利的刀切
3. 切之前刀要沾一下水，防止粘刀
4. 切成约2厘米宽的小段
5. 切的时候刀要一刀切断，不要来回拉

**注意事项：** 刀要锋利，切的时候要快准。不要慢慢锯，容易把寿司切碎。

### 步骤9：装盘
**正在做什么：** 将切好的寿司装盘。

**食材当前状态：** 寿司已经切成小段。

**操作要点：**
1. 将寿司码放在盘子中
2. 可以摆成不同的形状
3. 配上芥末和酱油
4. 放上腌姜装饰
5. 立即食用

**注意事项：** 寿司要现做现吃，放久了口感会变差。芥末可以放在酱油中，也可以直接蘸。

## 烹饪关键点/小贴士

1. **米的选择**：要用专门的寿司米或短粒米。寿司米粘度适中，容易捏成型。不能用长粒米。

2. **洗米技巧**：洗米时要轻轻揉搓，不要用力太大。洗到水清澈为止，这样米饭才干净。

3. **醋饭要点**：醋饭要在热的时候拌入醋，这样醋味才能渗透。拌好后要盖上湿毛巾，防止变干。

4. **海苔选择**：要用烤紫菜，未烤的紫菜太软不好用。烤紫菜要选颜色深、有光泽的。

5. **卷制技巧**：卷的时候要均匀用力，卷紧但不要太紧。太紧米饭会挤出来，太松会散。

6. **切寿司**：切寿司的刀要锋利，切之前要沾水。一刀切断，不要来回拉锯。

7. **食用方法**：寿司要现做现吃。蘸酱油时不要把芥末放在酱油中搅匀，应该把芥末放在寿司上，然后再蘸酱油。

- 膳食纤维：约2克

### 营养亮点
- 寿司米提供碳水化合物
- 生鱼片富含优质蛋白质和Omega-3
- 蔬菜提供维生素和膳食纤维
- 海苔富含碘和矿物质
