# 肉骨茶

## 菜系/国家
新加坡/马来西亚菜 / 新加坡

## 概述
肉骨茶是新加坡和马来西亚的经典美食，以猪骨和药材熬制汤底，配以米饭或油条食用。汤头浓郁，带有药材的香气，是东南亚华人社区的代表性美食。

## 份量/人数
4人份

## 所需餐具
- 汤锅
- 砂锅
- 盘子

## 食材清单

### 主料
- 排骨：600克

### 药材包
- 当归：5克
- 党参：10克
- 枸杞：10克
- 淮山：15克
- 玉竹：10克
- 川芎：5克
- 八角：2个
- 桂皮：1小块

### 调料
- 生抽：30ml
- 老抽：15ml
- 盐：10克
- 糖：10克
- 料酒：30ml
- 白胡椒粉：5克

### 辅料
- 大蒜：20克（整颗）
- 姜：20克
- 葱：30克

### 配食
- 油条：2根
- 米饭：适量

## 详细步骤

### 步骤1：处理排骨
**正在做什么：** 将排骨处理干净。

**食材当前状态：** 排骨是新鲜的。

**操作要点：**
1. 排骨剁成约5厘米的段
2. 放入开水中焯烫
3. 去掉血沫
4. 捞出洗净备用

**注意事项：** 要把血沫去干净。

### 步骤2：准备药材
**正在做什么：** 将药材包准备好。

**食材当前状态：** 药材都是干燥的。

**操作要点：**
1. 所有药材放入纱布袋中
2. 扎紧袋口
3. 稍微冲洗一下

**注意事项：** 药材包可以让汤更清澈。

### 步骤3：炖煮
**正在做什么：** 将排骨和药材一起炖煮。

**食材当前状态：** 排骨已焯好，药材包已准备好。

**操作要点：**
1. 砂锅中放入排骨
2. 放入药材包
3. 加入大蒜和姜片
4. 加入料酒
5. 加入生抽和老抽
6. 加入盐和糖
7. 加入足量的水
8. 大火烧开
9. 转小火炖2小时

**注意事项：** 要小火慢炖。

### 步骤4：调味
**正在做什么：** 最后调味。

**食材当前状态：** 肉骨茶已炖好。

**操作要点：**
1. 打开锅盖
2. 加入白胡椒粉
3. 试试味道，调整盐量

**注意事项：** 胡椒粉是灵魂调料。

### 步骤5：装盘
**正在做什么：** 将肉骨茶装盘。

**食材当前状态：** 肉骨茶已调味好。

**操作要点：**
1. 盛入碗中
2. 撒上葱花
3. 配上油条或米饭

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **药材**：药材包可以根据口味调整。
2. **火候**：要小火慢炖，药材味道才能释放。
3. **胡椒**：白胡椒粉是肉骨茶的关键调料。
4. **配食**：油条蘸汤吃是经典吃法。
