# 红烧肉

## 菜系/国家
浙菜 / 中国

## 概述
红烧肉是中国最经典的家常菜之一，以五花肉为主料，经过慢火红烧而成。成品色泽红亮，肥而不腻，入口即化，是中华美食的代表作。

## 份量/人数
4人份

## 所需餐具
- 砂锅或炖锅
- 炒锅
- 锅铲
- 盘子（盛装成品）

## 食材清单

### 主料
- 五花肉：500克

### 调料
- 生抽（酱油）：30ml（2大勺）
- 老抽：15ml（1大勺，用于上色）
- 冰糖：30克
- 料酒：30ml（2大勺）
- 八角：2个
- 桂皮：1小块
- 香叶：2片
- 食盐：适量

### 辅料
- 生姜：20克（切片）
- 葱：2根（打结）
- 清水：适量

## 详细步骤

### 步骤1：处理五花肉
**正在做什么：** 将五花肉切成方块，准备焯水。

**食材当前状态：** 五花肉是整块的，表面有猪毛和杂质。

**操作要点：**
1. 将五花肉洗净，切成约4厘米见方的块状
2. 锅中加水，放入五花肉块
3. 加入料酒和姜片，大火烧开
4. 撇去浮沫，煮3分钟后捞出洗净备用

**注意事项：** 切块时要肥瘦相间，太瘦会柴，太肥会腻。

### 步骤2：炒糖色
**正在做什么：** 炒制糖色，为红烧肉上色。

**食材当前状态：** 五花肉已焯水备用，锅中无油。

**操作要点：**
1. 锅中放入少量油，小火加热
2. 放入冰糖，慢慢翻炒
3. 炒至冰糖融化变成琥珀色
4. 迅速放入五花肉翻炒均匀

**注意事项：** 糖色要炒到琥珀色，不能炒焦，否则会发苦。

### 步骤3：红烧炖煮
**正在做什么：** 加入调料和水，慢火炖煮。

**食材当前状态：** 五花肉已裹上糖色，呈红亮色。

**操作要点：**
1. 放入八角、桂皮、香叶
2. 加入生抽、老抽、料酒
3. 倒入开水，水量没过肉块
4. 大火烧开后转小火
5. 盖上锅盖，炖煮约1小时

**注意事项：** 一定要加开水，不能加冷水，否则肉质会变硬。

### 步骤4：收汁
**正在做什么：** 大火收汁，使肉块裹上浓稠汤汁。

**食材当前状态：** 五花肉已经软烂，汤汁剩余约一半。

**操作要点：**
1. 打开锅盖，大火收汁
2. 不断翻动肉块，使其均匀上色
3. 收至汤汁浓稠即可出锅

**注意事项：** 收汁时要不断翻动，防止粘底糊锅。

## 烹饪关键点/小贴士

1. **选肉**：选择肥瘦相间的五花肉，层次分明的口感最好。
2. **火候**：先大火烧开，后小火慢炖，这是肉质软烂的关键。
3. **糖色**：炒糖色要耐心，小火慢炒，糖色是红烧肉色亮的关键。
4. **水量**：炖煮时水要一次加足，中途不要加水。
