# 东坡肉

## 菜系/国家
浙菜 / 中国浙江杭州

## 概述
东坡肉是杭州的传统名菜，相传由北宋大文豪苏东坡创制。这道菜选用五花肉为主料，用慢火长时间炖煮，成菜色泽红亮如玛瑙，肉质酥软如豆腐，肥而不腻，入口即化，是中华美食的经典之作。

## 份量/人数
4-6人份

## 所需餐具
- 砂锅或炖锅
- 炒锅（用于炒糖色）
- 锅铲
- 漏勺
- 盘子（盛装成品）

## 食材清单

### 主料
- 五花肉：750克（约1大块）

### 调料
- 冰糖：80克（约8大勺）
- 生抽：80ml（约5大勺）
- 老抽：30ml（约2大勺）
- 料酒：60ml（约4大勺）
- 食盐：5克（约1小勺）
- 八角：3个
- 桂皮：1小块（约8克）
- 香叶：3片
- 草果：1个
- 陈皮：5克（1小块）

### 辅料
- 大葱：50克（2根，切段）
- 姜：30克（5-6片）
- 小葱：30克（1小把，打成葱结）

## 详细步骤

### 步骤1：五花肉处理
**正在做什么：** 将五花肉切成约8厘米见方的大块。

**食材当前状态：** 五花肉是一大块连皮的猪肉。

**操作要点：**
1. 将五花肉洗净，用厨房纸巾吸干表面水分
2. 将五花肉切成约8厘米见方的大块
3. 每块都要带皮
4. 切好后放入盘中备用

**注意事项：** 肉块不要切太小，炖煮后会收缩。太小的块没有大气磅礴的感觉。

### 步骤2：五花肉焯水
**正在做什么：** 将肉块焯烫，去除血沫。

**食材当前状态：** 肉块已经切好，整齐地摆在盘中。

**操作要点：**
1. 锅中加入足量清水，能没过肉块
2. 放入五花肉块
3. 加入料酒30ml
4. 大火烧开，观察血沫浮起
5. 用漏勺撇去浮沫
6. 焯约5分钟后捞出
7. 用温水洗净表面浮沫
8. 沥干水分备用

**注意事项：** 捞出后用温水清洗，不要用冷水，肉质会变硬。

### 步骤3：炒糖色
**正在做什么：** 将冰糖炒成焦糖色。

**食材当前状态：** 炒锅是干净的，冰糖是大颗粒的白色晶体。

**操作要点：**
1. 炒锅烧热
2. 放入冰糖80克
3. 加入少量清水，约20ml
4. 用中小火加热，不断搅拌
5. 冰糖逐渐融化
6. 继续搅拌，糖色变成琥珀色
7. 当糖色变成深琥珀色时
8. 迅速放入五花肉块

**注意事项：** 糖色炒得恰到好处，肉的颜色才会红亮。炒浅了不够色，炒深了会发苦。

### 步骤4：翻炒上色
**正在做什么：** 将肉块与糖色翻炒均匀。

**食材当前状态：** 肉块已经下锅，表面还比较苍白。

**操作要点：**
1. 立即下入五花肉块
2. 快速翻炒，让每块肉都裹上糖色
3. 炒至肉块表面呈现红褐色
4. 加入生抽80ml和老抽30ml
5. 继续翻炒，让调料均匀分布

**注意事项：** 翻炒要快，糖色遇冷会凝固。加入酱油后也要快速翻匀。

### 步骤5：加入香料
**正在做什么：** 加入所有香料，准备炖煮。

**食材当前状态：** 肉块已经上色，呈红褐色。

**操作要点：**
1. 放入八角3个、桂皮1小块、香叶3片
2. 放入草果1个、陈皮5克
3. 翻炒一下，让香料出香味
4. 炒约1分钟

**注意事项：** 香料可以根据个人口味调整。草果和陈皮是东坡肉的特色，不可或缺。

### 步骤6：炖煮
**正在做什么：** 加入足量的水，用小火慢炖。

**食材当前状态：** 所有材料已经在锅中。

**操作要点：**
1. 加入足够的开水，水量没过肉块约2厘米
2. 加入料酒30ml
3. 放入葱段和姜片
4. 放入葱结
5. 大火烧开后，转最小火
6. 盖上锅盖，保持微沸状态
7. 炖煮约2.5-3小时
8. 中途不要打开锅盖

**注意事项：** 一定要加开水，不能加冷水。火候要极小，保持微沸即可。大火会让肉块炖散。

### 步骤7：收汁
**正在做什么：** 大火收汁，使汤汁浓稠。

**食材当前状态：** 肉块已经软烂，汤汁还比较多。

**操作要点：**
1. 炖至肉块软烂后，开大火
2. 不断用锅铲翻动肉块，防止粘底
3. 收汁约15-20分钟
4. 汤汁变得浓稠，裹在肉块表面
5. 根据口味加入食盐调味
6. 挑出香料（八角、桂皮等）
7. 关火

**注意事项：** 收汁时要不断翻动，防止底部糊锅。盐要最后放，提前放会让肉质变柴。

### 步骤8：装盘
**正在做什么：** 将东坡肉装入盘中。

**食材当前状态：** 东坡肉已经完成，色泽红亮。

**操作要点：**
1. 先将香料和葱姜挑出
2. 将肉块整齐地摆放在盘中
3. 淋上锅中的浓稠汤汁
4. 可以撒上少许葱花装饰

**注意事项：** 装盘后要尽快食用，放凉后口感会变差。

## 烹饪关键点/小贴士

1. **五花肉选择**：选用肥瘦相间的三层五花肉，带皮的最好。太瘦的肉炖出来柴，太肥的腻。

2. **糖色要点**：炒糖色是东坡肉成败的关键。可以用冰糖或白糖，冰糖炒出来颜色更透亮。

3. **火候控制**：全程控制好火候。炒糖色时用中小火，炖煮时用极小火（最小火），收汁时用大火。

4. **炖煮时间**：至少要炖2.5小时以上，肉才能完全酥软。时间越长越好吃。

5. **水温注意**：焯水和炖煮都要用热水或开水，不能用冷水。冷水会让肉质变硬。

6. **香料搭配**：八角、桂皮、草果、陈皮是东坡肉的经典配料，缺一不可。

7. **保存技巧**：东坡肉放凉后可以冷藏保存3-5天。重新加热时可以连汤一起蒸。

- 适量食用可以补血养颜

- 胶原蛋白对皮肤有益
