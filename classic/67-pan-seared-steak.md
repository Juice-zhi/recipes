# 煎牛排

## 菜系/国家
西餐 / 欧美

## 概述
煎牛排是西餐中的经典菜肴，以牛里脊或牛排为原料，煎至所需的成熟度。简单调味，保留牛肉的原汁原味，是检验牛肉品质的经典做法。

## 份量/人数
2人份

## 所需餐具
- 煎锅
- 夹子
- 刀
- 盘子

## 食材清单

### 主料
- 牛排：400克（2块，约2厘米厚）

### 调料
- 橄榄油：30ml
- 盐：适量
- 黑胡椒：适量
- 黄油：30克
- 蒜末：10克
- 新鲜迷迭香：2根
- 新鲜百里香：3根

## 详细步骤

### 步骤1：处理牛排
**正在做什么：** 将牛排恢复到室温。

**食材当前状态：** 牛排是冷藏的。

**操作要点：**
1. 牛排提前30分钟从冰箱取出
2. 用厨房纸吸干表面的水分
3. 两面撒上盐和黑胡椒
4. 静置15分钟

**注意事项：** 牛排要恢复到室温再煎。

### 步骤2：热锅
**正在做什么：** 将煎锅烧热。

**食材当前状态：** 锅是冷的。

**操作要点：**
1. 煎锅大火烧热
2. 倒入橄榄油
3. 油热至微微冒烟

**注意事项：** 锅要足够热，才能锁住肉汁。

### 步骤3：煎牛排
**正在做什么：** 将牛排煎至所需熟度。

**食材当前状态：** 牛排已调味。

**操作要点：**
1. 放入牛排，不要移动
2. 煎2-3分钟
3. 翻面
4. 再煎2-3分钟
5. 侧面也要煎一下

**注意事项：** 煎的时候不要经常翻动。

### 步骤4：加入黄油和香料
**正在做什么：** 加入黄油和香料增加风味。

**食材当前状态：** 牛排已煎至五分熟。

**操作要点：**
1. 放入黄油
2. 加入蒜末、迷迭香、百里香
3. 用勺子将黄油浇在牛排上
4. 继续煎1-2分钟

**注意事项：** 要不断浇汁，让牛排入味。

### 步骤5：休息
**正在做什么：** 让牛排休息一下。

**食材当前状态：** 牛排已煎好。

**操作要点：**
1. 取出牛排
2. 放在温热的盘子中
3. 用锡纸盖住
4. 休息5分钟

**注意事项：** 休息可以让肉汁重新分布。

### 步骤6：装盘
**正在做什么：** 将牛排装盘。

**食材当前状态：** 牛排已休息好。

**操作要点：**
1. 打开锡纸
2. 可以再撒一些黑胡椒
3. 配上喜欢的蔬菜

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **牛排**：选择质量好的牛排，如西冷、菲力。
2. **室温**：牛排要恢复到室温再煎，否则外熟里生。
3. **锅要热**：锅要热才能锁住肉汁。
4. **休息**：煎好后要休息，切的时候才不回血水。
