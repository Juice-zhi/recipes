# 海南鸡饭

## 菜系/国家
新加坡/马来西亚菜 / 新加坡

## 概述
海南鸡饭是新加坡的国菜，以鲜嫩的白切鸡配上香喷喷的鸡油饭。鸡肉鲜嫩多汁，米饭吸收了鸡汤的鲜味，是东南亚最具代表性的美食之一。

## 份量/人数
4人份

## 所需餐具
- 煮锅
- 蒸锅
- 刀
- 盘子

## 食材清单

### 主料
- 整鸡：1只（约1.5公斤）
- 大米：400克

### 鸡汤调料
- 姜：30克
- 葱：50克
- 盐：15克

### 饭调料
- 鸡油：50克
- 蒜末：15克
- 姜末：10克
- 鸡汤：400ml

### 蘸料
- 辣椒酱：30克
- 姜末：15克
- 酱油：20ml
- 糖：5克

## 详细步骤

### 步骤1：处理鸡
**正在做什么：** 将鸡清洗干净。

**食材当前状态：** 整鸡是新鲜的。

**操作要点：**
1. 鸡去内脏，洗净
2. 去掉多余的脂肪
3. 用盐将鸡身内外抹匀
4. 静置30分钟

**注意事项：** 要把鸡身内外都抹盐。

### 步骤2：煮鸡汤
**正在做什么：** 用鸡骨煮高汤。

**食材当前状态：** 鸡已处理好。

**操作要点：**
1. 锅中加水，放入姜片和葱
2. 大火烧开
3. 放入整鸡
4. 水开后转小火
5. 煮约20分钟至鸡熟透
6. 捞出鸡，留下鸡汤

**注意事项：** 火不能太大，否则鸡肉会老。

### 步骤3：制作鸡油饭
**正在做什么：** 用鸡油将米饭炒香。

**食材当前状态：** 米是生的。

**操作要点：**
1. 大米洗净，沥干水分
2. 锅中放入鸡油
3. 融化后炒香蒜末和姜末
4. 放入大米翻炒
5. 倒入400ml鸡汤
6. 煮至水干

**注意事项：** 要用鸡汤煮饭，更香。

### 步骤4：蒸饭
**正在做什么：** 将米饭蒸熟。

**食材当前状态：** 米饭已炒过。

**操作要点：**
1. 将米饭放入蒸锅
2. 大火蒸20分钟
3. 蒸至米饭熟透

**注意事项：** 饭要蒸到松软。

### 步骤5：冷却鸡
**正在做什么：** 让鸡自然冷却。

**食材当前状态：** 鸡已煮熟。

**操作要点：**
1. 煮好的鸡捞出
2. 放入冰水中快速冷却
3. 这样鸡肉更嫩滑
4. 沥干水分

**注意事项：** 冰水可以让鸡皮更Q弹。

### 步骤6：切鸡
**正在做什么：** 将鸡切成块。

**食材当前状态：** 鸡已冷却。

**操作要点：**
1. 将鸡切成小块
2. 摆放在米饭旁边
3. 配上蘸料

**注意事项：** 要切得大小均匀。

### 步骤7：制作蘸料
**正在做什么：** 调制蘸料。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 辣椒酱放入碗中
2. 加入姜末
3. 加入酱油和糖
4. 调匀

**注意事项：** 蘸料可以根据个人口味调整。

## 烹饪关键点/小贴士

1. **鸡**：选择新鲜的走地鸡，肉质更好。
2. **火候**：煮鸡时火不能太大，保持微开。
3. **冰水**：过冰水可以让鸡皮更弹牙。
4. **饭**：用鸡油炒过的饭才香。
