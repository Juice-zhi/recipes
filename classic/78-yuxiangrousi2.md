# 鱼香肉丝

## 菜系/国家
川菜 / 中国四川

## 概述
鱼香肉丝是四川经典名菜，虽然名字中有"鱼"，但实际并不含鱼。是以猪肉丝为主料，配以木耳、竹笋等，用鱼香味调料炒制。酸甜微辣，是川菜的代表菜之一。

## 份量/人数
3-4人份

## 所需餐具
- 炒锅
- 碗（调料汁用）
- 盘子

## 食材清单

### 主料
- 猪里脊肉：300克
- 木耳：50克
- 竹笋：100克

### 肉丝腌料
- 盐：3克
- 料酒：10ml
- 淀粉：10克

### 鱼香汁调料
- 郫县豆瓣酱：20克
- 醋：20ml
- 糖：20克
- 生抽：15ml
- 淀粉：10克

### 辅料
- 姜：10克
- 蒜：10克
- 葱：30克
- 泡椒：20克

### 油料
- 食用油：40ml

## 详细步骤

### 步骤1：处理食材
**正在做什么：** 将所有食材切好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 里脊肉切成细丝
2. 木耳泡发后切丝
3. 竹笋切丝
4. 姜蒜切末
5. 葱切段
6. 泡椒切碎

**注意事项：** 食材要切得细一些。

### 步骤2：腌制肉丝
**正在做什么：** 将肉丝腌制入味。

**食材当前状态：** 肉丝是生的。

**操作要点：**
1. 肉丝放入碗中
2. 加盐、料酒、淀粉
3. 抓匀腌制15分钟

**注意事项：** 淀粉可以让肉丝更嫩。

### 步骤3：调鱼香汁
**正在做什么：** 调制鱼香味调料汁。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 碗中放入糖、醋、生抽
2. 加入淀粉调匀
3. 调成鱼香汁备用

**注意事项：** 淀粉要调匀，不要有颗粒。

### 步骤4：炒肉丝
**正在做什么：** 将肉丝炒散。

**食材当前状态：** 肉丝已腌制好。

**操作要点：**
1. 锅中倒油
2. 烧热后放入肉丝
3. 快速翻炒
4. 炒至变色后盛出

**注意事项：** 要大火快炒。

### 步骤5：炒底料
**正在做什么：** 炒香豆瓣酱和配料。

**食材当前状态：** 肉已盛出。

**操作要点：**
1. 锅中留底油
2. 放入姜蒜末、泡椒
3. 小火炒香
4. 放入豆瓣酱炒出红油

**注意事项：** 豆瓣酱要炒出红油。

### 步骤6：加入配菜
**正在做什么：** 加入木耳和竹笋。

**食材当前状态：** 底料已炒好。

**操作要点：**
1. 放入木耳丝和竹笋丝
2. 翻炒均匀
3. 炒至断生

**注意事项：** 不要炒太久。

### 步骤7：加入肉丝
**正在做什么：** 将肉丝放回锅中。

**食材当前状态：** 配菜已炒好。

**操作要点：**
1. 放入炒好的肉丝
2. 翻炒均匀

**注意事项：** 要快速翻动。

### 步骤8：浇汁
**正在做什么：** 倒入调好的鱼香汁。

**食材当前状态：** 食材都炒好了。

**操作要点：**
1. 倒入鱼香汁
2. 大火快速翻炒
3. 让酱汁均匀包裹
4. 放入葱段
5. 出锅装盘

**注意事项：** 要大火快炒。

## 烹饪关键点/小贴士

1. **刀工**：肉丝要切得粗细均匀。
2. **火候**：全程要大火快炒。
3. **调味**：鱼香汁的比例是糖醋1:1，这是关键。
4. **豆瓣酱**：要选正宗的郫县豆瓣酱。
