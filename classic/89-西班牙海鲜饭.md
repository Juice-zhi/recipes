# 西班牙海鲜饭

## 菜系/国家
西班牙菜 / 西班牙

## 概述
西班牙海鲜饭是西班牙的国菜，以西班牙米为主料，加入各种海鲜和香料，用平底锅烩制而成。色泽金黄，海鲜鲜美，是地中海饮食的经典代表。

## 份量/人数
4人份

## 所需餐具
- 平底锅（直径约30厘米）
- 木勺
- 盘子

## 食材清单

### 主料
- 西班牙米：300克
- 虾：300克
- 青口贝：200克
- 鱿鱼：150克

### 辅料
- 洋葱：100克
- 番茄：200克
- 青椒：100克
- 豌豆：50克
- 藏红花：0.5克

### 汤底
- 鱼高汤：1000ml
- 白葡萄酒：100ml

### 调料
- 橄榄油：60ml
- 辣椒粉：3克
- 盐：适量
- 黑胡椒：适量

## 详细步骤

### 步骤1：处理海鲜
**正在做什么：** 将海鲜处理干净。

**食材当前状态：** 海鲜都是完整的。

**操作要点：**
1. 虾去壳，留尾
2. 青口贝刷干净，去须
3. 鱿鱼切圈
4. 用少许盐和胡椒腌制

**注意事项：** 海鲜要新鲜。

### 步骤2：处理蔬菜
**正在做什么：** 将蔬菜切好。

**食材当前状态：** 蔬菜都是完整的。

**操作要点：**
1. 洋葱切碎
2. 番茄去皮切丁
3. 青椒切丁

**注意事项：** 番茄要去皮。

### 步骤3：炒蔬菜
**正在做什么：** 将蔬菜炒香。

**食材当前状态：** 蔬菜已切好。

**操作要点：**
1. 平底锅中倒入橄榄油
2. 放入洋葱
3. 小火炒软
4. 加入番茄和青椒
5. 炒至软烂

**注意事项：** 要把蔬菜炒出香味。

### 步骤4：加入米和藏红花
**正在做什么：** 将米炒一下。

**食材当前状态：** 米是干燥的。

**操作要点：**
1. 放入米
2. 翻炒2分钟
3. 让米吸收油脂
4. 加入藏红花
5. 翻炒均匀

**注意事项：** 藏红花要提前用温水泡开。

### 步骤5：加入液体
**正在做什么：** 加入高汤和酒。

**食材当前状态：** 米已炒过。

**操作要点：**
1. 倒入白葡萄酒
2. 让酒精挥发
3. 倒入鱼高汤
4. 加入辣椒粉
5. 大火烧开

**注意事项：** 液体要一次加够。

### 步骤6：煮饭
**正在做什么：** 将米饭煮熟。

**食材当前状态：** 锅中是米和汤。

**操作要点：**
1. 转中火
2. 煮约15分钟
3. 不要翻动
4. 让米吸收汤汁
5. 饭快熟时放入海鲜
6. 放上虾、青口贝、鱿鱼
7. 放入豌豆

**注意事项：** 放海鲜后不要翻动。

### 步骤7：完成
**正在做什么：** 装盘。

**食材当前状态：** 海鲜饭已做好。

**操作要点：**
1. 盖上锅盖，焖5分钟
2. 打开盖子
3. 让海鲜饭稍微"锅巴"化
4. 撒上欧芹
5. 挤上柠檬汁

**注意事项：** 正宗的海鲜饭底部应该有锅巴。

## 烹饪关键点/小贴士

1. **米**：要用西班牙米，如Bomba或Arborio。
2. **藏红花**：藏红花是海鲜饭的灵魂调料。
3. **液体**：液体不要加太多，米饭要保持粒粒分明。
4. **海鲜**：海鲜最后放，保持鲜嫩。
