# 烤鸡翅

## 菜系/国家
美式菜 / 美国

## 概述
烤鸡翅是美国酒吧和家庭的经典小食，以鸡翅为主料，用各种调味酱腌制后烤制。表皮焦香，肉质鲜嫩，是看比赛、聚会的好伴侣。

## 份量/人数
4人份

## 所需餐具
- 烤箱
- 烤盘
- 碗

## 食材清单

### 主料
- 鸡翅中：800克

### 调料（酱料）
- 酱油：30ml
- 蜂蜜：30ml
- 番茄酱：30ml
- 蒜末：15克
- 姜末：10克
- 辣椒粉：5克
- 孜然粉：3克
- 盐：适量
- 胡椒粉：适量

## 详细步骤

### 步骤1：处理鸡翅
**正在做什么：** 将鸡翅清洗干净。

**食材当前状态：** 鸡翅是完整的。

**操作要点：**
1. 鸡翅洗净
2. 用厨房纸吸干水分
3. 在鸡翅上划两刀

**注意事项：** 水分要吸干，否则不入味。

### 步骤2：调制酱料
**正在做什么：** 将所有调料调匀。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 碗中放入酱油和蜂蜜
2. 加入番茄酱
3. 加入蒜末、姜末
4. 加入辣椒粉、孜然粉
5. 盐和胡椒粉调味
6. 搅拌均匀

**注意事项：** 酱料要调匀。

### 步骤3：腌制鸡翅
**正在做什么：** 将鸡翅腌制入味。

**食材当前状态：** 鸡翅已处理好。

**操作要点：**
1. 鸡翅放入大碗中
2. 倒入调好的酱料
3. 按摩鸡翅，让酱料渗透
4. 盖上保鲜膜
5. 放入冰箱腌制2小时以上

**注意事项：** 腌制时间越长越入味。

### 步骤4：预热烤箱
**正在做什么：** 将烤箱预热。

**食材当前状态：** 烤箱是冷的。

**操作要点：**
1. 烤箱预热至200℃
2. 准备好烤盘，铺上锡纸

**注意事项：** 要充分预热。

### 步骤5：烤制
**正在做什么：** 将鸡翅烤熟。

**食材当前状态：** 鸡翅已腌制好。

**操作要点：**
1. 将鸡翅摆在烤盘上
2. 放入烤箱
3. 先烤15分钟
4. 取出翻面
5. 再烤10分钟
6. 烤至表面焦脆

**注意事项：** 观察鸡翅颜色，避免烤焦。

### 步骤6：完成
**正在做什么：** 将烤好的鸡翅装盘。

**食材当前状态：** 鸡翅已烤好。

**操作要点：**
1. 从烤箱取出
2. 稍微冷却
3. 装盘
4. 可以撒上少许葱花

**注意事项：** 小心烫手。

## 烹饪关键点/小贴士

1. **鸡翅**：选择大小均匀的鸡翅，成熟度一致。
2. **腌制**：腌制时间越长越入味，最好过夜。
3. **蜂蜜**：蜂蜜可以帮助上色和增加光泽。
4. **烤制**：火候要控制好，表面焦脆里面鲜嫩。
