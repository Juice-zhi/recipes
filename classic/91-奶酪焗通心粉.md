# 奶酪焗通心粉

## 菜系/国家
意大利菜 / 意大利

## 概述
奶酪焗通心粉是意大利北部的经典菜肴，以通心粉为主料，配以浓郁的白酱和奶酪烤制。奶酪拉丝，是意大利人最爱的家常菜之一。

## 份量/人数
4人份

## 所需餐具
- 烤箱
- 煮锅
- 炒锅
- 盘子

## 食材清单

### 主料
- 通心粉：400克
- 马苏里拉芝士：150克
- 帕尔玛干酪：50克

### 白酱
- 黄油：40克
- 面粉：40克
- 牛奶：500ml
- 肉豆蔻：少许

### 辅料
- 火腿：100克
- 蘑菇：100克

## 详细步骤

### 步骤1：煮通心粉
**正在做什么：** 将通心粉煮至半熟。

**食材当前状态：** 通心粉是干燥的。

**操作要点：**
1. 锅中加水，放盐
2. 水开后放入通心粉
3. 煮5-6分钟至半熟
4. 捞出沥干备用

**注意事项：** 不要煮太熟，后面还要烤。

### 步骤2：制作白酱
**正在做什么：** 制作奶油白酱。

**食材当前状态：** 食材都是独立的。

**操作要点：**
1. 锅中融化黄油
2. 加入面粉翻炒
3. 慢慢加入牛奶
4. 不断搅拌
5. 煮至浓稠
6. 加入肉豆蔻和盐调味

**注意事项：** 要不断搅拌，避免结块。

### 步骤3：炒配料
**正在做什么：** 将火腿和蘑菇炒香。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 火腿切丁
2. 蘑菇切片
3. 锅中黄油炒香
4. 放入火腿和蘑菇
5. 炒至变色

**注意事项：** 稍微炒一下即可。

### 步骤4：混合
**正在做什么：** 将通心粉和酱料混合。

**食材当前状态：** 通心粉已煮好，白酱已做好。

**操作要点：**
1. 将白酱倒入通心粉中
2. 加入炒好的配料
3. 搅拌均匀
4. 加入一半的马苏里拉芝士

**注意事项：** 要让酱料均匀包裹通心粉。

### 步骤5：烤制
**正在做什么：** 将通心粉放入烤箱烤制。

**食材当前状态：** 通心粉已混合好。

**操作要点：**
1. 放入耐热烤盘
2. 撒上剩余的芝士
3. 撒上帕尔玛干酪
4. 预热烤箱至200℃
5. 放入烤盘
6. 烤15-20分钟
7. 烤至表面金黄起泡

**注意事项：** 要烤到芝士融化并金黄。

### 步骤6：完成
**正在做什么：** 出炉。

**食材当前状态：** 焗通心粉已烤好。

**操作要点：**
1. 从烤箱取出
2. 稍微冷却5分钟
3. 即可食用

**注意事项：** 小心烫口。

## 烹饪关键点/小贴士

1. **通心粉**：煮到半熟即可，后续烤制会继续熟。
2. **白酱**：白酱要浓稠，能挂住通心粉。
3. **奶酪**：马苏里拉芝士要够量，才能拉丝。
4. **烤制**：表面烤到金黄即可。
