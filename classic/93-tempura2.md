# 天妇罗

## 菜系/国家
日本料理 / 日本

## 概述
天妇罗是日本料理中的经典油炸食品，将海鲜、蔬菜裹上薄薄的面糊炸至金黄酥脆。口感清爽不油腻，是日本四大料理之一。

## 份量/人数
4人份

## 所需餐具
- 炸锅
- 漏勺
- 碗
- 盘子

## 食材清单

### 面糊
- 低筋面粉：100克
- 冰水：150ml
- 鸡蛋：1个
- 泡打粉：3克

### 海鲜
- 虾：8只
- 鱿鱼：100克

### 蔬菜
- 红薯：100克
- 南瓜：100克
- 青椒：2个
- 茄子：1个
- 香菇：4个

### 油料
- 食用油：500ml（实耗约150ml）

### 蘸料
- 酱油：30ml
- 味醂：15ml
- 高汤：30ml
- 萝卜泥：30克

## 详细步骤

### 步骤1：处理食材
**正在做什么：** 将所有食材处理好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 虾去壳，留尾，去虾线
2. 鱿鱼切圈
3. 红薯、南瓜切片
4. 青椒去籽切块
5. 茄子切片
6. 香菇去蒂

**注意事项：** 食材要切得大小适中。

### 步骤2：调面糊
**正在做什么：** 调制天妇罗面糊。

**食材当前状态：** 食材都是粉末和液体。

**操作要点：**
1. 面粉和泡打粉混合
2. 打入鸡蛋
3. 倒入冰水
4. 轻轻搅拌
5. 不要搅拌太久，有小颗粒没关系
6. 保持面糊冰凉

**注意事项：** 面糊不要太稠，稀一些更好。

### 步骤3：裹面糊
**正在做什么：** 将食材裹上面糊。

**食材当前状态：** 食材已处理好，面糊已调好。

**操作要点：**
1. 食材表面沾上一层薄薄的面粉
2. 再裹上面糊
3. 多余的面糊要抖掉

**注意事项：** 面糊要薄薄的。

### 步骤4：油炸
**正在做什么：** 将天妇罗炸至金黄。

**食材当前状态：** 食材已裹好面糊。

**操作要点：**
1. 锅中倒油
2. 加热至170-180℃
3. 放入裹好面糊的食材
4. 中火炸2-3分钟
5. 炸至金黄色
6. 捞出沥油

**注意事项：** 油温要控制好，不能太低。

### 步骤5：制作蘸料
**正在做什么：** 调制天妇罗蘸料。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 酱油、味醂、高汤混合
2. 加入萝卜泥
3. 搅拌均匀

**注意事项：** 萝卜泥可以解腻。

### 步骤6：完成
**正在做什么：** 装盘。

**食材当前状态：** 天妇罗已炸好。

**操作要点：**
1. 摆放在盘中
2. 配上蘸料
3. 立即食用

**注意事项：** 要趁热吃，凉了就不脆了。

## 烹饪关键点/小贴士

1. **面糊**：面糊要冰的，炸出来才酥脆。
2. **油温**：油温要控制好，170-180℃最适合。
3. **面衣**：面糊要薄薄的，不要太厚。
4. **食材**：食材要保持干燥，不要有水分。
