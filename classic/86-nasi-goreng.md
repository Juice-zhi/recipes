# 印尼炒饭

## 菜系/国家
印度尼西亚菜 / 印度尼西亚

## 概述
印尼炒饭是印度尼西亚的经典主食，以米饭为主料，加入虾仁、鸡肉、鸡蛋等配料炒制。味道浓郁，带有独特的东南亚香料风味，是印尼的国菜。

## 份量/人数
4人份

## 所需餐具
- 炒锅
- 锅铲
- 盘子

## 食材清单

### 主料
- 米饭：500克
- 虾仁：150克
- 鸡胸肉：150克
- 鸡蛋：2个

### 辅料
- 洋葱：100克
- 胡萝卜：50克
- 青豆：50克
- 葱：30克

### 调料
- 印尼甜酱油（Kecap Manis）：40ml
- 酱油：20ml
- 辣椒酱：20克
- 虾酱：10克
- 咖喱粉：5克

### 油料
- 食用油：40ml
- 参巴酱（Sambal）：30克（可选）

## 详细步骤

### 步骤1：处理食材
**正在做什么：** 将所有食材切好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 虾仁去壳去虾线
2. 鸡肉切丁
3. 鸡蛋打散
4. 洋葱切丁
5. 胡萝卜切丁
6. 葱切碎

**注意事项：** 食材要切得大小均匀。

### 步骤2：炒配料
**正在做什么：** 将虾仁和鸡肉炒熟。

**食材当前状态：** 虾仁和鸡肉都是生的。

**操作要点：**
1. 锅中倒油
2. 油热后放入鸡肉
3. 炒至变色
4. 放入虾仁
5. 炒至变色后盛出

**注意事项：** 不要炒太久，保持嫩滑。

### 步骤3：炒鸡蛋
**正在做什么：** 将鸡蛋炒散。

**食材当前状态：** 鸡蛋已打散。

**操作要点：**
1. 锅中再倒少许油
2. 放入鸡蛋
3. 炒散
4. 盛出备用

**注意事项：** 鸡蛋要炒得嫩一些。

### 步骤4：炒饭
**正在做什么：** 将米饭炒热。

**食材当前状态：** 米饭是冷的。

**操作要点：**
1. 锅中倒油
2. 放入洋葱炒香
3. 加入咖喱粉
4. 放入米饭
5. 大火快速翻炒
6. 把米饭炒散

**注意事项：** 要用冷米饭，大火快炒。

### 步骤5：加入配料
**正在做什么：** 将所有配料放入炒匀。

**食材当前状态：** 饭已炒热。

**操作要点：**
1. 放入炒好的鸡肉和虾仁
2. 放入鸡蛋
3. 加入胡萝卜和青豆
4. 快速翻炒

**注意事项：** 要翻炒均匀。

### 步骤6：调味
**正在做什么：** 加入调料翻炒均匀。

**食材当前状态：** 所有材料已放入。

**操作要点：**
1. 加入印尼甜酱油
2. 加入酱油
3. 加入虾酱
4. 如果能吃辣，加入参巴酱
5. 快速翻炒均匀
6. 撒上葱花

**注意事项：** 甜酱油是印尼炒饭的关键。

### 步骤7：装盘
**正在做什么：** 将炒饭装盘。

**食材当前状态：** 炒饭已做好。

**操作要点：**
1. 盛入盘中
2. 可以配上煎蛋
3. 可以撒上炸葱片

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **米饭**：要用冷米饭，最好是隔夜饭。
2. **甜酱油**：印尼甜酱油是灵魂调料，不可用普通酱油代替。
3. **大火**：全程要大火快炒。
4. **配料**：可以根据个人喜好调整配料。
