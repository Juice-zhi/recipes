# 日式豚骨拉面

## 菜系/国家
日本料理 / 日本

## 概述
日式豚骨拉面是日本九州的经典拉面，以猪骨长时间熬制的浓白汤底为特色。汤头浓郁醇厚，配以叉烧、糖心蛋，是日本拉面的代表。

## 份量/人数
2人份

## 所需餐具
- 大汤锅
- 煮锅
- 碗

## 食材清单

### 汤底
- 猪骨：1000克
- 猪肘：500克
- 姜：30克
- 葱：50克
- 蒜：20克

### 面
- 日式拉面：300克

### 配料
- 叉烧：200克
- 糖心蛋：2个
- 紫菜：2片
- 葱花：30克
- 竹笋：50克

### 调料
- 酱油：30ml
- 味醂：15ml
- 盐：适量

## 详细步骤

### 步骤1：处理猪骨
**正在做什么：** 将猪骨焯水去腥。

**食材当前状态：** 猪骨是新鲜的。

**操作要点：**
1. 猪骨和猪肘洗净
2. 冷水下锅
3. 大火烧开
4. 撇去浮沫
5. 捞出洗净

**注意事项：** 要把血沫去干净。

### 步骤2：熬汤底
**正在做什么：** 长时间熬制猪骨汤。

**食材当前状态：** 猪骨已焯好。

**操作要点：**
1. 锅中加入足量水
2. 放入猪骨和猪肘
3. 加入姜、葱、蒜
4. 大火烧开
5. 转小火，保持微沸
6. 熬制4-6小时
7. 汤色变得浓白

**注意事项：** 要小火慢熬，不能用大火。

### 步骤3：调味汤底
**正在做什么：** 给汤底调味。

**食材当前状态：** 汤已熬好。

**操作要点：**
1. 过滤汤汁
2. 加入酱油调味
3. 加入味醂
4. 加入适量盐

**注意事项：** 汤底要调味适当。

### 步骤4：准备配料
**正在做什么：** 将配料准备好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 叉烧切薄片
2. 糖心蛋对半切开
3. 紫菜切小块
4. 竹笋切丝
5. 葱切花

**注意事项：** 配料要提前准备好。

### 步骤5：煮面
**正在做什么：** 将拉面煮熟。

**食材当前状态：** 拉面是干燥的。

**操作要点：**
1. 烧水，水开后放入拉面
2. 煮2-3分钟至软
3. 捞出沥干
4. 放入碗中

**注意事项：** 不要煮太久。

### 步骤6：组装
**正在做什么：** 将拉面和汤组装好。

**食材当前状态：** 面已煮好，汤已调好。

**操作要点：**
1. 拉面放入碗中
2. 浇上热汤
3. 摆上叉烧
4. 放上糖心蛋
5. 放上紫菜和竹笋
6. 撒上葱花

**注意事项：** 要趁热吃。

## 烹饪关键点/小贴士

1. **猪骨**：要选新鲜的猪骨，熬出的汤才浓白。
2. **火候**：要小火慢熬，至少4小时。
3. **调味**：酱油要慢慢加，边加边尝。
4. **叉烧**：可以买现成的，也可以自己制作。
