# 印度飞饼

## 菜系/国家
印度菜 / 印度

## 概述
印度飞饼是印度著名的街头美食，薄如蝉翼，口感酥脆。可以搭配各种馅料，如原味、蒜味、奶酪等，是印度最具代表性的面食之一。

## 份量/人数
4人份

## 所需餐具
- 平底锅
- 擀面杖
- 案板

## 食材清单

### 主料
- 面粉：250克
- 鸡蛋：1个
- 牛奶：120ml
- 盐：3克
- 糖：10克
- 黄油：30克

### 油料
- 食用油：30ml

### 配料（可选）
- 蒜蓉：10克
- 芝士碎：50克

## 详细步骤

### 步骤1：和面
**正在做什么：** 将面粉和其他材料揉成面团。

**食材当前状态：** 面粉是粉末状，其他材料是液体。

**操作要点：**
1. 面粉放入盆中
2. 加入盐和糖
3. 加入鸡蛋和牛奶
4. 揉成光滑的面团
5. 盖上湿布醒30分钟

**注意事项：** 面团要揉到光滑。

### 步骤2：制作油酥
**正在做什么：** 制作飞饼用的油酥。

**食材当前状态：** 黄油是固体。

**操作要点：**
1. 将黄油软化
2. 放入少量面粉
3. 搅拌成油酥状
4. 放入冰箱冷藏变硬

**注意事项：** 油酥不要太软。

### 步骤3：擀面皮
**正在做什么：** 将面团擀成薄片。

**食材当前状态：** 面团已醒好。

**操作要点：**
1. 醒好的面团分成4份
2. 取一份擀成圆形
3. 抹上油酥
4. 像折扇子一样折起
5. 再擀成薄片

**注意事项：** 要擀得尽量薄。

### 步骤4：加入配料
**正在做什么：** 在面皮上加入配料。

**食材当前状态：** 面皮已擀好。

**操作要点：**
1. 可以撒上蒜蓉
2. 或者放上芝士碎
3. 再轻轻擀一下，让配料附着

**注意事项：** 配料不要放太多。

### 步骤5：烙饼
**正在做什么：** 将飞饼烙熟。

**食材当前状态：** 飞饼已做好。

**操作要点：**
1. 平底锅烧热
2. 放入飞饼
3. 中火烙1-2分钟
4. 翻面再烙1分钟
5. 烙至两面金黄酥脆

**注意事项：** 火不能太大，会烤焦。

### 步骤6：出锅
**正在做什么：** 将烙好的飞饼装盘。

**食材当前状态：** 飞饼已烙好。

**操作要点：**
1. 取出飞饼
2. 可以用锅铲敲打，让它分层
3. 配上咖喱或其他酱料

**注意事项：** 趁热吃最酥脆。

## 烹饪关键点/小贴士

1. **面团**：面团要醒到位，才会柔软。
2. **油酥**：油酥是飞饼分层的关键。
3. **擀制**：要尽量擀薄，薄如蝉翼才好吃。
4. **火候**：烙的时候火不能太大。
