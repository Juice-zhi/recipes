# 冬阴功汤 (Tom Yum Soup)

## 菜系/国家
泰国菜 / 泰国

## 概述
冬阴功汤是泰国最著名的国汤，"冬阴"在泰语中是酸辣的意思，"功"是虾。这道汤以虾为主料，加入香茅、柠檬叶、南姜等泰国特色香料，酸辣开胃，香气浓郁，是泰国菜的代表作。

## 份量/人数
4人份

## 所需餐具
- 汤锅
- 漏勺
- 碗（盛汤用）
- 砧板和刀

## 食材清单

### 主料
- 鲜虾：300克（约12-15只）
- 草菇：150克（或其他蘑菇）

### 香料
- 香茅：30克（2根，切段）
- 柠檬叶：5片
- 南姜：20克（切片）
- 辣椒：30克（约4-6个，切圈）
- 鱼露：30ml（2大勺）
- 青柠汁：45ml（3大勺）

### 辅料
- 洋葱：50克（半个，切块）
- 番茄：100克（1个，切块）
- 香菜：15克（装饰用）

### 汤底
- 鸡汤或虾汤：1000ml

## 详细步骤

### 步骤1：虾的处理
**正在做什么：** 将虾处理干净。

**食材当前状态：** 鲜虾是带壳的虾，有虾线。

**操作要点：**
1. 将鲜虾洗净
2. 用剪刀剪去虾须和虾脚
3. 用牙签从虾背的第二节处挑出虾线
4. 去除虾线
5. 如果想要更美观，可以去虾壳留尾
6. 处理好的虾放入碗中备用

**注意事项：** 虾线一定要去除，否则会有腥味。保留虾壳可以让汤更鲜美。

### 步骤2：准备香料
**正在做什么：** 将所有香料准备好。

**食材当前状态：** 香茅、柠檬叶、南姜、辣椒等都是原始状态。

**操作要点：**
1. 香茅去掉外皮，只用白色的部分
2. 将香茅切段，约3厘米
3. 柠檬叶用手揉搓一下，释放香味
4. 南姜切片
5. 辣椒切成圈
6. 洋葱切块
7. 番茄切块
8. 草菇切片

**注意事项：** 香茅要用白色的部分，绿色的部分太硬。南姜不是生姜，味道不同。

### 步骤3：煮汤底
**正在做什么：** 煮香料汤底。

**食材当前状态：** 香料都准备好了，鸡汤也准备好了。

**操作要点：**
1. 汤锅中放入鸡汤1000ml
2. 放入香茅段
3. 放入柠檬叶
4. 放入南姜片
5. 大火烧开
6. 煮约10分钟，让香料出味
7. 煮出香味后

**注意事项：** 香料要煮出味道，但不要煮太久，否则会发苦。煮10分钟足够释放香味。

### 步骤4：加入蔬菜
**正在做什么：** 加入蔬菜煮熟。

**食材当前状态：** 香料汤底已经煮好。

**操作要点：**
1. 放入洋葱块
2. 放入草菇片
3. 放入番茄块
4. 煮约3-5分钟，让蔬菜变软

**注意事项：** 蔬菜不要煮太久，保持爽脆口感。番茄可以增加酸甜味。

### 步骤5：加入虾
**正在做什么：** 加入虾煮熟。

**食材当前状态：** 蔬菜已经在汤中。

**操作要点：**
1. 放入处理好的虾
2. 大火煮至虾变色
3. 虾变成粉红色即可
4. 约需2-3分钟
5. 不要煮太久，虾会变老

**注意事项：** 虾不要煮太久，变色后再煮1分钟即可。煮太久虾肉会变硬。

### 步骤6：调味
**正在做什么：** 调味，使汤呈现酸辣口味。

**食材当前状态：** 虾已经煮好，汤是基础的香料味。

**操作要点：**
1. 加入鱼露30ml
2. 加入青柠汁45ml
3. 放入辣椒圈
4. 搅拌均匀
5. 尝味道，适当调整
6. 酸度不够可以再加青柠汁
7. 辣度不够可以再加辣椒

**注意事项：** 鱼露是咸味的来源，不要放太多。青柠汁是酸味的来源，根据个人口味调整。

### 步骤7：出锅
**正在做什么：** 将汤装碗，撒上香菜。

**食材当前状态：** 冬阴功汤已经完成，酸辣香味扑鼻。

**操作要点：**
1. 将汤装入碗中
2. 放入虾和蔬菜
3. 撒上香菜装饰
4. 立即食用

**注意事项：** 冬阴功汤要趁热喝，凉了就不好喝了。香菜可以增添香气。

## 烹饪关键点/小贴士

1. **虾的选择**：要用新鲜的活虾或冰鲜虾。虾要处理干净，去除虾线。带壳的虾煮出来汤更鲜。

2. **香料选择**：香茅、柠檬叶、南姜是冬阴功的关键香料。可以在亚洲超市购买。

3. **酸度调节**：正宗的冬阴功要够酸。青柠汁比醋更有风味。酸度要尝着合适，不要太酸。

4. **辣度调节**：辣椒可以根据个人口味调整。泰国小辣椒很辣，要小心使用。

5. **鱼露用量**：鱼露是咸味的来源，也是鲜味的来源。不要放太多，会太咸。

6. **汤底选择**：可以用鸡汤、虾汤或清水。虾汤最鲜美，可以用虾头虾壳煮。

7. **食用注意**：冬阴功汤要趁热喝，凉了就不好喝了。可以配白米饭一起吃。
