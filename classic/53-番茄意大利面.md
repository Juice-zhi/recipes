# 番茄意大利面

## 菜系/国家
意大利菜 / 意大利

## 概述
番茄意大利面是意大利最经典的家常面食，以意面搭配新鲜番茄酱制成。简单美味，是意大利饮食文化的代表，在全球范围内广受欢迎。

## 份量/人数
2人份

## 所需餐具
- 深锅（煮意面）
- 炒锅
- 漏勺
- 盘子

## 食材清单

### 主料
- 意大利面：200克
- 新鲜番茄：400克（约4个）

### 调料
- 橄榄油：30ml
- 蒜末：10克
- 食盐：适量
- 黑胡椒：适量
- 帕尔玛干酪：30克（可选）
- 新鲜罗勒叶：10片

## 详细步骤

### 步骤1：煮意大利面
**正在做什么：** 将意面煮至弹牙。

**食材当前状态：** 意面是干燥的直条状。

**操作要点：**
1. 锅中加水，放入盐
2. 水开后下入意面
3. 煮8-10分钟至弹牙
4. 捞出沥干，保留100ml面汤

**注意事项：** 意面不要煮太软，要保持嚼劲。

### 步骤2：制作番茄酱
**正在做什么：** 将番茄炒成酱汁。

**食材当前状态：** 番茄是完整的。

**操作要点：**
1. 番茄顶部划十字，用开水烫后去皮
2. 切成小块
3. 锅中加橄榄油，爆香蒜末
4. 放入番茄块翻炒
5. 加盐调味，小火煮10分钟至酱汁浓稠

**注意事项：** 要将番茄炒出汁水，变成浓稠酱汁。

### 步骤3：拌匀出锅
**正在做什么：** 将意面和番茄酱拌匀。

**食材当前状态：** 意面已煮好，番茄酱已做好。

**操作要点：**
1. 将意面放入番茄酱锅中
2. 加入少许面汤，翻炒均匀
3. 撒上黑胡椒
4. 装盘后撒上帕尔玛干酪
5. 放上罗勒叶装饰

**注意事项：** 要让每根意面都裹上酱汁。

## 烹饪关键点/小贴士

1. **意面煮法**：加盐煮面，水量要足。
2. **番茄选择**：选择成熟的红番茄，酸味适中。
3. **保留面汤**：面汤可以让酱汁更好地附着在面上。
4. **橄榄油**：用特级初榨橄榄油风味更佳。
