# 宫保鸡丁

## 菜系/国家
川菜 / 中国四川

## 概述
宫保鸡丁是四川成都的传统名菜，由清朝四川总督丁宝桢创制，因其被封为"太子太保"而得名。这道菜以鸡肉为主料，配以花生米和干辣椒，呈现酸甜麻辣的复合口味，是最具代表性的川菜之一。

## 份量/人数
2-3人份

## 所需餐具
- 炒锅（最好是铁锅）
- 锅铲
- 漏勺
- 碗（调料碗和盛料碗）
- 盘子（盛装成品）

## 食材清单

### 主料
- 鸡胸肉：250克
- 花生米：50克

### 调料
- 干辣椒：8-10个（约10克）
- 花椒：3克
- 郫县豆瓣酱：10克（1小勺）
- 生抽（酱油）：15ml（1大勺）
- 老抽：3ml（半小勺）
- 醋：20ml（1大勺半）
- 白糖：15克（1大勺）
- 料酒：10ml（2小勺）
- 食盐：3克（约半小勺）
- 鸡精：2克（可选）

### 辅料
- 大葱：30克（半根，切成约1厘米的段）
- 姜：10克（2片，切末）
- 蒜：10克（2瓣，切末）
- 鸡蛋清：1个
- 水淀粉：30ml（淀粉15克+水15ml）

### 油料
- 食用油：60ml
- 麻油：3ml（半小勺）

## 详细步骤

### 步骤1：鸡肉腌制
**正在做什么：** 将鸡胸肉切丁后腌制上浆，使其保持嫩滑口感。

**食材当前状态：** 鸡胸肉是完整的肉块，表面湿润。

**操作要点：**
1. 将鸡胸肉洗净，用厨房纸巾吸干表面水分
2. 先在鸡肉表面撒入1克食盐，轻轻按摩帮助入味
3. 加入料酒5ml，继续按摩去腥
4. 打入鸡蛋清1个
5. 加入水淀粉10ml（淀粉5克+水5ml）
6. 用手轻轻抓匀，让鸡肉充分吸收调料
7. 表面滴几滴食用油，锁住水分
8. 腌制15分钟

**注意事项：** 腌制时手法要轻柔，不要过度用力搅拌，否则鸡肉会变柴。腌好的鸡肉应该看起来光滑有光泽。

### 步骤2：准备辅料
**正在做什么：** 将所有辅料和调料准备齐全，便于烹饪时使用。

**食材当前状态：** 花生米是完整的，干辣椒是整根的，其他调料都是原始状态。

**操作要点：**
1. 花生米提前用温水浸泡5分钟，便于去皮
2. 用手轻轻揉搓去掉花生红外衣，沥干水分
3. 将干辣椒去蒂，切成约1厘米的小段
4. 花椒和干辣椒段放在一起备用
5. 大葱切成约1厘米的段，葱白和葱叶分开放
6. 姜蒜切末备用
7. 调好水淀粉（淀粉15克+水15ml）
8. 调好宫保汁：生抽15ml + 老抽3ml + 醋20ml + 白糖15克 + 料酒5ml + 鸡精2克，搅拌至糖溶化

**注意事项：** 花生米去皮后炒出来更酥脆，颜色也更好看。宫保汁要提前调好，糖要完全溶化。

### 步骤3：炸花生米
**正在做什么：** 将花生米炸至酥脆金黄。

**食材当前状态：** 花生米是去皮后的白色颗粒，含有一定水分。

**操作要点：**
1. 锅中倒入40ml食用油，冷油下入花生米
2. 小火慢炸，不断翻动，使花生米受热均匀
3. 炸约3-4分钟，花生米颜色微微变黄
4. 继续小火炸至金黄色，表面有细小裂纹
5. 立即捞出，放在厨房纸上吸去多余油分
6. 完全冷却后会变得酥脆

**注意事项：** 一定要冷油下锅，小火慢炸，这样才能炸透且不糊。炸到金黄色就要捞出，余温会让颜色继续加深。

### 步骤4：滑炒鸡肉
**正在做什么：** 将腌好的鸡肉丁滑炒至变色，保持嫩滑。

**食材当前状态：** 鸡肉丁表面裹着薄薄的浆液，呈粉红色。

**操作要点：**
1. 锅中倒入20ml食用油，烧至五成热（约150°C）
2. 下入腌好的鸡肉丁，用筷子快速拨散
3. 保持中火，快速滑炒
4. 炒至鸡肉变色，表面微白，约需1-2分钟
5. 鸡肉八成熟时盛出，沥干油分备用

**注意事项：** 油温不要太高，保持中火快速滑炒。鸡肉丁下锅后要立即用筷子拨散，防止粘连。炒到八成熟即可，后面还要回锅。

### 步骤5：炒制底料
**正在做什么：** 炒制干辣椒、花椒和豆瓣酱，形成香辣底料。

**食材当前状态：** 锅中只有底油，干辣椒和花椒是干燥的。

**操作要点：**
1. 锅中留底油约15ml，烧热
2. 下入干辣椒段和花椒，小火慢炒
3. 炒至干辣椒颜色变深，开始出香味
4. 下入郫县豆瓣酱10克，快速翻炒
5. 炒出红油，约需30秒
6. 下入姜蒜末，炒出香味

**注意事项：** 干辣椒和花椒要小火炒，大火容易炒糊。小心不要炒太久，辣椒稍微变色就要下一步。

### 步骤6：回锅鸡肉
**正在做什么：** 将鸡肉倒回锅中，与底料快速翻炒均匀。

**食材当前状态：** 底料已经在锅中，红油透亮，香气四溢。

**操作要点：**
1. 放入滑炒过的鸡肉丁，大火快速翻炒
2. 翻炒均匀，让鸡肉裹上红油
3. 沿锅边淋入一点料酒去腥
4. 翻炒约30秒

**注意事项：** 这个步骤要大火快炒，保持鸡肉的嫩滑口感。

### 步骤7：加入调料
**正在做什么：** 倒入调好的宫保汁，大火收汁。

**食材当前状态：** 鸡肉已经裹上红油，锅中热度很高。

**操作要点：**
1. 将调好的宫保汁摇匀（糖可能沉淀）
2. 大火状态下，将宫保汁倒入锅中
3. 快速翻炒，让鸡肉均匀吸收味道
4. 汤汁开始变得浓稠
5. 下入葱白段，快速翻匀

**注意事项：** 宫保汁要摇匀后使用。倒入时要沿着锅边淋入，让高温激发醋的香味。

### 步骤8：加入花生米和完成
**正在做什么：** 最后加入炸好的花生米，翻炒均匀后出锅。

**食材当前状态：** 鸡肉已经充分吸收调料味道，汤汁浓稠。

**操作要点：**
1. 放入炸好的花生米
2. 快速翻匀，让花生米均匀分布
3. 沿锅边淋入麻油3ml，增香
4. 最后放入葱叶段，翻匀
5. 立即出锅，装入盘中

**注意事项：** 花生米要最后放，保持酥脆口感。如果放早了，花生米会变软不脆。

## 烹饪关键点/小贴士

1. **鸡肉选择**：选用鸡胸肉，肉质细嫩脂肪少。如果喜欢更香的口感，可以用鸡腿肉，但要去掉筋膜。

2. **腌制上浆**：鸡肉腌制时加入蛋清和水淀粉，形成保护膜，炒出来更加嫩滑。加油可以防止下锅时粘连。

3. **油温控制**：滑炒鸡肉时油温不要太高，五成热即可。太高温会让鸡肉表面立即变性，口感变硬。

4. **花生米技巧**：花生米要冷油下锅，小火慢炸。炸好后要完全冷却才会酥脆。可以提前炸好，用密封盒保存。

5. **调味平衡**：宫保味的核心是酸甜麻辣咸五味平衡。醋要用香醋或米醋，不要用陈醋味道太重。

6. **火候掌握**：整个烹饪过程要保持大火快炒，特别是最后收汁阶段，时间长了鸡肉会变老。

7. **增香技巧**：出锅前沿锅边淋少许醋和麻油，可以提升整体香气。

## 营养信息

- 热量：约400-450千卡
- 蛋白质：约35克
- 脂肪：约25克
- 碳水化合物：约20克

### 营养亮点
- 鸡肉是高蛋白低脂肪的优质肉类
- 花生含有丰富的维生素E和健康脂肪
- 青葱含有维生素C和膳食纤维
- 适量食用有益于增强体力
