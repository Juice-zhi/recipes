# 炸鸡

## 菜系/国家
美式菜 / 美国

## 概述
炸鸡是美国最具代表性的快餐食品，鸡肉裹上面粉糊炸至金黄酥脆。外皮酥脆，鸡肉多汁，是全球最受欢迎的美食之一。

## 份量/人数
4人份

## 所需餐具
- 炸锅
- 漏勺
- 碗
- 盘子

## 食材清单

### 主料
- 鸡翅中：500克
- 鸡腿：500克

### 裹粉材料
- 面粉：150克
- 玉米淀粉：50克
- 泡打粉：5克
- 盐：5克
- 黑胡椒：3克
- 辣椒粉：3克
- 大蒜粉：3克

### 油料
- 食用油：1000ml（实耗约200ml）

## 详细步骤

### 步骤1：处理鸡肉
**正在做什么：** 将鸡肉处理干净。

**食材当前状态：** 鸡肉是完整的。

**操作要点：**
1. 鸡翅和鸡腿洗净
2. 用厨房纸吸干水分
3. 在鸡肉上划几刀，便于入味

**注意事项：** 鸡肉一定要擦干，否则裹粉不牢固。

### 步骤2：调制裹粉
**正在做什么：** 调制炸鸡用的干粉。

**食材当前状态：** 各种粉类都是独立的。

**操作要点：**
1. 面粉、玉米淀粉、泡打粉放入碗中
2. 加入盐、黑胡椒、辣椒粉、大蒜粉
3. 搅拌均匀

**注意事项：** 裹粉要调得均匀。

### 步骤3：裹粉
**正在做什么：** 将鸡肉裹上面粉。

**食材当前状态：** 鸡肉已处理好，裹粉已调好。

**操作要点：**
1. 将鸡肉放入裹粉中
2. 用力按压，让裹粉附着
3. 抖掉多余的面粉
4. 静置10分钟，让裹粉回潮

**注意事项：** 要裹得均匀，不要太厚。

### 步骤4：油炸
**正在做什么：** 将鸡肉炸至金黄。

**食材当前状态：** 鸡肉已裹好粉。

**操作要点：**
1. 锅中倒入足量油
2. 加热至170℃
3. 放入鸡肉
4. 中火炸8-10分钟
5. 捞出沥油
6. 油温升至190℃后复炸2分钟

**注意事项：** 油温要控制好，不要太高。

### 步骤5：完成
**正在做什么：** 将炸鸡装盘。

**食材当前状态：** 炸鸡已炸好。

**操作要点：**
1. 捞出沥油
2. 放在架子上控油
3. 撒上少许盐
4. 配上喜欢的酱料

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **鸡肉**：选择新鲜的鸡肉，水分要擦干。
2. **裹粉**：加入玉米淀粉可以让外皮更酥脆。
3. **复炸**：复炸是酥脆的关键。
4. **油温**：油温170℃最适合初炸。
