# 宫保鸡丁

## 菜系/国家
川菜 / 中国四川

## 概述
宫保鸡丁是四川传统名菜，由清朝官员丁宝桢创制。鸡肉鲜嫩，花生酥脆，口味酸甜微辣，是最具代表性的川菜之一，风靡全球。

## 份量/人数
3-4人份

## 所需餐具
- 炒锅
- 碗（腌料用）
- 盘子

## 食材清单

### 主料
- 鸡胸肉：300克
- 花生米：100克

### 调料
- 干辣椒：10克（约8个）
- 花椒：3克
- 郫县豆瓣酱：15克
- 醋：20ml
- 白糖：20克
- 酱油：15ml
- 料酒：15ml
- 淀粉：15克
- 食盐：适量

### 辅料
- 姜片：5克
- 蒜片：5克
- 葱段：30克

### 油料
- 食用油：50ml

## 详细步骤

### 步骤1：处理鸡肉
**正在做什么：** 将鸡胸肉切丁腌制。

**食材当前状态：** 鸡胸肉是整块的。

**操作要点：**
1. 鸡胸肉切成约1.5厘米的丁
2. 放入碗中，加盐、料酒、淀粉抓匀
3. 倒入少许油，腌制15分钟

**注意事项：** 鸡肉要切得大小均匀，腌制时加少许油可使鸡肉更滑嫩。

### 步骤2：炸花生米
**正在做什么：** 将花生米炸至酥脆。

**食材当前状态：** 花生米是生的。

**操作要点：**
1. 锅中倒入油，冷油下花生米
2. 小火慢炸至金黄酥脆
3. 捞出沥油，放凉备用

**注意事项：** 要冷油下锅，小火炸制，才能炸透炸脆。

### 步骤3：炒制鸡肉
**正在做什么：** 将鸡肉炒至变色。

**食材当前状态：** 鸡肉已腌制好。

**操作要点：**
1. 锅中倒油，烧热
2. 下入鸡丁，快速滑炒
3. 炒至变色后盛出备用

**注意事项：** 要大火快炒，保持鸡肉嫩滑。

### 步骤4：炒制底料
**正在做什么：** 炒制干辣椒和花椒。

**食材当前状态：** 锅中只有油。

**操作要点：**
1. 锅中留底油
2. 下入干辣椒段和花椒，小火炒香
3. 加入姜蒜片炒香
4. 加入郫县豆瓣酱炒出红油

**注意事项：** 干辣椒和花椒不要炒糊。

### 步骤5：合炒出锅
**正在做什么：** 将鸡肉和花生米一起炒匀。

**食材当前状态：** 鸡肉已炒好，花生米已炸好，底料已炒好。

**操作要点：**
1. 放入鸡丁翻炒均匀
2. 加入酱油、糖、醋调味
3. 放入葱段和炸好的花生米
4. 快速翻匀出锅

**注意事项：** 花生米要最后放，保持酥脆。

## 烹饪关键点/小贴士

1. **鸡肉**：鸡胸肉要切得大小均匀，腌制上劲。
2. **花生**：花生米要冷油下锅，小火炸透。
3. **火候**：整个过程要大火快炒，保持鸡肉嫩滑。
4. **调味**：糖醋比例要适中，酸甜微辣。
