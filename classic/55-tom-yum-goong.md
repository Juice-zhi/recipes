# 冬阴功汤

## 菜系/国家
泰国菜 / 泰国

## 概述
冬阴功汤是泰国最著名的酸辣海鲜汤，"冬阴"在泰语中是酸辣的意思，"功"是虾。汤味道浓郁，酸辣开胃，带有独特的泰国香料风味，是泰国菜的代表。

## 份量/人数
4人份

## 所需餐具
- 汤锅
- 碗

## 食材清单

### 主料
- 鲜虾：300克
- 草菇：150克

### 调料
- 冬阴功酱：60克
- 鱼露：30ml
- 椰浆：100ml
- 柠檬汁：30ml
- 柠檬叶：4片
- 香茅：1根
- 辣椒：3个

### 辅料
- 洋葱：50克
- 姜：20克

### 汤底
- 鸡汤：1000ml

## 详细步骤

### 步骤1：处理虾
**正在做什么：** 将虾处理干净。

**食材当前状态：** 虾是带壳的。

**操作要点：**
1. 虾去壳，留下虾尾
2. 挑去虾线
3. 用少许盐和柠檬汁腌制

**注意事项：** 虾线要去除干净，否则会有腥味。

### 步骤2：准备香料
**正在做什么：** 将香料切好备用。

**食材当前状态：** 香料都是完整的。

**操作要点：**
1. 香茅切段，用刀拍松
2. 柠檬叶去梗
3. 辣椒切段
4. 洋葱切块
5. 姜切片
6. 草菇对半切开

**注意事项：** 香茅要拍松才能释放香味。

### 步骤3：煮汤底
**正在做什么：** 将香料煮出味道。

**食材当前状态：** 锅中是鸡汤。

**操作要点：**
1. 鸡汤放入锅中
2. 加入香茅、柠檬叶、姜
3. 大火烧开
4. 转小火煮10分钟

**注意事项：** 要让香料的味道充分释放。

### 步骤4：加入冬阴功酱
**正在做什么：** 加入冬阴功酱调味。

**食材当前状态：** 汤底已做好。

**操作要点：**
1. 放入冬阴功酱
2. 搅拌均匀
3. 放入草菇煮3分钟
4. 加入椰浆

**注意事项：** 椰浆要最后放，避免煮沸分离。

### 步骤5：加入虾和其他调料
**正在做什么：** 加入虾和调味料。

**食材当前状态：** 汤已调好味。

**操作要点：**
1. 放入虾，煮至变色
2. 加入鱼露调味
3. 加入柠檬汁
4. 放入辣椒

**注意事项：** 虾不要煮太久，会变老。

### 步骤6：装盘
**正在做什么：** 将汤盛入碗中。

**食材当前状态：** 汤已煮好。

**操作要点：**
1. 盛入碗中
2. 可以加少许香菜装饰

**注意事项：** 趁热喝风味最佳。

## 烹饪关键点/小贴士

1. **虾**：选择新鲜的大虾，虾肉更鲜甜。
2. **椰浆**：椰浆可以让汤更浓郁顺滑。
3. **柠檬汁**：要最后放，避免煮太久失去酸味。
4. **辣度**：根据个人口味调整辣椒用量。
