# 泰式炒饭

## 菜系/国家
泰国菜 / 泰国

## 概述
泰式炒饭是泰国最具代表性的主食之一，以米饭为主料，加入虾、蟹肉、鸡蛋等配料，用泰国鱼露和罗勒调味。酸甜可口，带有独特的泰国风味。

## 份量/人数
2人份

## 所需餐具
- 炒锅
- 锅铲
- 盘子

## 食材清单

### 主料
- 米饭：400克
- 虾仁：150克
- 蟹肉：100克
- 鸡蛋：2个

### 辅料
- 洋葱：80克
- 青豆：50克
- 葱：30克
- 泰国罗勒：20克

### 调料
- 泰国鱼露：30ml
- 糖：15克
- 泰国辣酱：20克
- 白胡椒粉：3克
- 虾酱：10克

### 油料
- 食用油：40ml

### 配食
- 青柠：1个
- 辣椒：2个

## 详细步骤

### 步骤1：处理食材
**正在做什么：** 将所有食材准备好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 虾仁去壳去虾线
2. 蟹肉撕成丝
3. 鸡蛋打散
4. 洋葱切丁
5. 葱切段
6. 罗勒叶备用

**注意事项：** 食材要提前准备好。

### 步骤2：炒配料
**正在做什么：** 将虾仁和蟹肉炒熟。

**食材当前状态：** 虾仁和蟹肉是生的。

**操作要点：**
1. 锅中倒油
2. 油热后放入虾仁
3. 炒至变色
4. 放入蟹肉
5. 炒至变色后盛出

**注意事项：** 不要炒太久。

### 步骤3：炒鸡蛋
**正在做什么：** 将鸡蛋炒散。

**食材当前状态：** 鸡蛋已打散。

**操作要点：**
1. 锅中再倒少许油
2. 放入鸡蛋
3. 炒散
4. 盛出备用

**注意事项：** 鸡蛋要炒得嫩一些。

### 步骤4：炒饭
**正在做什么：** 将米饭炒热。

**食材当前状态：** 米饭是冷的。

**操作要点：**
1. 锅中倒油
2. 放入洋葱炒香
3. 放入米饭
4. 大火快速翻炒
5. 把米饭炒散

**注意事项：** 要用冷米饭，大火快炒。

### 步骤5：加入配料
**正在做什么：** 将所有配料放入炒匀。

**食材当前状态：** 饭已炒热。

**操作要点：**
1. 放入炒好的虾仁和蟹肉
2. 放入鸡蛋
3. 加入青豆
4. 快速翻炒

**注意事项：** 要翻炒均匀。

### 步骤6：调味
**正在做什么：** 加入调料翻炒均匀。

**食材当前状态：** 所有材料已放入。

**操作要点：**
1. 加入鱼露
2. 加入糖
3. 加入虾酱
4. 加入白胡椒粉
5. 快速翻炒均匀
6. 放入葱段和罗勒

**注意事项：** 鱼露是泰式炒饭的灵魂。

### 步骤7：装盘
**正在做什么：** 将炒饭装盘。

**食材当前状态：** 泰式炒饭已做好。

**操作要点：**
1. 盛入盘中
2. 摆上青柠块
3. 放上辣椒圈

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **米饭**：要用冷米饭，最好是隔夜饭。
2. **鱼露**：泰国鱼露是灵魂调料。
3. **大火**：全程要大火快炒。
4. **罗勒**：泰国罗勒是不可缺少的调料。
