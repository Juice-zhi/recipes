# 辣子鸡

## 菜系/国家
川菜 / 中国四川

## 概述
辣子鸡是四川经典名菜，以鸡肉为主料，用大量干辣椒和花椒炒制。麻辣酥香，是川菜中非常受欢迎的菜肴，也是下酒好菜。

## 份量/人数
3-4人份

## 所需餐具
- 炒锅
- 漏勺
- 盘子

## 食材清单

### 主料
- 鸡腿肉：500克

### 腌料
- 盐：5克
- 料酒：15ml
- 生抽：15ml
- 淀粉：20克

### 调料
- 干辣椒：80克
- 花椒：20克
- 郫县豆瓣酱：15克
- 姜：15克
- 蒜：15克

### 油料
- 食用油：500ml（实耗约80ml）

## 详细步骤

### 步骤1：处理鸡肉
**正在做什么：** 将鸡肉切块腌制。

**食材当前状态：** 鸡腿肉是整块的。

**操作要点：**
1. 鸡腿去骨，切成约2厘米的块
2. 放入碗中
3. 加盐、料酒、生抽
4. 加入淀粉抓匀
5. 腌制30分钟

**注意事项：** 鸡肉要切得大小均匀。

### 步骤2：准备辣椒
**正在做什么：** 将干辣椒剪成段。

**食材当前状态：** 干辣椒是完整的。

**操作要点：**
1. 干辣椒去蒂
2. 剪成约2厘米的段
3. 去掉部分辣椒籽
4. 花椒准备好

**注意事项：** 辣椒籽可以去掉一部分，减少辣度。

### 步骤3：炸鸡肉
**正在做什么：** 将鸡肉炸至金黄。

**食材当前状态：** 鸡肉已腌制好。

**操作要点：**
1. 锅中倒入足量油
2. 烧至六成热（160℃）
3. 放入鸡肉块
4. 中火炸至金黄
5. 捞出沥油
6. 油温升至八成热（180℃）
7. 复炸一次至酥脆

**注意事项：** 复炸是关键，使外皮酥脆。

### 步骤4：炒香料
**正在做什么：** 炒香辣椒和花椒。

**食材当前状态：** 鸡肉已炸好。

**操作要点：**
1. 锅中留底油
2. 放入姜蒜片炒香
3. 放入豆瓣酱炒出红油
4. 放入干辣椒段和花椒
5. 小火炒出香味

**注意事项：** 辣椒和花椒不要炒糊。

### 步骤5：加入鸡肉
**正在做什么：** 将鸡肉放入锅中翻炒。

**食材当前状态：** 香料已炒好。

**操作要点：**
1. 放入炸好的鸡肉
2. 快速翻炒
3. 让鸡肉均匀裹上辣椒和花椒
4. 翻炒均匀出锅

**注意事项：** 要快速翻动。

### 步骤6：装盘
**正在做什么：** 将辣子鸡装盘。

**食材当前状态：** 鸡肉已炒好。

**操作要点：**
1. 盛入盘中
2. 可以撒上少许芝麻
3. 配上一些香菜

**注意事项：** 要趁热吃。

## 烹饪关键点/小贴士

1. **复炸**：一定要复炸，外皮才会酥脆。
2. **辣椒**：干辣椒用量要足够多，这是辣子鸡的特点。
3. **火候**：炸鸡肉时油温要控制好。
4. **炒制**：最后翻炒要快，保持鸡肉酥脆。
