# 狮子头

## 菜系/国家
淮扬菜 / 中国江苏

## 概述
狮子头是江苏扬州的经典名菜，以猪肉为主料，制成拳头大小的肉圆，红烧而成。肉质软嫩，入口即化，是淮扬菜的代表作。

## 份量/人数
4人份

## 所需餐具
- 炒锅
- 蒸锅
- 盘子

## 食材清单

### 主料
- 猪五花肉：500克
- 虾仁：100克

### 辅料
- 荸荠：100克
- 葱：30克
- 姜：20克

### 调料
- 盐：5克
- 料酒：20ml
- 生抽：30ml
- 老抽：10ml
- 糖：15克
- 淀粉：30克
- 鸡蛋：1个

### 油料
- 食用油：500ml（实耗约50ml）

## 详细步骤

### 步骤1：处理食材
**正在做什么：** 将猪肉和配料处理好。

**食材当前状态：** 猪肉是整块的。

**操作要点：**
1. 五花肉去皮，先切丁再剁成肉末
2. 不要剁太细，要保持颗粒感
3. 虾仁去虾线，剁成虾泥
4. 荸荠去皮切碎
5. 葱姜切末

**注意事项：** 肉要自己剁，不要用绞肉机。

### 步骤2：调肉馅
**正在做什么：** 将肉馅调味并搅拌上劲。

**食材当前状态：** 食材都准备好了。

**操作要点：**
1. 肉末放入大碗中
2. 加入虾泥
3. 加入荸荠碎
4. 加入葱姜末
5. 加入盐、料酒、生抽
6. 加入蛋清和淀粉
7. 顺着一个方向搅拌
8. 搅拌至肉馅起胶

**注意事项：** 要顺着一个方向搅拌。

### 步骤3：做成肉圆
**正在做什么：** 将肉馅做成大肉圆。

**食材当前状态：** 肉馅已调好。

**操作要点：**
1. 用手将肉馅团成约拳头大小的圆
2. 表面要光滑
3. 做成4-6个狮子头

**注意事项：** 要团得紧实，不要松散。

### 步骤4：煎制
**正在做什么：** 将狮子头煎至表面金黄。

**食材当前状态：** 肉圆已做好。

**操作要点：**
1. 锅中倒油
2. 油热后放入狮子头
3. 中火煎至表面金黄
4. 翻面再煎
5. 煎至四面金黄

**注意事项：** 要中小火煎，不要太大火。

### 步骤5：红烧
**正在做什么：** 将狮子头红烧入味。

**食材当前状态：** 狮子头已煎好。

**操作要点：**
1. 放入姜片
2. 加入生抽和老抽
3. 加入糖
4. 加入适量水，没过狮子头
5. 大火烧开
6. 转小火炖1小时

**注意事项：** 要小火慢炖。

### 步骤6：装盘
**正在做什么：** 将狮子头装盘。

**食材当前状态：** 狮子头已炖好。

**操作要点：**
1. 捞出狮子头放入盘中
2. 浇上汤汁
3. 可以配上青菜装饰

**注意事项：** 要趁热吃。

## 烹饪关键点/小贴士

1. **选肉**：要选肥瘦相间的五花肉。
2. **刀工**：肉要自己剁，保持颗粒感。
3. **搅拌**：要顺着一个方向搅拌上劲。
4. **火候**：要小火慢炖，才会软烂。
