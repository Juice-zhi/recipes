# 回锅肉

## 菜系/国家
川菜 / 中国四川

## 概述
回锅肉是四川传统名菜，以煮熟的五花肉再回锅炒制得名。颜色红亮，肥而不腻，是川菜中最具代表性的家常菜之一。

## 份量/人数
3-4人份

## 所需餐具
- 炒锅
- 锅铲
- 盘子

## 食材清单

### 主料
- 五花肉：400克

### 辅料
- 青蒜：100克
- 郫县豆瓣酱：30克
- 甜面酱：10克

### 配料
- 姜：10克
- 蒜：10克
- 葱：20克

### 调料
- 食用油：30ml
- 料酒：15ml
- 糖：5克

## 详细步骤

### 步骤1：煮肉
**正在做什么：** 将五花肉煮熟。

**食材当前状态：** 五花肉是生的。

**操作要点：**
1. 五花肉洗净
2. 放入锅中，加水没过肉
3. 加入姜片、葱段、料酒
4. 大火烧开，转中火煮30分钟
5. 煮到能用筷子扎透即可
6. 捞出放凉

**注意事项：** 肉要煮到断生，但不要太软。

### 步骤2：切肉
**正在做什么：** 将煮熟的肉切成薄片。

**食材当前状态：** 五花肉已煮熟并放凉。

**操作要点：**
1. 放凉的肉切成约3毫米厚的薄片
2. 要尽量切得薄厚均匀

**注意事项：** 肉要放凉后再切，否则会散。

### 步骤3：炒肉片
**正在做什么：** 将肉片炒至出油。

**食材当前状态：** 肉片是生的。

**操作要点：**
1. 锅中倒入少许油
2. 放入肉片
3. 小火煸炒
4. 炒至肉片出油，边缘微卷
5. 盛出备用

**注意事项：** 要小火慢炒，把油煸出来。

### 步骤4：炒辅料
**正在做什么：** 炒香豆瓣酱和配料。

**食材当前状态：** 肉已盛出，锅中只有油。

**操作要点：**
1. 锅中留底油
2. 放入郫县豆瓣酱
3. 小火炒出红油
4. 放入姜蒜片炒香

**注意事项：** 豆瓣酱要炒出红油。

### 步骤5：合炒
**正在做什么：** 将肉片和辅料一起炒匀。

**食材当前状态：** 底料已炒好。

**操作要点：**
1. 放入肉片
2. 加入甜面酱
3. 加入糖
4. 快速翻炒均匀

**注意事项：** 要让肉片均匀裹上酱料。

### 步骤6：加入青蒜
**正在做什么：** 加入青蒜增香。

**食材当前状态：** 肉已炒好。

**操作要点：**
1. 放入切好的青蒜
2. 快速翻炒
3. 青蒜稍微变软即可出锅

**注意事项：** 青蒜不要炒太久。

## 烹饪关键点/小贴士

1. **选肉**：要选肥瘦相间的五花肉。
2. **煮肉**：肉不要煮得太软，否则切不成形。
3. **煸炒**：要把肥肉中的油煸出来，才不会腻。
4. **豆瓣酱**：郫县豆瓣酱是回锅肉的关键。
