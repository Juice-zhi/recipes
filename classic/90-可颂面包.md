# 可颂面包

## 菜系/国家
法国菜 / 法国

## 概述
可颂面包是法国的经典糕点，以黄油面团折叠多次制成。层层酥脆，是法国人早餐的经典选择，也是世界最著名的法式面包之一。

## 份量/人数
8个

## 所需餐具
- 烤箱
- 案板
- 擀面杖
- 保鲜膜

## 食材清单

### 面团
- 高筋面粉：250克
- 低筋面粉：50克
- 酵母：5克
- 糖：30克
- 盐：5克
- 牛奶：150ml
- 黄油：30克（面团用）

### 包裹用黄油
- 黄油：150克（裹入用）

### 蛋液
- 鸡蛋：1个

## 详细步骤

### 步骤1：和面
**正在做什么：** 将面团揉好。

**食材当前状态：** 面粉是粉末。

**操作要点：**
1. 高筋面粉、低筋面粉放入盆中
2. 加入酵母、糖、盐
3. 加入牛奶
4. 揉成面团
5. 加入30克黄油
6. 揉至光滑
7. 盖上保鲜膜，室温发酵1小时

**注意事项：** 面团不要揉太久。

### 步骤2：包裹黄油
**正在做什么：** 将黄油包入面团。

**食材当前状态：** 面团已发酵好，黄油是硬的。

**操作要点：**
1. 黄油切成薄片
2. 发酵好的面团排气
3. 擀成约15厘米的正方形
4. 把黄油片放在中间
5. 四周折起，封口
6. 擀成长方形

**注意事项：** 黄油要硬，不能软化。

### 步骤3：折叠
**正在做什么：** 将面团反复折叠。

**食材当前状态：** 面团已包入黄油。

**操作要点：**
1. 擀成长方形
2. 从中间对折
3. 再对折（三折）
4. 放入冰箱冷藏30分钟
5. 重复这个步骤3次

**注意事项：** 每次折叠后都要冷藏。

### 步骤4：整形
**正在做什么：** 将面团做成牛角形。

**食材当前状态：** 面团已折叠好。

**操作要点：**
1. 面团擀成约0.5厘米厚
2. 切成三角形
3. 从底部向上卷起
4. 弯成牛角形

**注意事项：** 要卷得紧实。

### 步骤5：发酵
**正在做什么：** 让可颂发酵。

**食材当前状态：** 可颂已整形。

**操作要点：**
1. 放在烤盘上
2. 盖上保鲜膜
3. 室温发酵约1小时
4. 发酵至1.5倍大

**注意事项：** 发酵时间要足够。

### 步骤6：烤制
**正在做什么：** 将可颂烤熟。

**食材当前状态：** 可颂已发酵好。

**操作要点：**
1. 烤箱预热至200℃
2. 表面刷上蛋液
3. 放入烤箱
4. 烤15-18分钟
5. 烤至金黄色

**注意事项：** 观察颜色，避免烤焦。

### 步骤7：完成
**正在做什么：** 取出放凉。

**食材当前状态：** 可颂已烤好。

**操作要点：**
1. 从烤箱取出
2. 放在架子上冷却
3. 趁热或冷却后食用

**注意事项：** 冷却后会更好切。

## 烹饪关键点/小贴士

1. **黄油**：黄油的质量决定可颂的口感。
2. **折叠**：折叠次数要足够，层数才够多。
3. **发酵**：发酵要到位，但不要发过头。
4. **温度**：烤的时候要注意观察。
