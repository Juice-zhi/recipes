# 马来拉面

## 菜系/国家
马来西亚菜 / 马来西亚

## 概述
马来拉面是马来西亚的经典面食，以咖喱汤底配以面条、牛肉丸、豆腐泡等配料。汤头浓郁，辛辣可口，是马来西亚华人社区的代表性美食。

## 份量/人数
2人份

## 所需餐具
- 汤锅
- 炒锅
- 碗

## 食材清单

### 主料
- 拉面：300克
- 牛肉丸：150克
- 豆泡：100克

### 汤底
- 咖喱酱：60克
- 椰浆：200ml
- 鸡汤：800ml

### 辅料
- 豆芽：100克
- 葱：30克
- 香蕉叶：若干（装饰用）

### 调料
- 盐：适量
- 糖：10克

## 详细步骤

### 步骤1：制作咖喱汤底
**正在做什么：** 熬制咖喱汤底。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 锅中放入咖喱酱
2. 小火炒出香味
3. 加入鸡汤
4. 大火烧开
5. 加入椰浆
6. 搅拌均匀
7. 加入盐和糖调味

**注意事项：** 要把咖喱酱炒出香味。

### 步骤2：处理配料
**正在做什么：** 将配料准备好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 牛肉丸对半切开
2. 豆泡洗净
3. 豆芽洗净
4. 葱切碎

**注意事项：** 配料要提前准备好。

### 步骤3：煮面
**正在做什么：** 将拉面煮熟。

**食材当前状态：** 拉面是干燥的。

**操作要点：**
1. 烧水，水开后放入拉面
2. 煮3-4分钟至软
3. 捞出沥干水分
4. 放入碗中

**注意事项：** 面不要煮太久。

### 步骤4：加热汤和配料
**正在做什么：** 将汤底和配料加热。

**食材当前状态：** 汤底已做好。

**操作要点：**
1. 咖喱汤重新烧开
2. 放入牛肉丸
3. 放入豆泡
4. 煮3分钟至入味

**注意事项：** 牛肉丸要煮透。

### 步骤5：组装
**正在做什么：** 将面和汤组装好。

**食材当前状态：** 面已煮好，汤已做好。

**操作要点：**
1. 拉面放入碗中
2. 浇上咖喱汤
3. 放上牛肉丸和豆泡
4. 放上豆芽
5. 撒上葱花

**注意事项：** 汤要足够热。

### 步骤6：完成
**正在做什么：** 上桌。

**食材当前状态：** 马来拉面已做好。

**操作要点：**
1. 可以用香蕉叶装饰
2. 配上辣椒酱

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **咖喱酱**：要选择正宗的马来咖喱酱。
2. **椰浆**：椰浆可以让汤底更浓郁。
3. **火候**：咖喱酱要先炒出香味。
4. **配料**：可以添加其他喜欢的配料。
