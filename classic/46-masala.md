# 印度玛萨拉 (Masala)

## 菜系/国家
印度菜 / 印度

## 概述
印度玛萨拉是指印度混合香料，是印度料理的灵魂。玛萨拉种类繁多，最常用的是 garam masala（辣味混合香料）和 curry powder（咖喱粉）。这些香料混合了多种天然香料，为印度菜肴增添独特的风味。

## 份量/人数
制作约50克

## 所需餐具
- 炒锅
- 研磨机或研钵
- 漏勺

## 详细步骤

### 步骤1：炒香料
**正在做什么：** 将香料炒香。

**操作要点：**
1. 将所有香料放入锅中
2. 小火翻炒
3. 不断翻炒
4. 炒至香料出香味
5. 约需3-5分钟
6. 注意不要炒糊

**注意事项：** 要用小火翻炒，大火会炒糊。炒到出香味即可。

### 步骤2：研磨
**正在做什么：** 将炒好的香料磨成粉。

**操作要点：**
1. 香料冷却后
2. 放入研磨机
3. 研磨成细粉
4. 或者用研钵研磨
5. 研磨成均匀的粉末

**注意事项：** 香料要完全冷却后再研磨。研磨要均匀，不要有颗粒。

### 步骤3：保存
**正在做什么：** 保存玛萨拉。

**操作要点：**
1. 研磨好的玛萨拉
2. 放入密封罐中
3. 放在阴凉处保存
4. 可以保存半年

**注意事项：** 要避免光照和潮湿。保存时间久了香味会变淡。

## 烹饪关键点/小贴士

1. **香料选择**：要用新鲜的香料。陈旧的香料香味不足。

2. **火候**：炒香料要用小火，不断翻炒。不要炒太久，会发苦。

3. **研磨**：研磨要均匀，颗粒要细。粗细不一会影响口感。

4. **保存**：玛萨拉要密封保存，避免光照。保存时间越长，味道越淡。

5. **使用**：玛萨拉在烹饪开始时加入，和食材一起炒香。
