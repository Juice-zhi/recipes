# 法式蜗牛 (Escargots)

## 菜系/国家
法国菜 / 法国

## 概述
法式蜗牛是法国最著名的前菜之一，以食用蜗牛为主料，用大蒜、欧芹、黄油烤制而成。这道菜蜗牛鲜嫩，黄油蒜香浓郁，是法国料理中的经典美味。

## 份量/人数
4人份（12只蜗牛）

## 所需餐具
- 烤箱
- 蜗牛盘或烤盘
- 刀
- 碗

## 食材清单

### 主料
- 食用蜗牛：12只（罐装）

### 蒜蓉黄油
- 黄油：100克（软化）
- 蒜：30克（6瓣，切成末）
- 欧芹：20克（切末）
- 盐：2克
- 黑胡椒：2克

### 配料
- 面包屑：30克
- 柠檬：1个

## 详细步骤

### 步骤1：处理蜗牛
**正在做什么：** 将蜗牛处理干净。

**操作要点：**
1. 如果使用罐装蜗牛，打开罐头
2. 取出蜗牛肉
3. 清洗干净
4. 沥干水分

**注意事项：** 罐装蜗牛已经是处理好的，直接使用即可。

### 步骤2：制作蒜蓉黄油
**正在做什么：** 制作蒜蓉黄油酱。

**操作要点：**
1. 黄油软化
2. 放入碗中
3. 加入蒜末
4. 加入欧芹末
5. 加入盐和黑胡椒
6. 搅拌均匀

**注意事项：** 黄油要软化，但不要融化。蒜末要切得细腻。

### 步骤3：组装
**正在做什么：** 将蜗牛放入盘中。

**操作要点：**
1. 蜗牛盘每个孔中放入1只蜗牛
2. 在每只蜗牛上放上蒜蓉黄油
3. 撒上面包屑
4. 滴几滴柠檬汁

**注意事项：** 黄油要放够量，这样才好吃。面包屑可以吸收水分。

### 步骤4：烤制
**正在做什么：** 将蜗牛烤熟。

**操作要点：**
1. 烤箱预热至200°C
2. 放入蜗牛盘
3. 烤约8-10分钟
4. 直到黄油融化，起泡
5. 表面金黄

**注意事项：** 烤的时间不要太长，蜗牛已经预处理过。烤到黄油融化即可。

### 步骤5：上桌
**正在做什么：** 法式蜗牛完成。

**操作要点：**
1. 取出烤好的蜗牛
2. 配上法棍面包
3. 趁热食用
4. 用蜗牛叉取出蜗牛食用

**注意事项：** 法式蜗牛要趁热吃，黄油蒜香才浓郁。

## 烹饪关键点/小贴士

1. **蜗牛选择**：通常使用罐装食用蜗牛，处理好的可以直接使用。

2. **黄油**：黄油是法式蜗牛的关键，要用质量好的无盐黄油。

3. **蒜和欧芹**：蒜和欧芹的用量要够，这样香味才浓郁。

4. **烤制**：烤箱温度要准确，不要烤太久。黄油融化即可。

5. **食用方法**：配上法棍面包，用蜗牛叉食用。面包可以蘸着黄油吃。
