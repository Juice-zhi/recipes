# 炒面

## 菜系/国家
中餐 / 中国广东

## 概述
炒面是广东茶餐厅的经典主食，以面条为主料，加入肉丝、豆芽、韭黄等配料炒制。面条爽滑，配料丰富，是广东地区的代表性美食。

## 份量/人数
2人份

## 所需餐具
- 炒锅
- 锅铲
- 盘子

## 食材清单

### 主料
- 细面条：300克
- 猪肉：100克
- 豆芽：100克
- 韭黄：50克

### 腌肉料
- 生抽：10ml
- 淀粉：5克
- 油：少许

### 调料
- 老抽：15ml
- 生抽：20ml
- 蚝油：10ml
- 食盐：2克
- 胡椒粉：少许

### 辅料
- 葱：30克
- 姜：10克
- 蒜：10克

### 油料
- 食用油：40ml

## 详细步骤

### 步骤1：处理面条
**正在做什么：** 将面条蒸软。

**食材当前状态：** 干面条或鲜面条。

**操作要点：**
1. 锅中烧水，水开后放入面条
2. 煮至七分熟，约3分钟
3. 捞出沥干水分
4. 放入大盘中
5. 加入老抽和油拌匀上色

**注意事项：** 面条不要煮太熟，后面还要炒。

### 步骤2：处理肉类
**正在做什么：** 将猪肉切丝腌制。

**食材当前状态：** 猪肉是整块的。

**操作要点：**
1. 猪肉切成细丝
2. 放入碗中
3. 加入生抽、淀粉抓匀
4. 加入少许油腌制10分钟

**注意事项：** 肉丝要切得细一些。

### 步骤3：处理配料
**正在做什么：** 将配料切好。

**食材当前状态：** 配料都是完整的。

**操作要点：**
1. 葱切段
2. 姜切丝
3. 蒜切片
4. 韭黄切段

**注意事项：** 配料要提前准备好。

### 步骤4：炒肉丝
**正在做什么：** 将肉丝炒熟。

**食材当前状态：** 肉已腌制好。

**操作要点：**
1. 锅中倒油
2. 油热后放入肉丝
3. 快速翻炒
4. 炒至变色后盛出

**注意事项：** 肉丝要炒到变色即可，不要炒太老。

### 步骤5：炒面
**正在做什么：** 将面条炒热。

**食材当前状态：** 面条已上色。

**操作要点：**
1. 锅中再加入少许油
2. 放入姜蒜爆香
3. 放入面条
4. 大火快速翻炒
5. 让面条均匀受热

**注意事项：** 要大火快炒，防止粘锅。

### 步骤6：加入配料
**正在做什么：** 将肉丝和蔬菜加入。

**食材当前状态：** 面条已炒热。

**操作要点：**
1. 放入炒好的肉丝
2. 放入豆芽和韭黄
3. 快速翻炒

**注意事项：** 蔬菜不要炒太久，保持脆爽。

### 步骤7：调味出锅
**正在做什么：** 调味并装盘。

**食材当前状态：** 炒面已基本完成。

**操作要点：**
1. 加入生抽
2. 加入蚝油
3. 放入葱段
4. 快速翻炒均匀
5. 出锅装盘

**注意事项：** 炒面要趁热吃。

## 烹饪关键点/小贴士

1. **面条**：选择碱水面，口感更好。
2. **蒸煮**：面条不要煮太熟，保持弹性。
3. **上色**：用老抽上色，颜色才漂亮。
4. **火候**：全程大火快炒，保持面条爽滑。
