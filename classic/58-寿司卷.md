# 寿司卷

## 菜系/国家
日本料理 / 日本

## 概述
寿司卷是日本寿司的经典形式，以醋饭包裹各种食材，用海苔卷制而成。可以根据个人喜好搭配不同的馅料，是日本料理中最具代表性的食品之一。

## 份量/人数
2人份

## 所需餐具
- 竹帘
- 刀
- 碗
- 盘子

## 食材清单

### 主料
- 寿司米饭：300克
- 海苔：3张

### 馅料
- 黄瓜：1根
- 胡萝卜：1根
- 蟹棒：3根
- 鸡蛋：2个
- 牛油果：1个

### 调料
- 寿司醋：30ml
- 酱油：适量
- 芥末：适量
- 姜片：适量

## 详细步骤

### 步骤1：准备寿司米饭
**正在做什么：** 将米饭拌入寿司醋。

**食材当前状态：** 米饭是刚煮好的热米饭。

**操作要点：**
1. 煮好的米饭放入大碗中
2. 倒入寿司醋
3. 用木勺翻拌
4. 边拌边扇风降温
5. 降至温热即可

**注意事项：** 米饭要保持温热，卷的时候才容易成型。

### 步骤2：准备馅料
**正在做什么：** 将各种食材切成长条。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 黄瓜切成长条
2. 胡萝卜切成长条，焯水备用
3. 蟹棒撕成丝
4. 鸡蛋摊成蛋皮，切条
5. 牛油果切条

**注意事项：** 食材要切得粗细均匀。

### 步骤3：铺米饭
**正在做什么：** 将米饭铺在海苔上。

**食材当前状态：** 海苔是完整的方形。

**操作要点：**
1. 竹帘铺在案板上
2. 海苔光面朝下放在竹帘上
3. 戴上一次性手套
4. 将米饭均匀铺在海苔上
5. 留顶部1厘米不铺米饭

**注意事项：** 米饭要铺得均匀，厚薄一致。

### 步骤4：放馅料
**正在做什么：** 将馅料放在米饭上。

**食材当前状态：** 米饭已铺好，馅料已切好。

**操作要点：**
1. 将馅料放在米饭的中间位置
2. 纵向排列
3. 放上蟹棒

**注意事项：** 馅料不要放太多，否则卷不起来。

### 步骤5：卷寿司
**正在做什么：** 用竹帘将寿司卷起。

**食材当前状态：** 寿司已准备好。

**操作要点：**
1. 双手握住竹帘
2. 从下往上卷起
3. 边卷边压实
4. 卷到顶部时，用竹帘压紧
5. 打开竹帘，寿司卷已完成

**注意事项：** 要卷得紧实，切的时候才不会散。

### 步骤6：切寿司
**正在做什么：** 将寿司卷切成小段。

**食材当前状态：** 寿司卷是长条形。

**操作要点：**
1. 刀沾水
2. 将寿司卷切成约2厘米宽的段
3. 每切一刀沾一次水
4. 切好的寿司摆盘

**注意事项：** 刀要锋利，切的时候要一刀切断。

## 烹饪关键点/小贴士

1. **米饭**：要用专用的寿司米，煮好后要保持温热。
2. **寿司醋**：可以买现成的，也可以用白醋、糖、盐自制。
3. **馅料**：可以根据个人喜好选择不同的馅料。
4. **卷法**：卷的时候要用力均匀，卷得紧实。
