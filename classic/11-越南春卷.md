# 越南春卷

## 菜系/国家
越南菜 / 越南

## 概述
越南春卷是越南的经典小吃，以米纸包裹猪肉、虾仁、蔬菜等配料。口感清爽，配上花生酱汁，是越南最具代表性的美食之一。

## 份量/人数
4人份

## 所需餐具
- 平底锅
- 碗（泡米纸用）
- 盘子

## 食材清单

### 主料
- 米纸：8张
- 猪肉末：150克
- 虾仁：150克

### 配料
- 米粉：100克
- 生菜：50克
- 薄荷叶：20克
- 香菜：20克
- 黄瓜：1根
- 胡萝卜：1根

### 虾仁腌料
- 盐：2克
- 胡椒粉：2克
- 柠檬汁：10ml

### 酱料
- 花生酱：60克
- 酱油：20ml
- 糖：15克
- 蒜末：10克
- 柠檬汁：20ml
- 温水：50ml

## 详细步骤

### 步骤1：处理虾仁
**正在做什么：** 将虾仁调味。

**食材当前状态：** 虾仁是完整的。

**操作要点：**
1. 虾仁去壳去虾线
2. 用盐、胡椒粉、柠檬汁腌制
3. 放入锅中煮熟
4. 捞出放凉，切成两半

**注意事项：** 虾仁不要煮太久。

### 步骤2：准备配料
**正在做什么：** 将蔬菜切好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 米粉煮熟，过冷水备用
2. 生菜洗净
3. 薄荷叶和香菜洗净
4. 黄瓜切丝
5. 胡萝卜切丝

**注意事项：** 配料要提前准备好。

### 步骤3：调制花生酱汁
**正在做什么：** 调制蘸料。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 花生酱放入碗中
2. 加入酱油和糖
3. 加入蒜末
4. 加入柠檬汁
5. 慢慢加入温水
6. 搅拌至顺滑

**注意事项：** 温水要慢慢加，不断搅拌。

### 步骤4：泡米纸
**正在做什么：** 将米纸泡软。

**食材当前状态：** 米纸是干的。

**操作要点：**
1. 碗中放入温水
2. 放入米纸
3. 浸泡约10-20秒
4. 取出放在案板上

**注意事项：** 不要泡太久，会破。

### 步骤5：包春卷
**正在做什么：** 将配料包入春卷。

**食材当前状态：** 米纸已泡好，配料都准备好了。

**操作要点：**
1. 米纸平铺
2. 放上生菜叶
3. 放上米粉
4. 放上黄瓜丝和胡萝卜丝
5. 放上薄荷叶和香菜
6. 放上虾仁
7. 从下往上卷起
8. 两边向中间折
9. 继续卷起
10. 卷紧

**注意事项：** 要卷得紧实。

### 步骤6：完成
**正在做什么：** 装盘。

**食材当前状态：** 春卷已包好。

**操作要点：**
1. 摆放在盘中
2. 配上花生酱汁
3. 可以对半切开方便食用

**注意事项：** 蘸酱吃更美味。

## 烹饪关键点/小贴士

1. **米纸**：泡米纸的时间不要太长，10-20秒即可。
2. **配料**：配料要提前准备好，保持干燥。
3. **卷法**：要卷得紧实，否则容易散。
4. **酱汁**：花生酱汁要调得顺滑。
