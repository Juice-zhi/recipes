# 披萨

## 菜系/国家
意大利菜 / 意大利那不勒斯

## 概述
披萨是意大利最具代表性的食物，由面饼、番茄酱和芝士组成。源自那不勒斯，现在已成为全球最受欢迎的美食之一。

## 份量/人数
2人份

## 所需餐具
- 烤箱
- 披萨石或烤盘
- 揉面垫
- 擀面杖

## 食材清单

### 面饼
- 高筋面粉：250克
- 酵母：5克
- 盐：5克
- 糖：10克
- 温水：160ml
- 橄榄油：15ml

### 配料
- 番茄酱：100克
- 马苏里拉芝士：200克
- 新鲜罗勒叶：10片

### 可选配料
- 意大利香肠：100克
- 蘑菇：50克
- 橄榄：30克
- 洋葱：30克

## 详细步骤

### 步骤1：和面
**正在做什么：** 将面团揉好。

**食材当前状态：** 面粉是粉末，其他是液体。

**操作要点：**
1. 面粉放入盆中
2. 中间挖一个小坑
3. 放入酵母、糖和温水
4. 静置5分钟
5. 加入盐和橄榄油
6. 揉成光滑的面团
7. 盖上湿布，发酵1小时

**注意事项：** 酵母不要直接接触盐，会失效。

### 步骤2：准备配料
**正在做什么：** 将配料准备好。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 番茄酱加入少许盐和蒜末调匀
2. 芝士擦成丝
3. 意大利香肠切片
4. 蘑菇切片
5. 洋葱切丝

**注意事项：** 配料要提前准备好。

### 步骤3：整形
**正在做什么：** 将面团擀成披萨饼皮。

**食材当前状态：** 面团已发酵好。

**操作要点：**
1. 发酵好的面团排气
2. 擀成约30厘米的圆形
3. 边缘稍微厚一些
4. 放在铺了烘焙纸的烤盘上

**注意事项：** 要擀得厚薄均匀。

### 步骤4：添加酱料
**正在做什么：** 在饼皮上抹番茄酱。

**食材当前状态：** 饼皮已擀好。

**操作要点：**
1. 将番茄酱均匀抹在饼皮上
2. 边缘留1厘米不抹
3. 用勺子抹均匀

**注意事项：** 酱料不要抹太多，会出水。

### 步骤5：添加芝士和配料
**正在做什么：** 在披萨上放芝士和配料。

**食材当前状态：** 酱料已抹好。

**操作要点：**
1. 先撒一层芝士
2. 放上香肠、蘑菇、洋葱
3. 再撒一层芝士
4. 放上罗勒叶

**注意事项：** 芝士要放够，烤出来才好吃。

### 步骤6：烤制
**正在做什么：** 将披萨放入烤箱烤制。

**食材当前状态：** 披萨已组装好。

**操作要点：**
1. 烤箱预热至250℃
2. 放入披萨
3. 烤8-10分钟
4. 烤至芝士融化并呈金黄色
5. 边缘变成金黄色

**注意事项：** 烤的时间不要太长，芝士会烤焦。

### 步骤7：出炉
**正在做什么：** 将披萨取出。

**食材当前状态：** 披萨已烤好。

**操作要点：**
1. 从烤箱取出
2. 稍等2分钟
3. 切成8块

**注意事项：** 小心烫手。

## 烹饪关键点/小贴士

1. **面团**：面团要揉到光滑，发酵要到位。
2. **烤箱**：烤箱要预热到最高温度，250℃以上。
3. **芝士**：马苏里拉芝士是经典选择，烤出来会拉丝。
4. **配料**：不要放太多水分多的配料。
