# 韩式炸鸡

## 菜系/国家
韩国料理 / 韩国

## 概述
韩式炸鸡是韩国近年来风靡全球的美食，以鸡肉裹上面糊炸至酥脆，再裹上特制的甜辣酱汁。外酥里嫩，甜辣可口，是韩国料理的明星产品。

## 份量/人数
4人份

## 所需餐具
- 炸锅
- 炒锅
- 漏勺
- 盘子

## 食材清单

### 主料
- 鸡翅中：600克
- 鸡腿：400克

### 裹粉
- 面粉：100克
- 淀粉：50克
- 泡打粉：3克
- 盐：3克
- 胡椒粉：2克

### 酱料
- 韩式辣酱：60克
- 番茄酱：30克
- 酱油：15ml
- 糖：30克
- 蒜末：20克
- 芝麻油：10ml

### 辅料
- 芝麻：15克
- 葱花：20克

### 油料
- 食用油：800ml（实耗约200ml）

## 详细步骤

### 步骤1：处理鸡肉
**正在做什么：** 将鸡肉清洗干净。

**食材当前状态：** 鸡肉是完整的。

**操作要点：**
1. 鸡翅和鸡腿洗净
2. 用厨房纸吸干水分
3. 在鸡肉上划几刀

**注意事项：** 水分要吸干。

### 步骤2：裹粉
**正在做什么：** 将鸡肉裹上面粉。

**食材当前状态：** 鸡肉已处理好。

**操作要点：**
1. 面粉、淀粉、泡打粉混合
2. 加入盐和胡椒粉
3. 将鸡肉放入粉中
4. 用力按压，让粉附着
5. 抖掉多余的粉

**注意事项：** 要裹得均匀。

### 步骤3：油炸
**正在做什么：** 将鸡肉炸至金黄。

**食材当前状态：** 鸡肉已裹好粉。

**操作要点：**
1. 锅中倒油
2. 加热至170℃
3. 放入鸡肉
4. 中火炸8-10分钟
5. 捞出沥油
6. 油温升至190℃
7. 复炸2分钟至酥脆

**注意事项：** 复炸是关键。

### 步骤4：制作酱料
**正在做什么：** 调制韩式甜辣酱。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 锅中放入韩式辣酱
2. 加入番茄酱
3. 加入酱油和糖
4. 加入蒜末
5. 小火加热
6. 搅拌均匀
7. 加入芝麻油

**注意事项：** 要小火加热，不断搅拌。

### 步骤5：裹酱
**正在做什么：** 将炸鸡裹上酱料。

**食材当前状态：** 炸鸡已炸好，酱料已做好。

**操作要点：**
1. 放入炸好的鸡肉
2. 快速翻匀
3. 让每块鸡肉都裹上酱料
4. 撒上芝麻
5. 撒上葱花

**注意事项：** 要快速翻动。

### 步骤6：完成
**正在做什么：** 装盘。

**食材当前状态：** 韩式炸鸡已做好。

**操作要点：**
1. 盛入盘中
2. 立即食用

**注意事项：** 趁热吃最美味。

## 烹饪关键点/小贴士

1. **鸡肉**：选择新鲜的鸡肉，水分要吸干。
2. **复炸**：复炸是酥脆的关键。
3. **酱料**：酱料可以根据口味调整甜度和辣度。
4. **芝麻**：撒上芝麻更香。
