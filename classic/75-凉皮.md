# 凉皮

## 菜系/国家
西北菜 / 中国陕西

## 概述
凉皮是陕西的经典小吃，以面粉为原料制成面皮，凉拌食用。口感爽滑，配上辣椒油和醋汁，酸辣开胃，是夏天最受欢迎的美食之一。

## 份量/人数
4人份

## 所需餐具
- 蒸锅
- 大盆
- 盘子

## 食材清单

### 面皮
- 面粉：300克
- 清水：300ml
- 盐：3克

### 配料
- 黄瓜：1根
- 豆芽：100克
- 花生碎：30克
- 香菜：20克

### 调料
- 辣椒油：30ml
- 醋：30ml
- 生抽：20ml
- 蒜水：30ml
- 芝麻酱：20ml

## 详细步骤

### 步骤1：洗面
**正在做什么：** 将面粉加水洗出面浆。

**食材当前状态：** 面粉是粉末。

**操作要点：**
1. 面粉放入盆中
2. 加水和成面团
3. 加入少许盐
4. 用手揉搓
5. 慢慢加水，洗面
6. 洗出的水倒入另一个盆中
7. 重复洗面，直至水清
8. 剩下的就是面筋

**注意事项：** 要多洗几遍，洗得越干净越好。

### 步骤2：沉淀
**正在做什么：** 让面浆沉淀。

**食材当前状态：** 洗出的面浆是浑浊的。

**操作要点：**
1. 洗好的面浆静置4小时以上
2. 让淀粉沉淀
3. 倒掉上面的清水
4. 留下的就是浓面浆

**注意事项：** 沉淀时间要足够。

### 步骤3：蒸面皮
**正在做什么：** 将面浆蒸成面皮。

**食材当前状态：** 面浆已沉淀好。

**操作要点：**
1. 盘中刷一层油
2. 舀入一勺面浆
3. 轻轻晃动，让面浆铺满盘底
4. 放入烧开的蒸锅中
5. 蒸2-3分钟至透明
6. 取出放入冷水中冷却
7. 揭下面皮

**注意事项：** 面浆要铺得薄薄的。

### 步骤4：处理配料
**正在做什么：** 将配料准备好。

**食材当前状态：** 配料都是完整的。

**操作要点：**
1. 黄瓜切丝
2. 豆芽焯水备用
3. 香菜切碎
4. 面筋蒸熟切块

**注意事项：** 配料要提前准备好。

### 步骤5：调制酱汁
**正在做什么：** 调拌凉皮的酱汁。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 辣椒油、醋、生抽放入碗中
2. 加入蒜水
3. 加入芝麻酱
4. 调匀

**注意事项：** 酱汁要调匀。

### 步骤6：拌匀食用
**正在做什么：** 将凉皮拌匀。

**食材当前状态：** 面皮已蒸好，酱汁已调好。

**操作要点：**
1. 面皮切宽条
2. 放入碗中
3. 放上黄瓜丝、豆芽
4. 浇上酱汁
5. 撒上花生碎和香菜
6. 拌匀食用

**注意事项：** 拌匀后再吃。

## 烹饪关键点/小贴士

1. **洗面**：洗面要有耐心，洗到水清为止。
2. **沉淀**：面浆要沉淀到位，否则不劲道。
3. **蒸制**：面皮要蒸得透明，不能太厚。
4. **酱汁**：辣椒油是凉皮的灵魂。
