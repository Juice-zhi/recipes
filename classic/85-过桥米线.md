# 过桥米线

## 菜系/国家
滇菜 / 中国云南

## 概述
过桥米线是云南昆明的经典小吃，以汤底滚烫、米线细软、配料丰富著称。食用时将生肉片放入热汤中烫熟，是云南最具代表性的美食。

## 份量/人数
2人份

## 所需餐具
- 汤锅
- 碗（大碗）
- 盘子（装配料）

## 食材清单

### 汤底
- 鸡汤：1500ml
- 火腿：50克
- 姜：20克
- 葱：30克

### 主料
- 米线：300克

### 配料（生）
- 猪里脊肉：100克
- 鸡胸肉：100克
- 鱼片：100克
- 虾仁：100克
- 鹌鹑蛋：2个
- 豆芽：50克
- 韭菜：50克

### 配料（熟）
- 熟鸡肉：50克
- 火腿片：30克
- 榨菜：30克

### 调料
- 盐：适量
- 胡椒粉：适量
- 辣椒油：适量

## 详细步骤

### 步骤1：熬汤底
**正在做什么：** 用鸡汤和火腿熬制高汤。

**食材当前状态：** 鸡汤是现成的。

**操作要点：**
1. 鸡汤放入锅中
2. 加入火腿片
3. 加入姜片和葱段
4. 大火烧开
5. 转小火熬30分钟

**注意事项：** 汤要熬得浓白。

### 步骤2：准备配料
**正在做什么：** 将所有配料切好摆盘。

**食材当前状态：** 食材都是完整的。

**操作要点：**
1. 猪肉、鸡肉、鱼肉都切成薄片
2. 虾仁去壳
3. 豆芽洗净
4. 韭菜切段
5. 熟鸡肉撕成丝
6. 摆放在盘子中

**注意事项：** 肉片要切得尽量薄。

### 步骤3：烫米线
**正在做什么：** 将米线烫熟。

**食材当前状态：** 米线是干燥的。

**操作要点：**
1. 烧水，水开后放入米线
2. 煮2-3分钟至软
3. 捞出放入碗中

**注意事项：** 米线不要煮太久。

### 步骤4：加热汤
**正在做什么：** 将汤底加热到滚烫。

**食材当前状态：** 汤已熬好。

**操作要点：**
1. 将熬好的汤重新烧开
2. 要保持滚烫
3. 小心倒入大碗中

**注意事项：** 汤要足够热才能烫熟生肉。

### 步骤5：上桌
**正在做什么：** 端上桌让食客自己烫。

**食材当前状态：** 所有材料都准备好了。

**操作要点：**
1. 将滚烫的汤倒入放米线的碗中
2. 迅速放入所有生肉片
3. 盖上盖子焖1分钟
4. 再放入其他配料
5. 配上辣椒油和胡椒粉

**注意事项：** 肉片要最先放入，烫熟后再吃其他。

## 烹饪关键点/小贴士

1. **汤底**：要用鸡汤熬制，味道才鲜美。
2. **配料**：配料要尽量切薄，容易烫熟。
3. **温度**：汤要保持滚烫，才能烫熟肉片。
4. **顺序**：先放生肉，再放蔬菜，最后放熟食。
