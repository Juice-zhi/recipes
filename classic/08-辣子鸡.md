# 辣子鸡

## 菜系/国家
川菜 / 中国四川

## 概述
辣子鸡是四川重庆地区的经典名菜，以其干辣香脆的独特风味著称。这道菜选用仔鸡为主料，搭配大量干辣椒和花椒炒制，成菜色泽红亮，鸡肉干香麻辣，是下酒佐餐的绝佳选择。

## 份量/人数
2-3人份

## 所需餐具
- 炒锅
- 锅铲
- 漏勺
- 厨房纸
- 盘子（盛装成品）

## 食材清单

### 主料
- 仔鸡：500克（约半只）

### 调料
- 干辣椒：50克（约20-30个）
- 花椒：15克
- 郫县豆瓣酱：15克（1小勺）
- 生抽：20ml（2大勺）
- 料酒：20ml（2大勺）
- 食盐：5克（约1小勺）
- 白糖：5克（1小勺）
- 鸡精：2克（可选）

### 辅料
- 姜：15克（3片，切末）
- 蒜：15克（3瓣，切末）
- 葱：30克（1根，切段）
- 白芝麻：10克（装饰用）

### 油料
- 食用油：80ml

## 详细步骤

### 步骤1：鸡肉处理
**正在做什么：** 将仔鸡剁成约2厘米见方的小块。

**食材当前状态：** 仔鸡是半只鸡，带着骨头。

**操作要点：**
1. 将仔鸡洗净，剁成约2厘米见方的小块
2. 鸡块不要太大，否则不容易入味
3. 鸡块不要太小，否则肉会柴
4. 剁好后放入碗中

**注意事项：** 鸡块要剁得大小均匀，这样成熟度一致。

### 步骤2：腌制鸡肉
**正在做什么：** 将鸡块腌制入味。

**食材当前状态：** 鸡块是刚剁好的，带有血水。

**操作要点：**
1. 放入食盐3克（约半小勺）
2. 加入生抽10ml（1大勺）
3. 加入料酒10ml（1大勺）
4. 用手抓匀
5. 腌制20分钟

**注意事项：** 腌制时间要足够，让鸡肉入味。抓匀时不要太用力，防止鸡肉变柴。

### 步骤3：准备调料
**正在做什么：** 将干辣椒剪成小段，准备其他调料。

**食材当前状态：** 干辣椒是完整的，花椒是颗粒状的。

**操作要点：**
1. 干辣椒去蒂，剪成约2厘米的小段
2. 将干辣椒段和花椒放在一起
3. 姜蒜切末
4. 葱切段

**注意事项：** 干辣椒要剪开，味道才能充分释放。辣椒籽可以保留，增加辣味。

### 步骤4：炸制鸡肉
**正在做什么：** 将鸡块炸至金黄酥脆。

**食材当前状态：** 鸡块已经腌制好，表面湿润。

**操作要点：**
1. 锅中倒入80ml食用油，烧至七成热（约200°C）
2. 放入鸡块，中火炸制
3. 保持中火，不断翻动
4. 炸至鸡肉表面金黄，约需5-7分钟
5. 用漏勺捞出，沥干油分
6. 放在厨房纸上吸去多余油分

**注意事项：** 油温要高，这样外皮才能酥脆。炸的时候要不断翻动，防止粘锅。

### 步骤5：炒制底料
**正在做什么：** 炒制干辣椒、花椒和豆瓣酱。

**食材当前状态：** 锅中只有底油，干辣椒和花椒是干燥的。

**操作要点：**
1. 锅中留底油约30ml
2. 烧热后下入干辣椒段和花椒
3. 小火慢炒，炒出香味
4. 炒至干辣椒颜色变深
5. 下入郫县豆瓣酱
6. 快速翻炒出红油
7. 下入姜蒜末

**注意事项：** 干辣椒和花椒要小火炒，大火容易炒糊。小心不要炒太久，辣椒稍微变色就要下一步。

### 步骤6：加入鸡肉
**正在做什么：** 将炸好的鸡肉倒入锅中翻炒。

**食材当前状态：** 底料已经在锅中，香气四溢。

**操作要点：**
1. 放入炸好的鸡块
2. 大火快速翻炒
3. 炒匀，让鸡肉均匀裹上味道
4. 加入生抽10ml
5. 加入料酒10ml
6. 加入白糖5克
7. 继续翻炒均匀

**注意事项：** 这个步骤要大火快炒，保持鸡肉的酥脆口感。

### 步骤7：调味和出锅
**正在做什么：** 最后调味，撒上芝麻出锅。

**食材当前状态：** 鸡肉已经充分吸收调料味道。

**操作要点：**
1. 加入鸡精2克（可选）
2. 放入葱段
3. 快速翻匀
4. 撒上白芝麻
5. 翻匀后出锅

**注意事项：** 葱段要最后放，保持翠绿和清香。白芝麻可以增加香气。

## 烹饪关键点/小贴士

1. **鸡肉选择**：最好选用仔鸡，肉质鲜嫩骨脆。鸡块要剁得大小均匀，约2厘米见方。

2. **油温控制**：炸鸡肉时油温要高，约七成热。这样外皮才能快速定型，锁住水分。

3. **干辣椒用量**：辣子鸡的特色就是干辣椒多，可以根据个人口味调整。喜欢更辣的可以多放。

4. **花椒技巧**：花椒是麻味的来源，要用四川花椒，麻味才正。花椒可以分两次放，味道更丰富。

5. **火候掌握**：炸鸡肉要中火慢炸，炒制时要大火快炒。这样才能外酥里嫩。

6. **去腥方法**：腌制时加料酒可以去腥。炸之前要把鸡肉表面的水分吸干。

7. **食用特点**：辣子鸡的特点是"见辣不见鱼"，就是辣椒多但找不到鸡肉在哪里。吃的就是这个感觉。

- 鸡肉富含优质蛋白质
- 辣椒有助于促进新陈代谢
- 花椒可以祛湿散寒
- 适量食用可以增强食欲
