# 石锅拌饭 (Bibimbap)

## 菜系/国家
韩国料理 / 韩国

## 概述
石锅拌饭是韩国传统的米饭料理，将米饭放入烧热的石锅中，配上各种蔬菜、肉类和煎蛋，食用时拌上辣椒酱。石锅的高温会让米饭形成香脆的锅巴，口感丰富。

## 份量/人数
2人份

## 所需餐具
- 石锅或砂锅
- 炒锅
- 碗（盛放配料用）
- 勺子（拌饭用）

## 食材清单

### 米饭
- 大米：300克

### 肉类
- 牛肉（牛腩）：150克
- 酱油：15ml
- 糖：5克
- 蒜末：5克
- 芝麻油：10ml

### 蔬菜
- 胡萝卜：80克（切丝）
- 西葫芦：80克（切丝）
- 豆芽：100克
- 菠菜：80克
- 香菇：80克（切片）
- 紫菜：10克（切丝）

### 蛋
- 鸡蛋：2个

### 调料
- 韩国辣椒酱：60ml
- 芝麻油：15ml
- 芝麻：15克
- 葱花：10克

## 详细步骤

### 步骤1：煮米饭
**正在做什么：** 将米饭煮熟。

**操作要点：**
1. 大米洗净
2. 放入电饭锅
3. 加入适量的水
4. 煮成熟米饭
5. 保温备用

**注意事项：** 米饭要煮得稍微硬一点，因为后面还要加热。

### 步骤2：处理牛肉
**正在做什么：** 将牛肉炒熟。

**操作要点：**
1. 牛肉切丝或切末
2. 加入酱油、糖、蒜末、芝麻油
3. 抓匀腌制
4. 炒锅中火炒熟
5. 备用

**注意事项：** 牛肉要炒到熟透。调味可以稍微咸一点。

### 步骤3：准备蔬菜
**正在做什么：** 将各种蔬菜炒熟。

**操作要点：**
1. 胡萝卜丝炒熟，加盐调味
2. 西葫芦丝炒熟，加盐调味
3. 豆芽炒熟，加盐调味
4. 菠菜焯水，挤干水分，加盐和芝麻油拌匀
5. 香菇切片炒熟，加盐调味
6. 紫菜丝稍微炒一下

**注意事项：** 每种蔬菜分开炒，调味。菠菜要焯水后过冷水。

### 步骤4：煎蛋
**正在做什么：** 煎两个太阳蛋。

**操作要点：**
1. 锅中放少许油
2. 打入鸡蛋
3. 煎至蛋白凝固
4. 蛋黄保持流动
5. 煎两个

**注意事项：** 蛋黄要保持流动，拌饭时才好吃。

### 步骤5：组装石锅
**正在做什么：** 将米饭和配料放入石锅。

**操作要点：**
1. 石锅内部刷一层芝麻油
2. 放入热米饭
3. 将蔬菜摆放在米饭上
4. 摆成漂亮的形状
5. 中间放上牛肉
6. 放上煎蛋
7. 撒上紫菜丝
8. 撒上芝麻和葱花

**注意事项：** 石锅要够热，才能形成锅巴。摆盘要漂亮。

### 步骤6：上桌和拌饭
**正在做什么：** 石锅拌饭完成。

**操作要点：**
1. 石锅直接上桌
2. 配上韩国辣椒酱
3. 吃之前
4. 将辣椒酱倒入石锅中
5. 用勺子拌匀
6. 让石锅的热度将米饭形成锅巴

**注意事项：** 拌饭时要小心，石锅很烫。锅巴是石锅拌饭的精华。

## 烹饪关键点/小贴士

1. **石锅**：石锅是石锅拌饭的关键，要提前加热。如果没有石锅，可以用砂锅代替。

2. **蔬菜**：蔬菜种类可以根据个人喜好调整。经典的有胡萝卜、西葫芦、豆芽、菠菜、香菇。

3. **牛肉**：牛肉要提前腌制入味。可以用牛腩或牛里脊。

4. **锅巴**：石锅的高温会在底部形成香脆的锅巴，这是石锅拌饭的精华。

5. **辣椒酱**：韩国辣椒酱是石锅拌饭的必备调料。可以根据个人口味调整用量。

6. **拌饭**：拌饭时要等一会儿再拌，让锅巴形成。不要太早拌，锅巴还没形成。
