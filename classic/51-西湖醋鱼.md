# 西湖醋鱼

## 菜系/国家
浙菜 / 中国杭州

## 概述
西湖醋鱼是杭州传统名菜，选用草鱼烹制，浇上糖醋芡汁。鱼肉鲜嫩，酸甜可口，带有蟹肉味道，是西湖楼外楼的招牌菜。

## 份量/人数
2人份

## 所需餐具
- 蒸锅
- 炒锅
- 盘子

## 食材清单

### 主料
- 草鱼：1条（约600克）

### 调料
- 醋：60ml
- 白糖：50克
- 酱油：30ml
- 料酒：20ml
- 姜末：10克

### 辅料
- 姜片：3片
- 葱：2根
- 胡椒粉：少许

### 芡汁材料
- 淀粉：20克
- 清水：50ml

## 详细步骤

### 步骤1：处理草鱼
**正在做什么：** 将草鱼宰杀洗净，从尾部剖开。

**食材当前状态：** 草鱼是完整的。

**操作要点：**
1. 草鱼去鳞、去内脏，洗净
2. 从尾部沿脊骨片开（不要切断）
3. 鱼身两侧各划几刀，便于入味

**注意事项：** 刀工要精细，鱼要保持完整。

### 步骤2：初步熟处理
**正在做什么：** 将鱼煮至断生。

**食材当前状态：** 鱼已处理好。

**操作要点：**
1. 锅中加水，放入姜片、葱、料酒
2. 水开后放入鱼，转小火
3. 煮约5-6分钟至鱼熟透
4. 捞出装盘

**注意事项：** 水不要沸腾，保持微开状态，鱼肉更嫩。

### 步骤3：调制醋汁
**正在做什么：** 调制糖醋芡汁。

**食材当前状态：** 调料都是独立的。

**操作要点：**
1. 锅中留少许汤汁
2. 加入酱油、糖、醋
3. 大火烧开
4. 淀粉加水调匀，缓缓倒入锅中
5. 不断搅拌至芡汁浓稠

**注意事项：** 芡汁要透明发亮，口感滑爽。

### 步骤4：浇汁
**正在做什么：** 将醋汁浇在鱼身上。

**食材当前状态：** 鱼已熟透摆放在盘中，醋汁已调好。

**操作要点：**
1. 将调好的醋汁浇在鱼身上
2. 撒上姜末
3. 可淋少许热油增香

**注意事项：** 浇汁要均匀，让鱼充分吸收味道。

## 烹饪关键点/小贴士

1. **火候**：煮鱼时水不能沸，保持小火微开。
2. **醋汁**：糖醋比例要适中，酸甜可口。
3. **芡汁**：淀粉要慢慢倒入，边倒边搅，防止结块。
4. **去腥**：加姜葱料酒可以有效去腥。
