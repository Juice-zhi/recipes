# 肉夹馍

## 菜系/国家
西北菜 / 中国陕西

## 概述
肉夹馍是陕西的经典小吃，以白吉馍夹入炖煮的腊汁肉制成。馍外酥里嫩，肉香浓郁，是西北地区的代表性美食，被誉为"中国汉堡"。

## 份量/人数
4人份

## 所需餐具
- 炖锅
- 烤箱或平底锅
- 刀

## 食材清单

### 馍
- 面粉：300克
- 酵母：3克
- 温水：150ml
- 盐：2克

### 肉
- 五花肉：500克
- 腊汁调料包：1包（可用八角、桂皮、香叶等代替）

### 调料
- 生抽：30ml
- 老抽：15ml
- 冰糖：20克
- 料酒：30ml
- 盐：适量

## 详细步骤

### 步骤1：和面
**正在做什么：** 将面团揉好。

**食材当前状态：** 面粉是粉末。

**操作要点：**
1. 面粉放入盆中
2. 加入酵母和盐
3. 慢慢加入温水
4. 揉成光滑的面团
5. 盖上湿布，醒发1小时

**注意事项：** 面团要揉到光滑。

### 步骤2：制作腊汁肉
**正在做什么：** 将肉炖煮入味。

**食材当前状态：** 五花肉是整块的。

**操作要点：**
1. 五花肉切成大块
2. 冷水下锅，加料酒焯水
3. 捞出洗净
4. 放入炖锅
5. 加入腊汁调料
6. 加入生抽、老抽、冰糖
7. 加水没过肉
8. 大火烧开，转小火炖2小时

**注意事项：** 要小火慢炖，肉才软烂。

### 步骤3：制作白吉馍
**正在做什么：** 将面团做成馍。

**食材当前状态：** 面团已醒发好。

**操作要点：**
1. 醒好的面团分成4份
2. 揉圆，擀成圆饼
3. 从中间切开一半
4. 放入预热至200℃的烤箱
5. 烤15分钟至金黄
6. 或者用平底锅烙熟

**注意事项：** 馍要外酥里嫩。

### 步骤4：夹肉
**正在做什么：** 将肉夹入馍中。

**食材当前状态：** 馍已烤好，肉已炖好。

**操作要点：**
1. 炖好的肉捞出
2. 用刀剁碎
3. 夹入切开的馍中
4. 可以浇一些肉汁

**注意事项：** 肉要剁得细一些。

### 步骤5：完成
**正在做什么：** 装盘。

**食材当前状态：** 肉夹馍已做好。

**操作要点：**
1. 趁热食用
2. 可以配上凉皮或饮料

**注意事项：** 肉夹馍要趁热吃才香。

## 烹饪关键点/小贴士

1. **和面**：面团要醒发到位，馍才松软。
2. **炖肉**：腊汁肉要小火慢炖，越炖越香。
3. **烙馍**：外皮要烙得酥脆。
4. **夹肉**：肉要剁得细腻，肥瘦相间。
