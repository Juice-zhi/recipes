# 酸菜鱼

## 菜系/国家
川菜 / 中国四川

## 概述
酸菜鱼是四川经典名菜，以草鱼为主料，配以酸菜烹制。鱼片鲜嫩，汤汁酸辣，是川菜中非常受欢迎的鱼类菜肴。

## 份量/人数
4人份

## 所需餐具
- 炒锅
- 汤锅
- 盘子

## 食材清单

### 主料
- 草鱼：1条（约750克）
- 酸菜：200克

### 鱼片腌料
- 盐：5克
- 料酒：15ml
- 淀粉：15克
- 蛋清：1个

### 调料
- 泡椒：30克
- 干辣椒：10克
- 花椒：3克
- 姜：20克
- 蒜：20克
- 野山椒：20克

### 汤底
- 高汤或清水：1000ml

### 油料
- 食用油：80ml

## 详细步骤

### 步骤1：处理鱼
**正在做什么：** 将草鱼片成鱼片。

**食材当前状态：** 草鱼是整条的。

**操作要点：**
1. 草鱼去鳞、去内脏
2. 鱼身两侧片下鱼肉
3. 鱼骨剁成块
4. 鱼肉片成薄片

**注意事项：** 鱼片要切得薄厚均匀。

### 步骤2：腌制鱼片
**正在做什么：** 将鱼片腌制入味。

**食材当前状态：** 鱼片已片好。

**操作要点：**
1. 鱼片放入碗中
2. 加盐抓匀
3. 加入料酒
4. 加入蛋清
5. 加入淀粉抓匀
6. 腌制15分钟

**注意事项：** 淀粉可以让鱼片更嫩滑。

### 步骤3：处理酸菜
**正在做什么：** 将酸菜切好。

**食材当前状态：** 酸菜是整颗的。

**操作要点：**
1. 酸菜洗净
2. 切成小块
3. 酸菜帮要切得薄一些
4. 用清水浸泡10分钟去咸味

**注意事项：** 酸菜要切得大小均匀。

### 步骤4：炒制底料
**正在做什么：** 炒制酸菜和调料。

**食材当前状态：** 酸菜已切好。

**操作要点：**
1. 锅中倒油
2. 放入姜蒜末炒香
3. 放入泡椒和野山椒
4. 放入酸菜翻炒
5. 炒出香味

**注意事项：** 要把酸菜炒出香味。

### 步骤5：煮汤
**正在做什么：** 加入高汤煮沸。

**食材当前状态：** 底料已炒好。

**操作要点：**
1. 放入鱼骨
2. 加入高汤或清水
3. 大火烧开
4. 转中火煮10分钟
5. 把酸菜和鱼骨捞出放入碗中

**注意事项：** 鱼骨要煮出鲜味。

### 步骤6：煮鱼片
**正在做什么：** 将鱼片放入汤中煮熟。

**食材当前状态：** 鱼片已腌制好。

**操作要点：**
1. 汤烧开后关火
2. 放入鱼片
3. 用勺子轻轻推动
4. 鱼片变色后捞出
5. 放入装有酸菜的碗中
6. 浇上汤汁

**注意事项：** 鱼片不要煮太久，会老。

### 步骤7：浇油
**正在做什么：** 最后浇上热油。

**食材当前状态：** 鱼片已煮好。

**操作要点：**
1. 鱼片上放上干辣椒和花椒
2. 锅中烧热油
3. 浇在干辣椒和花椒上
4. 发出"滋啦"声

**注意事项：** 油要烧到冒烟。

## 烹饪关键点/小贴士

1. **刀工**：鱼片要切得薄厚均匀。
2. **腌制**：加淀粉和蛋清可以让鱼片更嫩。
3. **火候**：煮鱼片要关火或小火，大火会让鱼片碎掉。
4. **酸菜**：酸菜要炒过再煮，味道更浓郁。
