# 印度玛萨拉

## 菜系/国家
印度菜 / 印度

## 概述
印度玛萨拉是印度最具代表性的混合香料，用于咖喱菜肴的烹饪。由多种香料混合而成，是印度菜肴的灵魂调料。

## 份量/人数
约30克

## 所需餐具
- 炒锅
- 研磨机
- 碗

## 食材清单

### 香料（可按比例调整）
- 孜然：10克
- 芫荽籽：10克
- 黑胡椒：5克
- 丁香：3克
- 肉桂：3克
- 小豆蔻：3克
- 辣椒粉：10克
- 姜黄粉：5克

## 详细步骤

### 步骤1：烘烤香料
**正在做什么：** 将香料烘干出香味。

**食材当前状态：** 香料都是完整的种子。

**操作要点：**
1. 锅中放入所有香料
2. 小火干炒
3. 不断翻动
4. 炒至香料微微变色
5. 冒出香味
6. 盛出放凉

**注意事项：** 要小火炒，不要炒糊。

### 步骤2：研磨
**正在做什么：** 将香料磨成粉。

**食材当前状态：** 香料已炒好放凉。

**操作要点：**
1. 将香料放入研磨机
2. 打成细粉
3. 倒入碗中
4. 充分混合

**注意事项：** 要磨得够细。

### 步骤3：保存
**正在做什么：** 将玛萨拉粉保存。

**食材当前状态：** 玛萨拉粉已做好。

**操作要点：**
1. 放入密封容器
2. 放在阴凉处
3. 可以保存3-6个月

**注意事项：** 避免受潮。

## 烹饪关键点/小贴士

1. **香料选择**：选择新鲜的香料，味道更浓郁。
2. **火候**：烘烤时要小火，不断翻动。
3. **研磨**：要磨得够细，容易入味。
4. **保存**：密封保存，避免受潮。
