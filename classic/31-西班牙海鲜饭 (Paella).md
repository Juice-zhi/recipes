# 西班牙海鲜饭 (Paella)

## 菜系/国家
西班牙菜 / 西班牙

## 概述
西班牙海鲜饭是西班牙的国菜，起源于瓦伦西亚。这道菜以西班牙短粒米为主料，加入藏红花、海鲜、肉类等，用平底锅煮制而成。米饭金黄，海鲜鲜美，是西班牙最著名的美食之一。

## 份量/人数
4人份

## 所需餐具
- 西班牙海鲜饭锅（Paella pan）或大平底锅
- 勺子
- 碗

## 食材清单

### 主料
- 西班牙短粒米：300克
- 虾：200克
- 青口贝：150克
- 鱿鱼：150克
- 鸡肉：200克

### 汤底
- 高汤：1000ml
- 藏红花：0.5克
- 番茄：200克（切碎）

### 调料
- 橄榄油：60ml
- 蒜：15克（切末）
- 洋葱：100克（切丁）
- 辣椒粉：3克
- 盐：5克
- 黑胡椒：2克

### 装饰
- 柠檬：1个（切块）
- 欧芹：15克（切碎）

## 详细步骤

### 步骤1：准备海鲜
**正在做什么：** 处理各种海鲜。

**操作要点：**
1. 虾去壳去肠线
2. 青口贝刷干净，去掉胡须
3. 鱿鱼去皮，切成圈
4. 鸡肉切块

**注意事项：** 海鲜要新鲜，处理干净。

### 步骤2：制作高汤
**正在做什么：** 用藏红花泡高汤。

**操作要点：**
1. 高汤放入锅中
2. 加入藏红花
3. 加热但不要煮开
4. 让藏红花的颜色和味道渗入
5. 保温备用

**注意事项：** 藏红花是西班牙海鲜饭的关键调料，提供了独特的颜色和风味。

### 步骤3：炒配料
**正在做什么：** 炒香洋葱、蒜和番茄。

**操作要点：**
1. 锅中倒入橄榄油
2. 烧热
3. 放入洋葱丁
4. 炒至软化
5. 加入蒜末
6. 加入番茄碎
7. 炒至番茄软烂
8. 加入辣椒粉

**注意事项：** 洋葱要炒软，炒出甜味。番茄要炒烂。

### 步骤4：加入米饭
**正在做什么：** 将米放入锅中翻炒。

**操作要点：**
1. 放入洗净的米
2. 翻炒均匀
3. 让米粒吸收油脂和汤汁
4. 炒约2分钟

**注意事项：** 米要炒一下，这样煮出来更香。

### 步骤5：加入高汤
**正在做什么：** 加入高汤煮饭。

**操作要点：**
1. 将藏红花高汤倒入锅中
2. 加入盐和黑胡椒
3. 大火烧开
4. 转中火
5. 保持微沸
6. 煮约10分钟
7. 不要搅拌米饭

**注意事项：** 高汤要一次加够，中途不要加水。不要搅拌米饭，会让米饭变得太软。

### 步骤6：加入海鲜
**正在做什么：** 将海鲜放在米饭上。

**操作要点：**
1. 将虾、青口贝、鱿鱼、鸡肉放在米饭上
2. 摆成好看的形状
3. 继续煮约10分钟
4. 直到海鲜熟透
5. 米饭熟透

**注意事项：** 海鲜要后放，煮太久会老。摆在上方可以保持海鲜的形状。

### 步骤7：形成锅巴
**正在做什么：** 让底部形成香脆的锅巴。

**操作要点：**
1. ，关火
2. 不要立即打开锅盖
3. 焖约5分钟
4. 让底部形成锅巴
5. 可以将锅底稍微加热一下

**注意事项：** 锅巴是西班牙海鲜饭的精华，又香又脆。

### 步骤8：上桌
**正在做什么：** 西班牙海鲜饭完成。

**操作要点：**
1. 撒上欧芹碎
2. 摆上柠檬块
3. 立即食用

**注意事项：** 海鲜饭要趁热吃，凉了就不好吃了。

## 烹饪关键点/小贴士

1. **米的选择**：要用西班牙短粒米（Arborio或Bomba），这种米吸水性好，煮出来有嚼劲。

2. **藏红花**：藏红花是西班牙海鲜饭的灵魂调料，提供了独特的颜色和风味。没有藏红花可以用姜黄代替，但味道不同。

3. **高汤**：高汤可以用海鲜汤或鸡汤。海鲜汤更鲜美。

4. **不加搅拌**：西班牙海鲜饭的特色是不搅拌米饭，让底部形成锅巴。这是精华所在。

5. **海鲜时机**：海鲜要后放，煮太久会老。虾和青口贝很容易熟。

6. **锅巴**：底部形成的锅巴又香又脆，是西班牙海鲜饭的特色。
