# 鱼香肉丝

## 菜系/国家
川菜 / 中国四川

## 概述
鱼香肉丝是四川成都的经典川菜，虽然名字中有"鱼"，实际上并没有使用鱼，而是用泡椒、葱姜蒜等调料调出类似鱼香的复合味道。这道菜色泽红亮，肉丝细嫩，咸甜酸辣四味兼备，是川菜中"鱼香"味型的代表作品。

## 份量/人数
2-3人份

## 所需餐具
- 炒锅
- 锅铲
- 漏勺
- 碗（调料碗）
- 盘子（盛装成品）

## 食材清单

### 主料
- 猪里脊肉：200克

### 辅料
- 木耳：30克（提前泡发）
- 冬笋：50克
- 胡萝卜：50克
- 莴笋：50克（可选）

### 调料
- 郫县豆瓣酱：20克（约1大勺）
- 泡椒：15克（约1小勺，切碎）
- 姜：10克（切末）
- 蒜：15克（3瓣，切末）
- 葱：30克（切花）

### 腌制调料
- 食盐：2克
- 料酒：10ml（1大勺）
- 鸡蛋清：1个
- 淀粉：10克

### 碗芡调料
- 生抽：15ml（1大勺）
- 醋：15ml（1大勺）
- 白糖：15克（1大勺）
- 料酒：5ml（1小勺）
- 鸡精：2克
- 淀粉：10克
- 清水：30ml

### 油料
- 食用油：60ml

## 详细步骤

### 步骤1：肉类腌制
**正在做什么：** 将里脊肉切丝后腌制上浆，保持嫩滑口感。

**食材当前状态：** 猪里脊肉是完整的肉块，表面湿润。

**操作要点：**
1. 将里脊肉洗净，吸干水分
2. 顺着肉的纹路切成约5厘米长、0.3厘米粗的丝
3. 放入碗中，加入食盐2克
4. 加入料酒10ml
5. 用手抓匀，让肉丝吸收调料
6. 加入鸡蛋清1个，继续抓匀
7. 最后加入淀粉10克，抓匀使肉丝表面形成薄浆
8. 腌制15分钟

**注意事项：** 切肉丝时顺着纹路切，炒出来更嫩。不要切太细，容易炒碎。

### 步骤2：准备辅料
**正在做什么：** 将所有辅料切成丝，准备碗芡。

**食材当前状态：** 木耳泡发好了，冬笋、胡萝卜是完整的。

**操作要点：**
1. 木耳泡发后洗净，去掉硬根，切成丝
2. 冬笋切成约5厘米长的丝
3. 胡萝卜去皮，切成约5厘米长的丝
4. 莴笋去皮，切成丝（如果使用）
5. 将所有辅料丝放入沸水中焯烫约1分钟
6. 捞出沥干水分备用

**注意事项：** 辅料丝要切得粗细均匀，和肉丝差不多。焯水可以让蔬菜更爽口。

### 步骤3：调制碗芡
**正在做什么：** 将所有碗芡调料调匀，方便烹饪时快速使用。

**食材当前状态：** 调料都是原始状态，需要混合。

**操作要点：**
1. 取一个碗，放入生抽15ml
2. 加入醋15ml
3. 加入白糖15克
4. 加入料酒5ml
5. 加入鸡精2克
6. 加入淀粉10克
7. 加入清水30ml
8. 搅拌均匀，确保糖和淀粉都溶化

**注意事项：** 碗芡要提前调好，糖要完全溶化，淀粉要搅匀避免沉淀。

### 步骤4：滑炒肉丝
**正在做什么：** 将腌好的肉丝滑炒至变色。

**食材当前状态：** 肉丝表面裹着薄薄的浆液，呈粉红色。

**操作要点：**
1. 锅中倒入40ml食用油，烧至五成热
2. 下入腌好的肉丝，用筷子快速拨散
3. 保持中火，快速滑炒
4. 炒至肉丝变色，表面微白
5. 约需1-2分钟
6. 盛出沥干油分备用

**注意事项：** 油温不要太高，保持中火快速滑炒。肉丝要拨散，防止粘连。

### 步骤5：炒制底料
**正在做什么：** 炒制豆瓣酱、泡椒和姜蒜末，形成鱼香味底料。

**食材当前状态：** 锅中只有底油，调料都是原始状态。

**操作要点：**
1. 锅中留底油约20ml，烧热
2. 下入郫县豆瓣酱20克
3. 用中火快速翻炒，炒出红油
4. 放入切碎的泡椒15克
5. 继续翻炒出香味
6. 下入姜末10克和蒜末15克
7. 炒出香味，约需15秒

**注意事项：** 豆瓣酱要炒出红油，但不要炒糊。泡椒要切碎，味道才能充分释放。

### 步骤6：加入辅料和肉丝
**正在做什么：** 将焯好的辅料和炒好的肉丝一起翻炒。

**食材当前状态：** 底料已经在锅中，红油透亮。

**操作要点：**
1. 放入焯好的辅料丝（木耳、冬笋、胡萝卜）
2. 快速翻炒均匀
3. 放入滑炒过的肉丝
4. 继续翻炒，让食材均匀混合

**注意事项：** 这个步骤要大火快炒，保持蔬菜的爽脆口感。

### 步骤7：加入碗芡
**正在做什么：** 倒入调好的碗芡，大火收汁。

**食材当前状态：** 所有食材已经混合均匀。

**操作要点：**
1. 将碗芡再次摇匀（淀粉可能沉淀）
2. 大火状态下，将碗芡倒入锅中
3. 快速翻炒，让食材均匀裹上芡汁
4. 汤汁变得浓稠
5. 撒入葱花30克
6. 快速翻匀

**注意事项：** 倒入碗芡时要边倒边炒，防止淀粉结块。葱花最后放，保持翠绿。

### 步骤8：出锅装盘
**正在做什么：** 将完成的鱼香肉丝装入盘中。

**食材当前状态：** 鱼香肉丝完成，色泽红亮，香味扑鼻。

**操作要点：**
1. 翻炒均匀后立即出锅
2. 装入盘中
3. 趁热食用

**注意事项：** 鱼香肉丝要趁热吃，口感最佳。冷了肉丝会变硬。

## 烹饪关键点/小贴士

1. **肉的选择**：最好选用猪里脊肉，肉质细嫩。切丝时要顺着纹路切。

2. **上浆技巧**：腌制时加入蛋清和淀粉，可以在肉丝表面形成保护膜，保持嫩滑口感。

3. **辅料搭配**：传统的鱼香肉丝会用木耳、冬笋、胡萝卜。还可以加入莴笋、荸荠等，增加口感层次。

4. **泡椒用量**：泡椒是鱼香味的关键，根据个人口味调整用量。泡椒和豆瓣酱一起使用，味道更浓郁。

5. **碗芡比例**：生抽、醋、糖的比例约为1:1:1，这是鱼香味的基础。可以根据个人口味微调。

6. **火候控制**：全程大火快炒。肉丝滑炒不要过久，保持嫩滑。辅料要保持爽脆。

7. **葱花时机**：葱花一定要最后放，既能增香又能保持翠绿颜色。
