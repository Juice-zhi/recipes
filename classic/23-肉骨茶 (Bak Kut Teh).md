# 肉骨茶 (Bak Kut Teh)

## 菜系/国家
新加坡/马来西亚菜 / 东南亚

## 概述
肉骨茶是新加坡和马来西亚的著名小吃，以猪骨和药材熬制的汤底配以米饭或油条食用。这道菜汤汁浓郁，带有药材的清香，既可当早餐，也可当正餐，是当地华人社区的传统美食。

## 份量/人数
4人份

## 所需餐具
- 大汤锅
- 漏勺
- 碗（盛汤用）

## 食材清单

### 主料
- 猪排骨：600克

### 药材
- 当归：5克
- 党参：10克
- 枸杞：10克
- 川芎：5克
- 玉竹：10克
- 八角：2个
- 桂皮：5克
- 陈皮：5克

### 调料
- 生抽：30ml（2大勺）
- 老抽：15ml（1大勺）
- 盐：10克
- 白胡椒粉：5克
- 蒜：30克（整瓣）

### 配料
- 油条：2根（切段）
- 白米饭：适量
- 小米椒：适量（切圈）

## 详细步骤

### 步骤1：排骨处理
**正在做什么：** 将排骨焯水去腥。

**操作要点：**
1. 排骨洗净，切成适当大小
2. 放入沸水中焯烫
3. 去除浮沫
4. 捞出洗净备用

**注意事项：** 焯水可以去除排骨的腥味和血水。

### 步骤2：熬汤底
**正在做什么：** 将药材和排骨一起熬汤。

**操作要点：**
1. 汤锅中加入足够的水
2. 放入所有药材
3. 大火烧开
4. 放入排骨
5. 大火烧开后转小火
6. 加入蒜瓣
7. 小火熬煮1.5-2小时
8. 熬至汤色浓白

**注意事项：** 要用小火熬制，大火会让汤浑浊。药材可以根据个人口味调整。

### 步骤3：调味
**正在做什么：** 调味。

**操作要点：**
1. 加入生抽30ml
2. 加入老抽15ml
3. 加入盐10克
4. 加入白胡椒粉5克
5. 搅拌均匀
6. 尝尝味道，适当调整

**注意事项：** 盐要分次加入，边加边尝。

### 步骤4：上桌
**正在做什么：** 肉骨茶完成。

**操作要点：**
1. 将排骨和汤盛入碗中
2. 配上油条段
3. 配上白米饭
4. 撒上小米椒圈
5. 趁热食用

**注意事项：** 肉骨茶要趁热吃，油条要泡在汤里吃。

## 烹饪关键点/小贴士

1. **药材选择**：药材可以根据个人体质和口味调整。传统肉骨茶会用当归、党参、枸杞等。

2. **火候**：要小火慢炖，炖出药材的味道。汤要熬到浓白。

3. **蒜的作用**：蒜可以增加香气，要整瓣放入。炖久的蒜会变得软糯好吃。

4. **油条**：油条是肉骨茶的经典搭配。泡在汤里吃，非常美味。

5. **吃法**：肉骨茶可以配米饭或油条。根据个人喜好选择。
